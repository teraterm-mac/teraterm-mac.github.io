Additional settings / "Theme" tab ([Setup] menu)

[Setup] menu Theme... opens this tab.

Theme

Looks of Tera Term Mac can be changed.
It is not a macOS appearance (Dark Mode, etc.) setting.
To change a theme, edit the theme file in a text editor (see Contents of a theme file).

Enable
The theme will be enabled.
Disable theme when moving or resizing window
Faster drawing by omitting drawing of the window background (BG theme) during window resizing and moving.
This can be used when using the BG theme.
Startup
Sets the theme to be used at startup.
no use
No theme is used
Fixed theme file
Loads a specific theme file.
Pick a theme bundled with the app from the "Bundled Themes" pop-up, or choose a theme file (*.ini) with the "..." button.
Random Theme file
Randomly load themes from theme files folder.
The theme folder is ~/Library/Application Support/Tera Term Mac/theme. If it has no *.ini files, a bundled theme is picked.

Color Scheme

Color scheme
Choose a preset scheme (Dark, White, Warm, Solarized, etc.) or the colors of a Terminal.app profile.
Choosing a scheme sets the text, background, cursor and ANSI colors to that scheme. Press OK to keep it.
Cursor color
Selects the cursor color.
