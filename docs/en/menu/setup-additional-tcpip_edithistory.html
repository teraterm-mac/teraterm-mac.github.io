Edit host list

Selecting a line in the list copies it to the edit field. OK saves the list; Cancel discards the changes.

Add
Adds the editing line to the history, at the selected position, or at the top if nothing is selected.
Replace
Replaces the selected history entry with the editing line.
Remove
Removes the selected history entry.
Up
Move up one selection in the history.
Down
Move down one selection in the history.
