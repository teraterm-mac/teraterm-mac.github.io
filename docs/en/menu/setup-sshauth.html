SSH Authentication ([Setup] menu)

"TTSSH: Authentication Setup" dialog box

These settings become the initial user name and private key in the New connection dialog, and the order of authentication methods passed to ssh (PreferredAuthentications). Authentication itself is done by OpenSSH (/usr/bin/ssh).

User name
Specifies the user name used when none is given.
Do not enter username
No user name is entered.
Use default username
Uses the default user name entered in the edit box. If it is empty, nothing is entered.
Use logon username
Uses the name of the user logged in to the Mac.
Sets the default authentication method.
Use plain password to log in
Use password authentication. ssh's default order is kept (you are asked for the password if public keys do not work).
Use RSA/DSA/ECDSA/ED25519 key to login
Use authentication with an RSA/DSA/ECDSA/ED25519 key you created beforehand. Public key authentication is tried first.
Private key file
Specifies the private key file (you can choose it with the [Private key...] button). It is passed with ssh's -i option.
Use a key in a format OpenSSH can read. PuTTY format keys (.ppk) cannot be used.
SSH2:Use keyboard-interactive to log in
Use keyboard-interactive authentication. Use this to log in with a password to a server where password authentication is disabled.
What you type is sent to the server encrypted.
Use ssh-agent
Authenticate with keys added to ssh-agent. Public key authentication is tried first.
