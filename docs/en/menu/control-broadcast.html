Broadcast command([Control] Menu)

If "Realtime mode" is off

Command input control
Input the command to be sent to each window.
History
Choose an option whether to save the history of transmitted commands. A maximum number of history to be saved can be specified by "MaxBroadcatHistory" .
History is saved in the broadcast.log file. File can be checked in [Setup]-Setup directory.
Enter key
Choose an option whether new line is added or not after the transmission of the command specified in above. A New line code can be chosen from the list of "CRLF", "CR", "LF".
Send to this process only
If this option is chosen, the command will be transmitted only to the Tera Term window where the "Broadcast command" dialog is invoked regardless of the selection status in the window list.
Submit key
Select the key operation used to send the command.
Window List
List of Tera Term windows. Choose the windows by left click where the commands will be transmitted. Right-click on the list to operate on the selected windows or to refresh the list.
Submit
Transmit the command. If "AcceptBroadcast" of the window is effective, the command will be received.

If "Realtime mode" is on

Command input control
Keys entered with this control focused will be transmitted to the windows that are chosen in the following window list. The command will be received by the window where "AcceptBroadcast" is even disabled. Use ⌘V (or Shift-Insert) to send the clipboard contents to the windows selected in the window list. Other ⌘ key combinations act on the input field itself. You can also send the clipboard contents to a selected window by right- or middle-clicking the mouse on this control. Settings such as "DisablePasteMouseRButton", "DisablePasteMouseMButton", and "ConfirmChangePaste" affect when the clipboard contents are sent.
Window List
List of Tera Term windows. Choose the windows by left click where the commands will be transmitted. Right-click on the list to operate on the selected windows or to refresh the list.
