Restore setup ([Setup] menu)

Restores the setup of Tera Term Mac from the Tera Term setup file.

"Restore setup" dialog box

The standard macOS open panel opens as a sheet on the terminal window. Select an existing Tera Term setup file (.ini).
The settings are applied to this window at once and are also saved to the app's preferences. SSH settings ([TTSSH] section) and proxy settings ([TTProxy] section) are read as well.
A TERATERM.INI made on Windows can also be read. Items that Tera Term Mac does not use are ignored.
