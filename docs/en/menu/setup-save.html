Save setup ([Setup] menu)

Saves the current setup to the Tera Term setup file.

"Save setup" dialog box

The standard macOS save panel opens as a sheet on the terminal window. Enter or select the setup file name. The setup file used last time is selected first (by default ~/Library/Application Support/Tera Term Mac/TERATERM.INI).
If the file already exists, it is overwritten. When you overwrite the same file as last time, it is backed up before overwriting (IniAutoBackup).
When you save to a new file, the contents of the previous file (including sections Tera Term Mac does not use) are carried over first.
If you omit the file name extension, the extension ".ini" is used.

Note: Tera Term Mac saves changes made in the setup windows to its preferences automatically. Use a setup file to share settings with another Mac or with Tera Term on Windows, or to keep a backup.
