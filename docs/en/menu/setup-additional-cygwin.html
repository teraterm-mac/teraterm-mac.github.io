Additional settings / "Local Shell" Tab ([Setup] Menu)

Configures the shell opened by [File] menu "Local Shell Connection" (⌘G). Changes apply to shells opened afterwards.

Local shell
Tera Term Mac starts a macOS shell directly in the terminal.
SHELL
Path of the shell to start. Use the "..." button to choose one. If empty, the shell in the SHELL environment variable (or /bin/zsh) is used.
TERM
Value of the TERM environment variable passed to the shell. The default is xterm-256color.
ENV_1, ENV_2
Environment variables passed to the shell, written as "name=value".
LOGIN_SHELL
Starts the shell as a login shell.
HOME_CHDIR
Starts the shell in your home folder.

These settings are stored in the app's preferences.
