Additional settings([Setup] Menu)

The [Setup] menu items Terminal, Window, Font, Theme, Keyboard, Serial port, TCP/IP, General and Additional settings all open this one settings dialog. Only the tab shown first differs.

The dialog opens as a separate window. Changes are applied to the terminal immediately, so you can see the result while you edit. OK keeps the changes; Cancel restores the state from when the dialog was opened. Settings are stored in the app's preferences. To write them to TERATERM.INI, use Save setup.
