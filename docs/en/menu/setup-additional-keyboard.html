Additional settings / "Keyboard" tab ([Setup] menu)

Transmit DEL by:
Backspace key
If this option is checked, pressing the delete key sends the DEL character (ASCII 0x7F). If not checked, the BS character (ASCII 0x08) is sent. Even if this option is (not) checked, the BS (DEL) character can be sent by pressing Control+delete.
Delete key
If this option is checked, pressing the forward delete key (fn+delete, or ⌦ on extended keyboards) sends the DEL character. If not checked, the function assigned for this key is determined by the keyboard setupfile.
Meta key
Uses the Option key as the meta key. For example, the sequence ESC A is sent by pressing Option+A.
"off" disables it, "on" uses both Option keys, "left" uses only the left Option key, and "right" uses only the right Option key. The Option key that is not the meta key still types characters as usual (symbols entered with Option).
Menu shortcuts use the ⌘ key, so they keep working in meta-key mode.
Disabled mode:
Application Keypad
This option disables Application Keypad mode.
If this option is selected, you can prevent a problem of a numeric keypad from being unavailable due to an accidental transition to Application Keypad mode.
Note that some application which uses application keypad mode may encounter other problems when this option is selected.
Application Cursor
This option disables Application Cursor mode.

You can modify key assignments by editing the keyboard setupfile.
