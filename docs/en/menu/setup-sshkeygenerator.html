SSH Keygenerator ([Setup] menu)

"TTSSH: Key Generator" dialog box

For details, see "Generating keys" in SSH connection.
Keys are generated with the macOS ssh-keygen (/usr/bin/ssh-keygen).

Key type
Specifies the type of key to generate.
RSA
Generates an RSA key for SSH2.
DSA
Generates a DSA key for SSH2. The key length is fixed at 1024 bits.
A DSA key longer than 1024 bits would not be more secure. For a stronger key, use RSA, ECDSA or ED25519.
Recent versions of ssh on macOS may not accept DSA keys.
ECDSA-256
Generates an ECDSA (256-bit) key for SSH2.
ECDSA-384
Generates an ECDSA (384-bit) key for SSH2.
ECDSA-521
Generates an ECDSA (521-bit) key for SSH2.
ED25519
Generates an ED25519 key for SSH2.
Key Bits
Specifies the key length. It can be changed only for RSA.
bcrypt KDF
Saves the private key in OpenSSH format (bcrypt KDF). You can also set the number of rounds.
When unchecked, the key is saved in PEM format.
Generate
Generates the key. It stays in a temporary folder until you save it.
Key passphrase
Specifies the passphrase for the private key.
Confirm passphrase
Enter the same passphrase again for confirmation.
Comment
Specifies the comment for the key.
Save public key
Saves the public key. The save panel opens in ~/.ssh with the file name id_<type>.pub.
Save private key
Saves the private key. The save panel opens in ~/.ssh with the file name id_<type>. The file permission is set to 600 (readable and writable only by you).
Encryption with the passphrase is done by ssh-keygen.
