Load key map ([Setup] menu)

Restores the keyboard setup from the keyboard setup file.

"Load key map" dialog box

The standard macOS open panel opens as a sheet on the terminal window. Select an existing keyboard setup file (.cnf). The default is ~/Library/Application Support/Tera Term Mac/KEYBOARD.CNF.
If the same key code is assigned more than once, a list of the errors is shown.
