XMODEM ([File] Transfer menu)

Transfers files between the Mac and the host with the XMODEM protocol.

Receive...
Receives a file from the host. Activate the send command of the host's XMODEM before executing this command.
Send...
Sends a file to the host.
Activate the send command of the host's XMODEM before executing this command.
