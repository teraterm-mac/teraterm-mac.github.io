[Window] menu

You can activate one of existing Tera Term windows by selecting it from the list in this menu. At most 9 windows can be listed in this menu. If actual number of windows exceeds 9 and you want to activate a window which is not in the list, use the Window command in this menu.
The mark before each window name shows its state: + normal, - minimized in the Dock, @ zoomed, # hidden.

Window...
Activates or closes a Tera Term window.
Minimize All
Minimize all Tera Term window.
Restore All
Restore all Tera Term window.
Cascade
Cascade, which puts windows in a single stack that has been fanned out so that the window title appear.
Stacked
Arranges the windows one above another, each as wide as the screen. Windows merged into tabs are split into separate windows first.
Side By Side
Arranges the windows side by side, each as tall as the screen. Windows merged into tabs are split into separate windows first.
Undo - Cascade|Stacked|Side By Side
Undo the Tera Term window position after arranging windows.
Minimize
Minimizes this window into the Dock (⌘M).
Zoom
Zooms this window, or returns it to its previous size.
Show Previous Tab / Show Next Tab
When windows are merged into tabs, switches to the previous tab (⌘{) or the next tab (⌘}).
Show Menu Bar / Hide Menu Bar
Shows or hides a menu bar inside the window, just below the title bar (PopupMenu in TERATERM.INI). The macOS menu bar at the top of the screen is always available.
While this menu bar is hidden, control-click (left button) in the window to pop up the menus.
TTMado (tabs and split panes)
TTMado is a built-in plugin of the Mac version that provides tabs and split panes. Drag tabs or windows to place them inside one window, drag pane headers to rearrange panes or turn them back into tabs, extend a pane to an edge, and so on. See Show several sessions in one window in the quick guide.
[Window] > [Stacked] and [Side By Side] show the tabs of a window as split panes.
To stop using it, uncheck "TTMado" in the [Plugins] tab of [Setup] - [Additional settings...] and click OK. It takes effect at once: split panes go back to tabs, and tabs work like normal macOS tabs. Check it again to turn it back on.
