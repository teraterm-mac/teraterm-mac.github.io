Additional settings / "Window" tab ([Setup] menu)

Title:
Text displayed in the window title.
See Accept window title change request for behavior when a remote title is set.
The remote title can be reset with Reset Remote Title.
Cursor shape
Cursor shape. Block, Vertical line or Horizontal line.
The "Blink cursor" check box selects whether the cursor blinks.
Enable bold font
Enables the use of bold style font for characters with the bold attribute.
16 Colors (PC style)
Enables the PC style mapping of bold color. In this mode, the bold (blink) attribute is used as a color attribute bit for text (background). This option increases the number of colors for text and background specified by escape sequences twice, from 8 to 16.
16 Colors (aixterm style)
Enables aixterm style 16 colors mode. This option increases the number of colors for text and background specified by escape sequences twice, from 8 to 16.
NOTE: The escape sequence(<CSI>100m) which changes the background color to the color number nine would conflict the escape sequence of the resetting rxvt-style characters and background color. So, if a user enables this mode, the behavior of <CSI>100m escape sequence will work never before.
If a user does not like this behavior, turn off this option.
256 Colors (xterm style)
Enables xterm style 256 colors mode. This option increases the number of colors for text and background specified by escape sequences twice, from 8 to 256.
Also, a user can change the color table by the escape sequence.
Scroll buffer
Enables the scroll buffer. If enabled, the number of lines in the scroll buffer (including the displayed area) can be specified. Up to 1,000,000 lines can be entered.
See also Maximum scroll buffer size.
Color
Attribute
Attribute of characters whose colors are being changed.
  • Normal
  • Bold
  • Blink
  • Reverse
  • URL
  • Underline
Text
Text color.
Background
Background color.
Swap colors
Exchanges the text color and background color of the currently active character attribute.
R:, G:, B:
Specifies the RGB value of the color of the specified character attribute.
Always use Normal text's BG
If this option is ON, Tera Term uses Normal background color instead of Bold, Blink and URL's background color.
