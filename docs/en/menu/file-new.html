New connection ([File] menu)

Connects to a new host, a serial port or the local shell (⌘N). If the connection is already open, a new window is opened for the connection.
To replay a log file, use [Replay log...] in the [File] menu.

"New connection" dialog box

Choose TCP/IP, Serial or Local shell (the shell of this Mac) and click [Connect]. The dialog starts with the type and values you used last time.

TCP/IP

Host
Enter the host name or IP address.
If you write user@myhost.example.com, the part before @ is used as the user name.
For Telnet, "myhost.example.com /B" connects in Telnet binary mode.
Enter the port number in [TCP port#]. Other command line options written in the host field are not used.
Host List
You can choose a host from the host list with the drop-down. The saved user name, port, service and private key are filled in.
The host list can be edited in the following ways:
  • [Setup] Additional settings, TCP/IP tab, Edit host list
  • Select "<Edit host list...>" from the drop-down
The host list is saved in the app's preferences. [Save setup...] in the [Setup] menu also writes it to the Hosts section of TERATERM.INI.
Up to 20 hosts can be saved.
keybind
The standard macOS text editing keys can be used in this edit control, for example:
Ctrl+a
Move caret to the beginning
Ctrl+e
Move caret to the end
Ctrl+b
Move caret back one character
Ctrl+f
Move caret forward one character
Ctrl+d
Delete one character
Ctrl+k
Delete to the end of the line
Add host list
If checked, the host you entered is added to the top of the host list when you connect.
If it is already in the list, it is moved to the top.
Add host list when new connection in Additional settings / "TCP/IP" tab is the initial value of this checkbox.
Telnet
Uses the Telnet protocol.
See also: Notes on using non-ASCII characters in user name or password
SSH
Uses the SSH protocol, connecting with the macOS ssh (/usr/bin/ssh).
See also: SSH connection
Other
Uses a protocol other than Telnet / SSH (plain TCP).
TCP port#
Specify the port number for the selected service.
Choosing Telnet or SSH fills in the following default.
Service TCP port# Note
Telnet 23 well-known ports
SSH 22 well-known ports
Other (any)
User name / Password
The user name and password for SSH. The user name starts with the one used last time, or the SSH Authentication setting. If the password is empty, ssh asks for it in the terminal.
See also notes on specifying a password on the command line.
Private key
The private key file for SSH public key authentication. [Choose...] lets you pick it from ~/.ssh. It is passed with ssh's -i option.

Note:
Only if Telnet is selected and <TCP port#> is 23, Tera Term Mac starts spontaneously sending telnet commands to the host for the option negotiation when the TCP/IP connection is established. In any cases, Tera Term Mac can respond to telnet commands sent by the host.

See also:
Telnet port number / Terminal setup for non-telnet connection

Serial

Port
Select a port from the list. The list shows /dev/cu.* devices (USB serial adapters and so on). If no port is available, "(no serial port found)" is shown. Click [Rescan] after plugging in a device.
Speed, data bits, parity, stop bits and flow control can also be set here.

Local shell

Connects to the shell of this Mac. By default your login shell ($SHELL) is started; you can change it on the Local shell tab of Additional settings. It can also be opened with [Local shell connection] (⌘G) in the [File] menu.
