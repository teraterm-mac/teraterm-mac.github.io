SSH ([Setup] menu)

Tera Term Mac connects over SSH with the OpenSSH client that comes with macOS (/usr/bin/ssh). The settings in this dialog are converted to ssh options (-o ...) when a connection is made. They take effect from the next session you connect.
Your ~/.ssh/config is used as with plain ssh.

"TTSSH: Setup" dialog box

Preferred cipher order
Specifies the ciphers used for SSH connections, in order of preference (ssh Ciphers).
Ciphers below <ciphers below this line are disabled> are not used.
The list shows the ciphers the ssh on this Mac supports (ssh -Q cipher). If you leave the order as ssh's default, no option is passed.
SSH Known Hosts
Specifies the files that store the hosts (and host public keys) you have connected to.
The default read/write file is ~/.ssh/known_hosts (ssh UserKnownHostsFile). The read-only file is passed as ssh GlobalKnownHostsFile. A relative path is taken from the setup folder (~/Library/Application Support/Tera Term Mac).
Host key rotation

Specifies whether host keys are updated automatically (ssh UpdateHostKeys).

An SSH server may change its host key for some reason.
Some servers then send the list of new host keys to the client so that the client can update its list.
When such a list is received, the client-side known hosts file can be updated.

No
Does not update (UpdateHostKeys=no).
Yes
Updates the known hosts file automatically (UpdateHostKeys=yes).
Ask
Asks before updating the known hosts file (UpdateHostKeys=ask).
Keepalive
Sends a keep-alive packet when nothing has been received from the server for the specified number of seconds (ssh ServerAliveInterval). 0 disables it.
Enable agent forwarding
Enables SSH agent forwarding with ssh-agent (ssh ForwardAgent=yes).
To be asked for confirmation each time a forwarded key is used, add the key with ssh-add -c.
Verify host key fingerprint by DNS
Specifies whether the server host key is verified with SSHFP resource records (ssh VerifyHostKeyDNS).
KEX order (SSH2 only)
Specifies the key exchange algorithms, in order of preference (ssh KexAlgorithms).
Algorithms below <KEXs below this line are disabled> are not used.
The list shows the algorithms the ssh on this Mac supports (ssh -Q kex).
MAC order (SSH2 only)
Specifies the MAC algorithms, in order of preference (ssh MACs).
Algorithms below <MACs below this line are disabled> are not used.
The list shows the algorithms the ssh on this Mac supports (ssh -Q mac).
Host key order (SSH2 only)
Specifies the host key algorithms, in order of preference (ssh HostKeyAlgorithms).
Algorithms below <Host keys below this line are disabled> are not used.
The list shows the algorithms the ssh on this Mac supports (ssh -Q key).
Compression level
Specifies compression of the connection. Any value other than 0 (none) enables compression (ssh Compression=yes). OpenSSH cannot choose a compression level, so the values 1 to 9 all behave the same. (On fast lines, compression may make the response slower.)
LogLevel
Specifies the level of ssh debug logging.
If it is greater than 0, ssh writes its log to "TTSSH.LOG" in the setup folder (~/Library/Application Support/Tera Term Mac) (ssh -E). The value maps to ssh LogLevel as follows.
Value ssh LogLevel
0 Disabled
1-24 INFO
25-49 VERBOSE
50-74 DEBUG1
75-99 DEBUG2
100 or more DEBUG3
