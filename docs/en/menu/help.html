[Help] menu

Index
Displays this help.
About TTProxy...
Displays information about the proxy feature (TTProxy).
About TTSSH...
Displays information about the SSH feature. Tera Term Mac uses the macOS OpenSSH client (/usr/bin/ssh) for SSH.
About Tera Term...
Displays information about Tera Term Mac.

[Tera Term Mac] menu

Application-wide items are in the [Tera Term Mac] menu at the left of the menu bar.

About Tera Term Mac
Shows the version and other information.
Acknowledgements and Licenses...
Shows acknowledgements and licenses of the software used.
Website (GitHub)...
Opens the Tera Term Mac website.
Check for Updates... / Automatically Check for Updates
Checks whether a newer version is available, and turns automatic checking on or off.
Edit TeraTerm Menu List...
Edits the list of connections registered in TeraTerm Menu.
Uninstall Tera Term Mac...
Removes Tera Term Mac from this Mac.
Quit Tera Term Mac
Closes all windows and quits the application (⌘Q).
