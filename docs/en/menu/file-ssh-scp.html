SSH SCP ([File] menu)

Transfers files between the Mac and the host with the Secure Copy Protocol.
Available only while connected with SSH. The macOS scp (/usr/bin/scp) is used, sharing the current SSH connection (you do not need to log in again).
A progress window is shown during the transfer.

Send

From:
Send file. Choose it with the [...] button, or drag a file from Finder onto this window.
TO:
Specify the destination path.
The path is treated as home directory when dest is empty.
NOTICE: The "~" may not be used in some cases of remote OS and shell.
Send button
Send start

Receive

From:
Receive file
TO:
Specify the save location.
You can specify either a download folder or a download file.
"File transfer" setting is used when TO is empty.
