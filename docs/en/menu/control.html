[Control] menu

Reset terminal
Resets various terminal modes.
Reset remote title
Reset remote title.
Are you there
Sends a AYT (Are You There) telnet signal. Usually, the host sends back some message responding to it. This command is available only with a telnet connection (⌘T).
Send break
Sends a break signal to the host (⌘B). Refer to sendbreak macro command.
Works for Telnet and serial connections. A break cannot be sent over SSH, because Tera Term Mac uses OpenSSH.
Reset port
Resets the serial port. This command is available only with a serial connection.
Broadcast command
Display the dialog for the transmission of broadcast command.
Open TEK
Opens the TEK window.
Close TEK
Closes the TEK window.
Always on top
Keeps this window above other windows. Choose it again to turn it off.
Macro
Runs a macro file.
Show Macro Window
Shows the running macro window.
