[File] menu

New connection...
Connects to a new host or a serial port (⌘N).
Duplicate session
Duplicates the current session in a new window (⌘D). Only TELNET, SSH and local shell connections are duplicated. Raw TCP and serial connections are not.
Please refer to Notes on Specifying a Password of the command line.
Local Shell Connection
Opens a new window connected to this Mac's shell (your login shell) (⌘G). It is configured in the Local shell tab of the Additional settings.
Log...
Logs received characters to a file.
Pause Logging
Pause logging.
Comment to Log...
Adds comment to the log file. The comment is written in UTF-8, followed by a newline (LF).
View Log
Opens the log file.
By default it opens in TextEdit. If ViewlogEditor names an application (.app) or an executable, that is used instead.
Show Log dialog...
Displays the log dialog.
Stop Logging
Stop logging and closes the log file.
Send file...
Sends a file to the host.
When this menu is selected
Open "Send file" dialog.
When this menu is selected with holding down the control key
Open file select dialog, "Send file" dialog is skipped.
Previously used send options are used.
behavior can be swapped by setting.
Receive file...
Outputs the received data to a file.
When this menu is selected
Open "Receive file" dialog.
When this menu is selected with holding down the control key
Open file select dialog, "Receive file" dialog is skipped.
Previously used receive options are used.
behavior can be swapped by setting.
Transfer
Transfers files between the Mac and the host with the Kermit/XMODEM/YMODEM/ZMODEM/B-Plus/Quick-VAN protocols.
SSH SCP
Transfers files between the Mac and the host with the SCP protocol.
Change directory...
Changes the current directory for file transfers.
Replay Log...
Replays the binary log file. This feature and the /R option are equivalent.
A new window opens and shows the file's contents as if they were received from the host.
Print...
Prints the current screen, or the selected text (⌘P).
Disconnect
Closes the connection (⌘I). If the connection type is TCP/IP and the Auto window close option is selected, the window is also closed.
Exit
Closes this window (⌘W). If the connection is open, it is also closed.
To quit the application itself, use "Quit Tera Term Mac" (⌘Q) in the [Tera Term Mac] menu.
Exit All
After one confirmation, closes all Tera Term Mac windows without asking for each one. If the connection is open, it is also closed.
