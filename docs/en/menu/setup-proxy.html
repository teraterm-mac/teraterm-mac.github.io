Proxy([Setup] menu)

Clicking OK saves the settings; they are used from the next connection. You do not need to restart Tera Term Mac.
The proxy is used for SSH connections as well as Telnet and other TCP connections. For SSH, Tera Term Mac itself relays the connection as ssh's ProxyCommand.

"Proxy Setup" dialog box

URL
Shows the current settings as a URL (e.g. socks5://user@proxy.example.com:1080).
Type
Configure Proxy type
  • Without Proxy: Do not use Proxy
  • HTTP: Use HTTP Proxy
  • TELNET: Use TELNET Proxy
  • SOCKS4: Use SOCKS4 Proxy *Protocol does not support IPv6.
  • SOCKS5: Use SOCKS5 Proxy
Hostname
Specify Proxy Server

The host name, IPv4 and IPv6 address can be specified.
The IPv6 address need not to be surround with the bracket.

Port number
Specify port number for Proxy server
Username
When an authentication is required for Proxy server, specify user name
Password
When an authentication is required for Proxy server, specify password
Other setup
Move to "Other Setup" menu

"Other Setup" menu

Common setup

Connection Timeout
The connection to Proxy will be reset if a communication with Proxy (including keep-alive) is lost for this time (seconds)
Proxy connection log
The communication with Proxy server will be logged in this file

SOCKS proxy setup

Specify a name resolution method by Name

auto resolve
Automated resolution
resolve remote
Resolution is done by SOCKS server
resolve local
Resolution is done by the Mac where Tera Term Mac is running

TELNET Proxy setup

Configure TELNET Proxy parameters

Hostname prompt
Specify prompt characters for Host name
Username prompt
Specify prompt characters for User name
Password
Specify prompt characters for Password
Connected
Specify message for notice of connection completed
Error message
Specify message to notify error from Proxy server
