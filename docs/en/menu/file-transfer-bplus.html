B-Plus ([File] Transfer menu)

Transfers a file between the Mac and the host with the B-Plus protocol.

Receive
Receives a file from the host. Activate the download command of the host before executing this command.
Send...
Sends a file to the host. Activate the upload command of the host before executing this command.
