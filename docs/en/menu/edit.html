[Edit] menu

Copy
Copies selected text to the clipboard (⌘C).
Note: Normally, you don't need to use this command, because dragging text automatically copies text to the clipboard (see mouse usage). Use this command to re-copy selected text to the clipboard.
Copy table
Copies selected text to the clipboard. If the copied text consists of words, each space between words is converted to a Tab character. If you copy a table on the screen by using this command, you can paste it into a spreadsheet application, like Numbers or Excel.
Paste
Sends text in the clipboard to the host (⌘V).
Paste<CR>
Sends text in the clipboard to the host, and then sends a new-line code (⌘R).
Clear screen
Erases the screen.
Clear buffer
Erases the scroll buffer and the screen.
Cancel selection
Reset selection. Clipboard content is not changed.
Select screen
Select current screen buffer and copy it into clipboard.
Select all buffer
Select complete screen buffer and copy it into clipboard (⌘A).
