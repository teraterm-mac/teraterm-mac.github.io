ZMODEM Send ([File] Transfer menu)

Sends files to the host. Activate the receive command of the host's ZMODEM before executing this command.

"ZMODEM Send" dialog box

File Name

Enter or select the file names of the existing files to be sent.

Option

Binary
The binary file transfer option. If you want to send text files, don't select this option.
