Additional settings / "UI" Tab ([Setup] Menu)

UI Language
Selects the language of menus and messages. The list is built from the language files (*.lng) bundled with the app.
The first item, "Automatic (follow macOS settings)", picks the language that matches your macOS language settings.
The change takes effect when you press OK. Refer to Language file.
