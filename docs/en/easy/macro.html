Try a macro

A macro (TTL) is a small program that does fixed steps for you. Macros you used with Tera Term on Windows run as they are.

Sample

These 5 lines connect to the example server server1.example.com with SSH and send two commands.

connect 'server1.example.com /ssh /user=user'
wait '$'
sendln 'echo Hello'
wait '$'
sendln 'ls'
  • connect … connects to the host.
  • wait … waits until "$" (the prompt) appears on the screen.
  • sendln … sends the text followed by a new line (return).

Create the macro file

  1. Write the 5 lines above in TextEdit (in plain text mode) or another editor. Replace the server name and user name with your own.
  2. Save it with a name ending in ".ttl", such as "sample.ttl".

Run the macro

  1. In Tera Term Mac, choose [Control] > [Macro].
  2. Choose the saved sample.ttl and click "Open".
  3. If you are asked for a password, type it in the terminal. After that the macro sends the commands by itself.

You can also double-click a .ttl file in the Finder. It then runs in a new window.

To stop it, choose [Control] > [Show Macro Window] and click "End" in the window that appears.
