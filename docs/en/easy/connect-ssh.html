Connect to a server with SSH

This page connects to the example server "example.com" as the user "user". Use the host name and user name your server administrator gave you instead.

Steps

  1. Press ⌘N (or choose [File] > [New connection...]).
  2. Make sure "TCP/IP" is selected.
  3. In "Host", type the host name or IP address (for example example.com).
  4. Under "Service", choose "SSH". Leave the TCP port at 22.
  5. Type your "User name" (for example user).
  6. You can leave "Password" empty. You will then be asked for it in the terminal after connecting.
  7. Click "Connect".


The New connection dialog with example.com as the host and user as the user name

The question on your first connection

The first time you connect to a server, the terminal shows a question like this:

The authenticity of host 'example.com (...)' can't be established.
ED25519 key fingerprint is SHA256:....
Are you sure you want to continue connecting (yes/no/[fingerprint])?
  1. It means "This is the first connection to this server. Is it really the right one?"
  2. If the host is correct, type yes and press return.
  3. You will not be asked again for this server.

If a server you use every day shows "REMOTE HOST IDENTIFICATION HAS CHANGED!", do not continue. Check with the server administrator first.

Enter your password

  1. When the terminal shows something like "user@example.com's password:", type your password.
  2. The characters you type are not shown. Just type and press return.
  3. When the server prompt (such as "$") appears, you are connected and can type commands.

Disconnect

  • Type exit on the server, or choose [File] > [Disconnect] (⌘I).
  • To close the window, press ⌘W.
