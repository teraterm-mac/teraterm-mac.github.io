Quick guide

Features that only the Mac version has are listed in Features only in the Mac version.
Tera Term Mac is an app (a terminal emulator) for connecting from your Mac to servers and network devices and working on them.
It brings the well-known Windows Tera Term to the Mac: SSH, Telnet, serial connections and TTL macros all work.


A Tera Term Mac window
