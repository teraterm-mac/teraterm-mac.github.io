How to run a macro file

Macros run inside Tera Term Mac.
There are the following ways to run a macro file.

1) Run a macro from the Tera Term Mac menu.

Choose [Control] > [Macro]. A panel to select a macro file (*.ttl) appears; select the macro file you want to run. The macro runs in that window.

2) Run a macro from the Finder.

Double-click a macro file (*.ttl) in the Finder. Tera Term Mac opens a new window and runs the macro. You can also open it with the open command in Terminal: 

open DIALUP.ttl
open -a "Tera Term Mac" DIALUP.ttl

The new window is not connected yet. Use the macro command connect to connect.

3) Run a macro from the command line.

You can give a macro file with the /M= option when starting Tera Term Mac. See Command line.

4) Other ways

A macro can also be run from a TeraTerm Menu entry (with the mode set to macro) or from a macro assignment in the keyboard setup file (KEYBOARD.CNF).

The macro window

While a macro is running, choose [Control] > [Show Macro Window] to open the "MACRO - <macro file name>" window. It shows the macro file name and the line being run. With the "Pause"/"Start"/"End" buttons you can pause, resume and end the macro.

Note: Loading macro files

A macro file is loaded into memory at once and then interpreted. However, the macro command include loads the specified macro file each time it is executed. When a macro file on a network is run directly and the network is disconnected, the include command causes an error.
