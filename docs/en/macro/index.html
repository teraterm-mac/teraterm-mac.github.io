Tera Term Mac runs macros written in the macro language "Tera Term Language (TTL)", which controls Tera Term Mac and provides various functions like auto dialing, auto login and so on.
Macros run inside Tera Term Mac. Most macros written for Tera Term for Windows run as they are.
