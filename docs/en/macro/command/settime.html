settime

Command to change the system time. Tera Term Mac does nothing. 

settime <time>

Remarks

Tera Term Mac does nothing for this command (it is accepted for compatibility with Windows macros).
The format of <time> is "HH:MM:SS". On a Mac, an application cannot change the system clock.
