getttdir

Gets the folder that contains Tera Term Mac.app. 

getttdir <strvar>

Remarks

The folder that contains Tera Term Mac.app (e.g. /Applications) is stored in the <strvar> string variable.
If the directory is gotten successfully, the system variable "result" is set to 0. Otherwise, "result" is set to zero.

Example

getttdir dir
messagebox dir 'getttdir' 0
; dir is "/Applications"
