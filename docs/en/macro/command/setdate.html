setdate

Command to change the system date. Tera Term Mac does nothing. 

setdate <date>

Remarks

Tera Term Mac does nothing for this command (it is accepted for compatibility with Windows macros).
The format of <date> is "YYYY-MM-DD". On a Mac, an application cannot change the system clock.
