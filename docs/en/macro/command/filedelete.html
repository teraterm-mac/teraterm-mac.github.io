filedelete

Deletes a file. 

filedelete <filename>

Remarks

Deletes the file specified by <filename>.
If the file is deleted successfully, the system variable "result" is set to 0. Otherwise, "result" is set to non-zero.

Example

filedelete 'temp.log'
