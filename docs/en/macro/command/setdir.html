setdir

Changes the current working directory for the macro. 

setdir <dir>

Remarks

Changes the current working directory for the macro to <dir>. Use Mac paths ('~' is the home folder; a drive letter such as 'c:' is ignored, and '\' is treated as '/').

File names specified for other commands (e.g. fileopen) are based on the "current working directory for the macro."

Note

The setdir command changes "current working directory for the macro."
The changedir command changes "File transfer directory."

Example

setdir '~/Documents'
