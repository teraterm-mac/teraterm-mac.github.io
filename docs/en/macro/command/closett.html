closett

Closes the window the macro is running in. 

closett

Remarks

Closes the window and enters the unlinked state. The macro keeps running.
In the unlinked state, the "connect" command can open a new window and link the macro to it.

This command always disables the warning on TCP/IP disconnection regardless of ConfirmDisconnect configuration.

Example

messagebox 'foo' 'val'
closett
end
