restoresetup

Loads a Tera Term setup file. 

restoresetup <filename>

Remarks

Loads the Tera Term setup file (TERATERM.INI) specified by <filename> and uses it for the window the macro is running in. Only the entries that Tera Term Mac uses are read.
If the file name is a relative path, it is based on the setup folder (~/Library/Application Support/Tera Term Mac).

Example

restoresetup 'teraterm.ini'
