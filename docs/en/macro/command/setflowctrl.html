setflowctrl

Causes Tera Term to change flow control. 

setflowctrl <value>

Parameters

integer <value>
Set the flow control of serial port by using below flags.
Value Meaning
1 Xon/Xoff
2 hardware(RTS/CTS)
3 none
4 hardware(DSR/DTR)

Example

; change flow control to "none"
setflowctrl 3
