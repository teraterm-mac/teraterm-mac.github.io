unlink

Terminates the link between the current window and the macro. 

unlink

Remarks

The macro enters the unlinked state and can not control the window any more. The window stays open and the macro keeps running.
In the unlinked state, the "connect" command can open a new window and link the macro to it.

Example

; connect to the host
connect 'host'

; terminate the link
unlink

; open a new window, link the macro to it and connect
connect 'host2'
