ifdefined

Checks the type. 

ifdefined <var>

Remarks

Sets the type of <var>. One of the following values in the system variable "result":

Value Meaning
0 undefined
1 integer
3 string
4 label
5 integer array
6 string array

Example

ifdefined data
int2str valstr result
messagebox valstr 'variable type'
