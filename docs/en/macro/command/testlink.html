testlink

Reports the current link and connection status. 

testlink

Remarks

The system variable "result" is set to one of the following values depending on the link and connection status:

Value Status
0 The macro is not linked to a window.
1 Connection to the host has not been made, but the macro is linked to a window.
2 Both connection and link have been made.

Example

; If the macro is not linked to a window, 
testlink
; execute the connect command.
if result=0 connect 'host'
