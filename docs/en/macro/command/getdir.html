getdir

Gets the current working directory for the macro. 

getdir <strvar>

Remarks

Returns the current working directory for the macro to the string variable <strvar> as a Mac path (e.g. /Users/user/Macro). Initially it is the folder that contains the macro file.
If the directory is the root, the string is "/". If the directory is a directory other than the root, the string ends with the directory name and not with "/".

Example

getdir dir
; dir = /Users/user/Macro
