scprecv

Receives a file from the remote host with the SCP protocol. 

scprecv <remote filename> [<local filename>]

Remarks

Receives the remote file <remote filename> from the host with the SCP(Secure Copy Protocol) protocol. The SSH connection is shared and the file is transferred with the Mac scp command. This command works only while connected with SSH. If the local file <local filename> is omitted, the file <remote filename> would be copied in the file transfer folder (the folder set by changedir; the Downloads folder by default). The macro does not pause until the end of the file transfer.

Example

connect '192.168.3.2:22 /ssh /auth=password /user=hoge /passwd=fuga'
wait '$'
scprecv 'bin/tool.sh'
scprecv 'sample.bin' '/Users/user/hoge.bin'
