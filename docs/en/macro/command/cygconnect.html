cygconnect

Connects to a local shell on the Mac. 

cygconnect [<command line parameters>]

Remarks

Connects the window the macro is running in to a local shell on this Mac (the shell set in the Local Shell tab of the settings). <command line parameters> is accepted for compatibility with Windows macros, but it is not used.

If the macro is not linked to a window (after unlink or closett), this command opens a new window, links it to the macro and connects it to the local shell.

If the macro has already been linked to a window and the window has already been connected to the host or the local shell, this command is ignored.

As a result of this command, the system variable "result" is set to one of the following values depending on the link and connection status:

Value Status
0 The macro is not linked to a window.
1 Connection to the host or the local shell has not been made, but the macro is linked to a window.
2 Both connection and link have been made.

To test the current link and connect status before executing the "cygconnect" command, use the "testlink" command.

Communication commands except "connect", "cygconnect" and "testlink" can not be executed before the link is established.

Example

; connect to the local shell
cygconnect
