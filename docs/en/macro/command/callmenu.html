callmenu

Executes a menu of window. 

callmenu <menu ID>

Remarks

Executes the menu that was specified by <menu ID>. The following IDs can be used. Other IDs only show a "not supported" message and do nothing.

ID Operation
50110, 50003 New connection
50111, 50010 Duplicate session
50112 Local shell in a new window
50120 Log
50124 Pause / resume log
50125 Stop log
50122 Open the log file
50123 Show the log file in the Finder
50130 Send file
50190, 50009 Disconnect
50199, 50005 Close the window
50200 Quit
50210, 50002 Copy
50230, 50008 Paste
50250 Clear screen
50260 Clear buffer
50280, 50290 Select all
50310, 50320, 50330, 50340, 50370, 50375 Setup dialog
50350 Serial port setup
50360 New connection
50380 Save setup
50410 Reset terminal
50411 Reset remote title
50420 Are You There
50430, 50001 Send break
50440 Reset port
50470 Macro
50990 About

Example

; select all.
callmenu 50280

; copy to the clipboard.
callmenu 50210
