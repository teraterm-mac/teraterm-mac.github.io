fileunlock

Unlocks the specified file. 

fileunlock <file handle>

Remarks

Unlocks the specified whole file (locked by filelock). Unlocking a file enables other programs that use locks to lock the file.

If the function succeeds, the system variable "result" is set to 0.
If the function fails, the system variable "result" is set to 1.

Examples

fileopen fhandle 'test.txt' 0
filelock fhandle
if result!=0 then
	messagebox 'error' 'hoge'
endif
filewrite fhandle 'sample'
pause 60
fileunlock fhandle
if result!=0 then
	messagebox 'error' 'hoge'
endif
fileclose fhandle
