loadkeymap

Command to load a keyboard setup file. Tera Term Mac does nothing. 

loadkeymap <filename>

Remarks

Tera Term Mac does nothing for this command (it is accepted for compatibility with Windows macros).
To load a keyboard setup file, use [Setup] > [Load key map...].
