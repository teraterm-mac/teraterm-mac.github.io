clearscreen

Erases the screen. 

clearscreen <int>

Remarks

Erases the screen of the terminal window if <int> is 0.
Erases the scroll buffer and screen of the terminal window if <int> is 1.
Does nothing if <int> is 2 (accepted for compatibility with Windows macros).

Example

clearscreen 0
