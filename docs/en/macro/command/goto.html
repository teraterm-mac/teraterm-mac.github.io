goto

Jumps to a label, 

goto <label>

Remarks

Moves control to the next line of the <label>.
However, the goto can not be used to exit the loop like as for and while, use the break instruction in place of the goto.

Example

; Jump to the next line of the ':label'.
goto label
...
...
...

:label
send 'abc'
