beep

Makes a beep sound. 

beep [<sound type>]

Remarks

Plays a Mac system sound.
The <sound type> parameter can be one of the following values. The default value is 5 (the default alert sound).

Value Meaning
0 The default alert sound
1 Glass
2 Funk
3 Basso
4 Purr
5 The default alert sound

Example

for i 1 10
	beep 0
	pause 1
next
