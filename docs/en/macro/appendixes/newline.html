About new-line characters

New-line characters (CR or CR+LF) received from the host are converted to CR+LF pairs and then passed to the macro.
You should use the pair (CR+LF) as a new-line character to send from a macro.
ASCII code 13 (decimal) is for CR, and 10 is for LF.

Example:

send 'abc'#13#10 Same as the statement "sendln 'abc'". The actual new-line character to be sent to the host is determined by the transmit new-line setting.
wait #10'abc' 'def'#13 Waits for a line beginning with "abc" or a line ending with "def".
logwrite 'abc'#13#10 Writes line "abc" to the log file.
