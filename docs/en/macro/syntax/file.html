Encoding

Macro files can be written in Unicode (UTF-8, UTF-16BE, UTF-16LE). UTF-8 is recommended.
Macro files written in Shift_JIS for Tera Term for Windows can also be read.

1) Supporting encoding

encoding support
Shift_JIS Support
UTF-8 (with BOM) Support
UTF-8 (without BOM) Support
UTF-16BE (without BOM) Not support
UTF-16LE (without BOM) Not support
UTF-16 (with BE BOM) Support
UTF-16 (with LE BOM) Support
UTF-16 (without BOM = UTF-16BE) Not support

2) Encoding determination

Tera Term Mac determines the encoding as follows.

When BOM exists
Tera Term Mac determines one of UTF-8, UTF-16BE and UTF-16LE from BOM type, next reading the file.
When BOM does not exist
  • Reading the file as UTF-8.
  • Reading the file as Shift_JIS when the file can not be decoded as UTF-8.
