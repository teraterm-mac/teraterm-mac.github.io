Mouse

VT window

Left button

Clicking the left button
The click position will be starting point for the selection area when Shift+Left Clicked.
Any existing selection area will be canceled.
If "Enabling text selection when the window is activated by mouse" is OFF, the click that activates the window does not start a selection.
While an application that uses mouse event reporting (vim, tmux, etc.) is running, clicks are sent to the host.
Shift + Left click
If no selection area exists, the area from Left Click position to current position will be selected.
If a selection area already exists, you can stretch or shrink the selected text area.
When "Copy to clipboard when text is selected" is ON, the selected text will be copied to the clipboard.
Dragging with the left button
Selects by character.
When "Copy to clipboard when text is selected" is ON, the selected text will be copied to the clipboard.
Double clicking the left button
Selects by word.
When "Copy to clipboard when text is selected" is ON, the selected text will be copied to the clipboard.
Word delimiter characters are specified by Delimiter characters setting.
When DelimDBCS is ON, the boundary between 1-cell and characters displayed in 2 or more cells (such as Kanji or Emojis) is treated as a delimiter.
Double clicking the left button and dragging (hold the left button on the second click)
The selected text area can be expanded or shrunk by word.
When "Copy to clipboard when text is selected" is ON, the selected text will be copied to the clipboard.
Triple clicking the left button
Selects a line,
When "Copy to clipboard when text is selected" is ON, the selected text will be copied to the clipboard.
Triple clicking the left button and dragging (hold the left button on the third click)
The selection area can be expanded or shrunk by line.
When "Copy to clipboard when text is selected" is ON, the selected text will be copied to the clipboard.
Double clicking a URL, or clicking a URL while pressing the ⌘ key
When clickable URLs (EnableClickableUrl) are enabled, opens the URL in the browser.
Double clicking the left button on the title bar
Zooms or minimizes the window to the Dock, following the macOS setting (System Settings, "Desktop & Dock").
Clicking the left button while pressing the Ctrl key
If the in-window menu bar is hidden, a pop-up menu with the same menus appears.
The in-window menu bar is hidden and shown with [Window] Hide Menu Bar / Show Menu Bar. The Mac menu bar at the top of the screen is always available.

right button

Clicking the right button
Sends text in the clipboard to the host.
It is effective when DisableMouseRButtonPaste is disabled.
When ConfirmPasteMouseRButton is on, a menu with "Paste" and "Paste<CR>" appears, and the text is pasted only when you choose one.
On a trackpad, click with two fingers or Control-click for a right click (when the in-window menu bar is hidden, Control-click shows the pop-up menu above instead).
Dragging with the right button
Selects text, copies it to the clipboard, and then sends it to the host.
It is effective when both DisableMouseRButtonPaste and SelectOnlyByLButton are disabled.

middle button

Clicking the middle button
Sends text in the clipboard to the host.
It is effective when DisableMouseMButtonPaste is disabled.

Mouse wheel

Mouse wheel
Rotating the wheel (two-finger scrolling on a trackpad) scrolls the window.
While an application that uses the alternate screen (vi, less, etc.) is running, the wheel is sent as up/down cursor keys. Applications that use mouse event reporting receive wheel events.

Drop

Dragging a text file and dropping it into the window
Files and folders can be dragged and dropped to be "Sent via SCP," "Sent as content," or "Pasted as file names.".
Displaying Confirmation Dialog
When ConfirmFileDragAndDrop is on
Dialog is shown after dropping
However, when "Do not display this dialog, next drop" is checked on the dialog, the dialog is not shown. Next, the dialog can be shown by dropping while pressing the Control (or Option) key.
When ConfirmFileDragAndDrop is off
When one file is dropped, the action is done without dialog displaying. The default action is Send File (Paste content of file).
When one or multiple folders are dropped, the action is done without dialog displaying. The default action is Paste Filename.
The dialog is shown other than these(multiple files/a file and folder). In this case, the dialog can be shown by dropping while pressing the Control (or Option) key.
Dialog
When the file and folder is dropped, the action can be determined.
SCP
The file is sent with SCP method.
Available on SSH connections when only files are dropped. The files are sent with the scp command, sharing the ssh connection in use.
dest
Specify the destination path.
The path is treated as home directory when dest is empty.
NOTICE: The "~" may not be used in some cases of remote OS and shell.
Send File (Paste content of file)
The file content is sent(pasted) into the terminal.
When the file is dropped, this menu can be selected with the file.
Binary
When this option is checked, the file content is transmitted as it is.
When this option is not checked, KANJI and new line code are converted.
Paste Filename
A file name and folder name is pasted.
Escape
When this option is checked, below processing is done.
  • " ;&()$!`'[]{}#^~" characters are escaped with "\".
Separator is Space
When multiple files are dropped, the file delimiter is space.
Separator is NewLine
When multiple files are dropped, the file delimiter is new line.
Do this for the next N files
When this option is checked, remaining files and folders are processed the same way.
Do same process, next drop
The dialog setting is recorded into memory, and then the setting is reused by using next action. When the dialog is shown, the dialog setting is update. Otherwise same action is done without confirmation. There are no configuration items and they are not saved file (TERATERM.INI).
The type of processing (SCP/Send File/Paste Filename) is recorded.
Do not display this dialog, next drop
When this option is checked, the dialog is not shown on next file dropping and the action is done without confirmation.
This option can be used when ConfirmFileDragAndDrop is off.
This option is a different setting from ConfirmFileDragAndDrop, and then the option can not be saved by using [Setup] Save Setup.
For example, when "Do same process, next drop" and SCP are selected, a folder is dropped. Next, when the action can not be done(needing confirmation) or when dropping while pressing the Control (or Option) key, the dialog is shown.
