Connecting through Proxy

This page describes Proxy connections in Tera Term Mac.

Prerequisite

Proxy is a technology which can be used to connect to outside where Internet environment and LAN are separated as shown in the following figure. However, a user may be not able to connect to the outside network because your gateway can not support the NAT.

There are various types of Proxy for this purpose. Tera Term Mac supports the following types of Proxy:

  • HTTP (*)
  • TELNET(for telnet)
  • SOCKS4 / SOCKS4a
  • SOCKS5

How to configure

Setup procedure

To configure, choose [Setup] Proxy....

The Proxy setup dialog appears. Choose the type of proxy in [Type], enter the host name (or IP address) of the Proxy server in [Hostname] and its port number in [Port number], then click [OK]. Fill in [Username] and [Password] only when the Proxy requires authentication.

Now you are ready - connect as usual.

Connection types and the Proxy

  • Telnet and Other (raw TCP) connections go through the Proxy directly from Tera Term Mac.
  • SSH connections use the macOS ssh command. When a Proxy is set, Tera Term Mac itself relays the connection as ssh's ProxyCommand. So TELNET proxies and SOCKS5 / HTTP proxies that need a user name and password also work.
  • Serial connections and the local shell do not use the Proxy.
  • The settings are read and written with the same names as the [TTProxy] section of TERATERM.INI.

Notice of HTTP proxy using

A user may be not able to connect the following type because basically the HTTP proxy server processes the HTTP request.

  • No HTTP and HTTPS.
  • Port number is not 80 and 443.
  • Port number is not 443 by using CONNECT method.

A use can not connect through the proxy to the TELNET and SSH server because these connections apply to above conditions.
