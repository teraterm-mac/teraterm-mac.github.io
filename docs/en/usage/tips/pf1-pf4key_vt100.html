PF1-PF4 keys of VT100

In the default setup (used when there is no KEYBOARD.CNF; the same as IBMKEYB.CNF), PF1-PF4 keys of VT100 are emulated by the F1-F4 keys. On Mac keyboards you may need to hold the fn key to press F1-F4 (or turn on "Use F1, F2, etc. keys as standard function keys" in the Keyboard pane of System Settings).

To change the assignment, edit the keyboard setup file KEYBOARD.CNF (see also Keyboard setup file). The following example assigns PF1-PF4 to the F1-F4 keys: 

[VT numeric keypad]
PF1=59
PF2=60
PF3=61
PF4=62
; Key codes for F1-F4 keys are 59-62.

[X function keys]
XF1=off
XF2=off
XF3=off
XF4=off
; XF1-XF4 items should be disabled, because
; key codes 59-62 can not be used twice in the setup file.

To use the top row of the numeric keypad instead (clear, =, /, * on a Mac keypad), the key codes are 325 for clear (Num Lock), 309 for / and 55 for *.
