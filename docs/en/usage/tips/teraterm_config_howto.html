How to configure Tera Term

You can use commands in the [Setup] menu for most settings in Tera Term Mac. [Setup] Terminal... (⌘,) opens a window with tabs for all settings.
Tera Term Mac saves changed settings automatically in the app's preferences and uses them the next time it starts.

The setup file (TERATERM.INI) can be written with [Setup] Save setup... and read with [Setup] Restore setup.... The default file is TERATERM.INI in the settings folder (~/Library/Application Support/Tera Term Mac). A TERATERM.INI from Windows Tera Term can be read too; items for features that Tera Term Mac does not have are skipped.

You can modify key assignments by editing the keyboard setup file (KEYBOARD.CNF in the settings folder).
See also Keycode.

[Setup] Setup directory... lists where the setup files are, and can show them in Finder.
