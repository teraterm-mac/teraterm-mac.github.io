Telnet port number

On the command line, or on the [File] New connection dialog box, you can specify the TCP port number (<TCP port#>) and telnet flag (<telnet flag>) for a TCP/IP connection. If these parameters are omitted in the command line, the default values are taken from the settings.

Only if <telnet flag> is 1 (on) and <TCP port#> is 23, Tera Term Mac starts spontaneously sending telnet commands to the host for the option negotiation when the TCP/IP connection is established.

If <telnet flag> is 1 (on), Tera Term Mac responds to telnet commands sent by the host whatever <TCP port#> is. If <telnet flag> is 0 (off; raw TCP with /T=0), received data is used as is.

Terminal setup for non-telnet TCP/IP connection

For a non-telnet TCP/IP connection (usually with a port other than 23), you may need to set the "local echo" option on, and the "new-line (transmit)" option to CR+LF.

Change local echo and new-line (transmit) in [Setup] Terminal....
