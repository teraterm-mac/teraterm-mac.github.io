Numeric keypad

In the default setup, Tera Term emulates VT100 keyboard. Therefore some numeric keys do not work like them in other applications. For example, the "Num Lock" key does not work as "Num Lock". To disable the emulation and use numeric keys in normal way, edit the keyboard setup file KEYBOARD.CNF to disable every items in the [VT numeric keypad] section by using the word "off", like the following (see also Keyboard setup file):

KEYBOARD.CNF lives in the settings folder (~/Library/Application Support/Tera Term Mac). If the file does not exist, the standard assignments (the same as IBMKEYB.CNF) are used. Changes to the file take effect at the next key press. To use a file in another location, choose it with [Setup] Load key map....

Mac keypad keys are mapped by their labels: the clear key acts as Num Lock, and the = key is the keypad =. On keyboards without a numeric keypad, such as MacBook keyboards, this setting does not matter.
