Log and replay functions

You can save the host data to the file if you use Tera Term logging function.

Log to the file

You can log characters received from the host. Execute the [File] Log... command to start logging.

Do in the following commands:

  1. Do [File] Log... command.
  2. The "Log" dialog box will be shown.

    Input the saving file name to the log file name field. You can also choose it with the "..." button or drop a file from Finder. If you enter only a file name, the file is saved in your home folder.
    All host data will be written to the file if you select `Binary'.
    KANJI, CR and LF codes are converted, and written to the file if you select `Text'. However, the escape sequences are not written to the file.
    The host data will be appended to the file if you select `Append'.
    The host data will overwrite the file if you select `New/Overwrite'.
    Turn on `Timestamp' to add the time to each line.

  3. Push OK button, and logging will start. If the logging dialog option is set to show the dialog, a small window showing the logging status opens. You can use Tera Term Mac normally while logging, except for some functions.
  4. Push Close or Pause button on the logging dialog box if you finish the logging or temporarily stop. Pause button will change into Start button if you push Pause button; push it to restart logging. [File] Pause Logging and [File] Stop Logging do the same. If you closed the dialog, [File] Show Logging dialog... opens it again.

You can read the saved file with an editor such as TextEdit, or with [File] View Log. To browse log files which contain escape sequences, it is convenient to use the replay function.

Replay the log file

Choose [File] Replay Log... and select a log file recorded in binary mode. A new window opens, and the contents of the log file are displayed as if the characters were received from the host. We call this function 'replay log'.
