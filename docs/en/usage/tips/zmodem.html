Tips on ZMODEM

The ZMODEM protocol implemented in Tera Term does not support 7 bit communication lines.

For serial port:

Set the appropriate parameters in the [Setup] Serial port... dialog box. Data must be 8 bit.

For telnet:

If file transfers fail, try to escape all control characters. If that does not work, try connecting to the host with the binary option.
To connect with the binary option:

  • Specify the /B option on the command line or after the host name in [File] New connection, or
  • Edit the setup file.
    -> Telnet binary option

If file transfers still fail, please check that you have correctly configured and used the ZMODEM command on the host side.
After confirming the above, please report it on GitHub Issues of Tera Term Mac.
Start a ZMODEM transfer from [File] Transfer > ZMODEM.

Additionally, the following settings are also possible.
Setup items for ZMODEM:

  • Auto activation of ZMODEM Receive
  • ZMODEM parameters for sending

Reference: Transfer the file via the intermediate server

Communication software

The ZMODEM file transfer will work well for the lrzsz package on the Red Hat Linux(e.g., Fedora, CentOS). The transfer may not work well for the zmtx-zmrx package.
On a Mac, lrzsz can be installed with Homebrew and similar tools (brew install lrzsz).

Modem communication program

  • lrzsz
  • zmtx-zmrx
