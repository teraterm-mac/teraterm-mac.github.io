Local shell connection

A local shell connection runs the shell of this Mac (zsh etc.) in a Tera Term Mac window.

  • Choose [File] Local Shell Connection or press ⌘G to open a shell in a new window.
  • You can also choose "Local shell (Terminal on this Mac)" in the New connection dialog.
  • Menu ID 50112 used with the callmenu macro command opens a local shell connection.

Settings

Settings are made on the Local Shell tab of [Setup] Additional settings.... They apply to shells opened afterwards.

SHELL
The shell to run. When empty, the shell in the SHELL environment variable (or /bin/zsh) is used.
TERM
The value of the TERM environment variable. The default is xterm-256color.
ENV_1, ENV_2
Additional environment variables in "name=value" form.
LOGIN_SHELL
Starts the shell as a login shell.
HOME_CHDIR
Starts in the home directory.
