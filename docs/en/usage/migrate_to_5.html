Migrating from Windows Tera Term to Tera Term Mac

Setup files, connection lists and macros used with Windows Tera Term (4 or 5) can be brought to Tera Term Mac.

Setup files

  • The setup folder of Tera Term Mac is ~/Library/Application Support/Tera Term Mac.
    • cf. About folders
    • [Setup] Setup directory... shows where TERATERM.INI and KEYBOARD.CNF are.
    • Regular settings are also stored in the macOS preferences (~/Library/Preferences/net.satoru.teramac.plist).
  • TERATERM.INI
    • Load the TERATERM.INI of Windows Tera Term with [Setup] Restore setup.... UTF-16 (with BOM), UTF-8 and Shift_JIS files can all be read.
    • Terminal size, character encoding, new-line, colors, font, serial port, SSH, Proxy and other settings are applied. Settings that do not exist on the Mac are skipped.
    • For a font that is not available on the Mac (such as Lucida Console), only the size is applied. Choose the font again with [Setup] Font....
    • COM port numbers cannot be used on the Mac. Choose a /dev/cu.* port in the connection dialog.
    • You can also write the settings to TERATERM.INI with [Setup] Save setup....
  • KEYBOARD.CNF
    • Copy the KEYBOARD.CNF of Windows Tera Term to the setup folder and it is used as is. Files in other places can be loaded with [Setup] Load key map....
  • TeraTerm Menu connection list (ttpmenu.ini)
    • Click "Import..." in the TeraTerm Menu list editor and choose the ttpmenu.ini of Windows. cf. TeraTerm Menu
    • If Windows TeraTerm Menu stores its settings in the registry, export them to ttpmenu.ini first with the conversion script.

Macro files

  • Most macro files (.ttl) written for Windows run as they are. For the changes made for the Mac, see the macro pages.
  • UTF-8 is recommended as the character encoding of macro files (extension ttl).
  • When a ttl file is loaded, its encoding (UTF-8 / UTF-16 with BOM / Shift_JIS) is detected automatically and converted to UTF-8. The detection may be wrong.
    With a BOM, the file is always read as UTF-8.
  • The maximum length of a string variable is 511 bytes.
  • String literals in ttl files and strings assigned to string variables are UTF-8. Take care with macros written for Tera Term 4 that assume Shift_JIS (CP932).
  • Kanji and other characters take more bytes (for example "あ" changes from 0x82,0xa0 to 0xe3,0x81,0x82), so data that fit in Tera Term 4 may be cut off.
  • Lengths and positions (index, pos) in string commands are in bytes.
    Because the internal encoding is UTF-8, the values differ from Tera Term 4.
  • Write file paths the Mac way (/Users/... or ~/...). A Windows path such as c:\work\a.txt is handled by reading \ as / and dropping the drive name.
  • Opening a macro file with Tera Term Mac (for example by double-clicking it in the Finder) runs the macro.

Plugins

  • Windows plugins (.dll) cannot be used. Proxy connections (TTProxy) and the [KanjiCode] menu (TTXKanjiMenu) are built into Tera Term Mac. For SSH, the macOS ssh command is used instead of TTSSH.
