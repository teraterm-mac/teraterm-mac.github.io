TeraTerm Menu Tutorial

1. About TeraTerm Menu

TeraTerm Menu is a launcher tool that connects to registered hosts with one click (originally written by S.Hayakawa, maintained by TeraTerm Project).

TeraTerm Menu is built into Tera Term Mac; no separate application is needed. When you choose a host, Tera Term Mac connects in a new window. User names and passwords are never passed on a command line.

2. Where the settings are stored

The connection list is stored in the macOS preferences (net.satoru.teramac), and the passwords, encrypted, in the macOS keychain.

The "Import..." and "Export..." buttons at the bottom left of the list editor read and write ttpmenu.ini.

  • Import: reads hosts and passwords from a Windows ttpmenu.ini (UTF-16 / UTF-8 / Shift_JIS, including the format written from the registry by the conversion script). Passwords encrypted with LockBox cannot be read; enter them again.
  • Export: writes a file that Windows TeraTerm Menu can read as is (UTF-16, CRLF). You can choose whether to export the passwords too (they use a weak encryption, so handle the file with care).

3. How to launch

When Tera Term Mac starts, the list editor opens first (when started with a host name or /M=, it connects directly).
TeraTerm Menu lives in the Tera Term icon in the menu bar. It stays there even after all windows are closed.

  • Left click: shows the list of registered hosts. Choose one to connect in a new window.
  • Right click: List Configuration / showing large icon / specifying font / showing list by left-click / Show List with Hotkey (⌃⌥M) / Open Tera Term Mac at Login / Version / Run (New Connection) / Quit
  • The hotkey ⌃⌥M shows the list at the mouse position.
  • The list is also available from the right-click menu of the Tera Term Mac icon in the Dock. The list editor also opens from "Edit TeraTerm Menu List..." in the application menu.
  • To quit, choose "Quit" from the right-click menu of the menu bar icon, or press ⌘Q.

4. Configuration

At first no hosts are registered, so start by creating the list in the list editor. Fill in the items on the right and click "Save"; the entry is added to the list on the left (an entry with the same name is overwritten). You can also sort entries into folders with right click or drag and drop in the list.

Name / Host Name
The host name can include a port number in the form "hostname:port".
autologin
Specify the user name, password, "use SSH" and key file. Check "use SSH" for SSH connections. For public key authentication, set the private key file in Keyfile. For Telnet, the user name and password are sent after waiting for the prompts.
specified macro file
Runs a TTL macro after connecting.
launch only
Only connects.
details
Specify the log file (%Y%m%d etc. insert the date and time), the user name prompt, the password prompt and options.
Options use the Tera Term command line syntax. For example, "/KT=UTF8 /KR=UTF8" sets the character encoding, "/C= /BAUD=" makes a serial connection and "/T=0" makes a raw TCP connection.
kick at starting
Connects automatically when Tera Term Mac starts.

Once the list is ready, left-click the menu bar icon to show the list and connect right away.

If you want to keep the connection list when uninstalling, save it to ttpmenu.ini with "Export..." first.

5. Contact

For TeraTerm Menu in Tera Term Mac, please use the GitHub Issues of Tera Term Mac (not the TeraTerm Project).
