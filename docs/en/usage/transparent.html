Change look and feel

You can change the look and feel of Tera Term Mac by using transparent window and theme. Transparent window and theme can be used at the same time.

  • (1) Transparent window
  • (2) Theme
    • (2)-1 Theme/BG
      • Use desktop image
      • Use background image
      • Use background image and desktop image
    • (2)-2 Theme/Color

(1) Transparent window

The Tera Term Mac window can be made transparent.
Use "Window opacity" on the Visual tab of [Setup] Additional settings....
Opacity is a value from 0 to 255. Smaller values are more transparent; 255 is opaque and is the default. Tera Term Mac treats values below 16 as 16. Opacity can be specified separately for the active and inactive windows.

(2) Theme

A theme changes the background image and text colors at once.

Theme settings are made in [Setup] Theme... (the Theme tab of Additional settings). Theme files (.ini) can be loaded, including those written for Windows Tera Term. You can also pick one of the bundled themes.
On the same tab, Tera Term Mac also offers its own color schemes (Dark, Solarized, etc.) and the color schemes of the standard Terminal app (Terminal.app) profiles.
Edit theme files with a text editor.

(2)-1 Theme/BG (background)

Tera Term Mac can display the desktop picture or a specified image as the background. The desktop picture and the specified image can be blended.

Use desktop image

Displays the desktop picture of the screen the window is on as the background of Tera Term Mac.

Use background image

Displays a specified image as the background of Tera Term Mac. Images with alpha channel can also be used.

Use background and desktop images

Displays a blend of the desktop picture and the specified image as the background of Tera Term Mac.

(2)-2 Theme/Color (character and background)

A color theme changes the text and background colors at once.
