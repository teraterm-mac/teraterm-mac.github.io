Keyboard

Some keyboard settings can be made in [Setup] Keyboard....

You can freely change key assignments by editing the keyboard setup file (KEYBOARD.CNF). Tera Term Mac reads KEYBOARD.CNF from the setup folder (~/Library/Application Support/Tera Term Mac). A KEYBOARD.CNF used with Windows Tera Term can be used as is. For details, see Keyboard setup file overview.

Mac keys are treated as the PC key at the same position or with the same label. Home / End / PageUp / PageDown, which Mac keyboards lack, are fn+Left/Right/Up/Down, and the clear key on the numeric keypad is NumLock.

Shortcut keys

VT window

Shortcut keys use ⌘ (Command key). Every key combination with ⌘ is a menu shortcut and is never sent to the host.
Hint: "User shortcut key"

⌘B
Sends a break signal (serial and Telnet connections; a break cannot be sent over SSH).
⌘C, Ctrl+Insert
Copies the text selected with the mouse to the clipboard. When AutoTextCopy is enabled, the text is already copied when you select it.
⌘D
Duplicates the session.
⌘G
Opens a local shell connection (the shell of this Mac) in a new window.
⌘I
Disconnects.
⌘N
Connects to a new host or serial port.
⌘P
Prints the current screen or the text selected with the mouse.
⌘W
Closes this window.
⌘Q
Quits Tera Term Mac. If some windows are connected, you are asked to confirm.
⌘R
Sends the text in the clipboard to the host, followed by a new-line.
⌘T
Sends the Telnet AYT (Are You There) command. The host usually answers with some message. Available only for Telnet connections.
⌘V, Shift+Insert
Sends the text in the clipboard to the host. A right click does the same. If DisablePasteMouseMButton is off, a middle-button click does the same too.
⌘A
Selects the whole buffer.
⌘,
Opens the terminal setup.
Ctrl+Tab, Ctrl+Shift+Tab
Switches between Tera Term Mac windows. The Mac's ⌘` also works. For windows grouped as tabs, ⌘⇧[ / ⌘⇧] moves to the previous / next tab.
Ctrl+Up/Down cursor
Scrolls up/down by one line (not available if macOS assigns these keys to Mission Control etc.).
Ctrl+PageUp/PageDown, Shift+PageUp/PageDown
Scrolls up/down by one page. On a Mac keyboard, fn+Up/Down are PageUp/PageDown.
Ctrl+Home
Moves to the top of the buffer.
Ctrl+End
Moves to the bottom of the buffer.
Option+F / E / S / O / W / K / H
When the in-window menu bar is shown, opens the [File] [Edit] [Setup] [Control] [Window] [KanjiCode] [Help] menus. Not available when the Option key is used as the Meta key.
F1 key
Same as the Num pad NumLock key.
F2 key
Same as the Num pad '/' key.
F3 key
Same as the Num pad '*' key.
F4 key
Same as the Num pad '-' key.

Depending on the macOS settings, function keys such as F1 must be pressed together with the fn key.

TEK window

Shortcut keys in the TEK window use the Option key.

Option+C
Copies the image of the area selected with the mouse to the clipboard.
Option+O
Moves to the VT window.
Option+P
Prints the whole screen or the area selected with the mouse.
Option+Q
Closes the TEK window.
Option+R
Same as ⌘R in the VT window.
Option+V
Same as ⌘V in the VT window.

Meta key

When Meta key is selected in [Setup] Keyboard..., the Option key works as the Meta key in the VT window. For example, pressing Option+A sends ESC A. You can also use only the left or right Option key as the Meta key (left / right).
The ⌘ shortcut keys keep working while the Meta key is enabled.
