Language file

The messages of the menus and dialogs are in the language files. The language files are bundled in the app, in Tera Term Mac.app/Contents/Resources/lang. Messages added in Tera Term Mac are in mac_<language>.lng in the same folder.
Choose the language in the "UI" tab of [Setup]-[Additional settings...]. "Auto" follows the macOS language setting.
You cannot add your own language files. Dialogs use the standard macOS font.
