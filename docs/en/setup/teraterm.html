Tera Term setup file

Tera Term Mac keeps its settings in the macOS preferences. Changes made in the setup dialogs are saved automatically and are used again at the next launch.

The setup file TERATERM.INI is read when the [Setup]-[Restore setup...] command is executed; its contents are applied to the current window and saved in the preferences. A TERATERM.INI made with Tera Term on Windows can be read as is.
To write the current setup into a setup file, execute the [Setup]-[Save setup...] command. The default file is ~/Library/Application Support/Tera Term Mac/TERATERM.INI.

The setup file is written as UTF-16 (with LE BOM). When reading, UTF-16, UTF-8 and Shift_JIS are detected automatically.

For details, see "How Tera Term Mac uses this file".

Special options in the Tera Term setup file

You need to edit the Tera Term setup file directly to change the following setup items. Edit TERATERM.INI and then read it with [Setup]-[Restore setup...]. The file transfer items are read directly from the TERATERM.INI that was last restored or saved.

Terminal emulation

  • The motion receiving BEL character
  • Mouse code in TEK GIN report
  • Mapping of Unicode to DEC special character
  • Flash time when Beep is Visual Bell

Window

  • Disabling auto text copying
  • Nonblinking cursor
  • Disabling text selection when the window is activated by mouse
  • Title format
  • Space between characters (lines)

Communication

  • Disabling the warning on TCP/IP disconnection
  • Telnet binary option
  • Pause time while the break signal is sending to the serial port
  • Automatic COM port Reconnection

  • Escaping all control characters in the B-Plus protocol
  • B-Plus log
  • Kermit log
  • XMODEM log
  • Receive command for XMODEM
  • Timeout settings for XMODEM
  • YMODEM log
  • Timeout settings for YMODEM
  • Auto activation of ZMODEM Receive / Send
  • Parameters for ZMODEM sending
  • Escaping all control characters in the ZMODEM protocol
  • ZMODEM log
  • Receive command for ZMODEM
  • Timeout settings for ZMODEM
  • File name filter for send file dialog
  • File name filter for receive file dialog
  • Confirmation of File Transfer by Drag & Drop
  • File Transfer Dialog is hidden
  • High Speed File Transfer on Serial Connection
  • Skip Send file dialog
  • Skip Receive file dialog

Printing

Miscellaneous
