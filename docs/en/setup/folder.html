The app and uninstalling

  • The app is /Applications/Tera Term Mac.app. When it is started from a disk image or the Downloads folder, it offers to move itself to the Applications folder.
  • The bundled TERATERM.INI, language files, themes and help are in Tera Term Mac.app/Contents/Resources. The settings at the first launch are made from the bundled TERATERM.INI.
  • The uninstall menu item removes the app and the preferences (including the connection list). The setup files folder is kept; delete it in the Finder if you no longer need it.

If a file name is specified

Another TERATERM.INI or KEYBOARD.CNF can be chosen from the menu.

  • TERATERM.INI: the file chosen in [Setup]-[Save setup...] or [Setup]-[Restore setup...] becomes the default from then on.
  • KEYBOARD.CNF: the file chosen in [Setup]-[Load key map...] keeps being used.

When setup files do not exist

  • The setup files folder is created if it does not exist.
  • When there is no KEYBOARD.CNF, the standard key settings (the same as IBMKEYB.CNF) are used. No file is copied.
