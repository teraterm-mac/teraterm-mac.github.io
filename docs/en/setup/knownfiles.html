TTSSH known_hosts file

SSH in Tera Term Mac is the macOS ssh command (OpenSSH), so the OpenSSH known_hosts file is used. The default is ~/.ssh/known_hosts (a KnownHostsFiles value of ssh_known_hosts in a TERATERM.INI made on Windows is also treated as this file). The format is the OpenSSH known_hosts format, and hashed host names can be used.

The synopsis of 'known_hosts' file is as follows: 

  SYNOPSIS:
    hostname key-type host-public-key
    
    #  comment
    !  negate

   EXAMPLE:
    192.168.1.2 ssh-rsa AAAAB3NzaC1...nXIDE=
    192.168.1.2 ssh-dss AAAAB3NzaC1...nXIDE=
    #192.168.1.3 ssh-rsa AAAAB3NzaC1...nXIDE=
    *.example.com,!mail.example.com ssh-rsa AAAAB3NzaC1...nXIDE=
