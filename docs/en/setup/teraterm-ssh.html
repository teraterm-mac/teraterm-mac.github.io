Log Level

Specifies whether the SSH connection is logged to the TTSSH.LOG file, and how much is logged. 

LogLevel=<Value>

SSH connections use the macOS ssh command. When the value is not 0, it is turned into an ssh LogLevel, and the log is written with ssh -E to TTSSH.LOG in the setup folder (~/Library/Application Support/Tera Term Mac).

Value ssh LogLevel
0 (no log)
1-24 INFO
25-49 VERBOSE
50-74 DEBUG1
75-99 DEBUG2
100 or moreDEBUG3 
Default:
LogLevel=0
