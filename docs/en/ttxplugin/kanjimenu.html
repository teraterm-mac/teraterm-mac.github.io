[KanjiCode] menu

The [KanjiCode] menu switches the sending/receiving character code quickly.
Menu display character code for Japanese or Korean environment selected in settings. Sending/receiving character code and Ambiguous Character Width can be changed using menus.

Ambiguous Character Width is disabled when the character code is not UTF-8.

When the menu content is Auto, it is chosen from the preferred macOS language (Korean gives the Korean menu; anything else gives the Japanese menu).

The setting dialog of the [KanjiCode] menu is opened by selecting [Setting] from the menu.
