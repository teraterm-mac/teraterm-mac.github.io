TTProxy command line

Format

The following parameters specify the proxy (TTProxy). They can be used on the startup command line (for the first window opened at launch) and with the connect macro command. For SSH connections, ssh connects through this proxy. 

-proxy=protocol://<user<:password>@>proxyserver:proxyport
protocol://<user<:password>@>proxyserver:proxyport/realhost
-noproxy
protocol
Proxy type
Supported proxy types are following:
  • http
  • telnet
  • socks4
  • socks5
  • none
proxyserver
Proxy server host
proxyport
Proxy server port
realhost
Server host that you want to connect
user
User name for proxy authentication
password
Password for proxy authentication
-noproxy
Disable proxy setting. Same as "-proxy=none://"

Example

open -a "Tera Term Mac" --args -proxy=socks5://user:pass@proxy:1080 sshserver /ssh
open -a "Tera Term Mac" --args -proxy=telnet://proxy:8023 telnetserver:23 /nossh
open -a "Tera Term Mac" --args -proxy=none:// sshserver /ssh
open -a "Tera Term Mac" --args -noproxy sshserver /ssh

Note

The following style is invalid. 

protocol://<user<:password>@>proxyserver:proxyport/realhost:portnumber

The following style isn't supported. This style conflicts with Tera Term parameter style "telnet://server<:port>". 

protocol://<user<:password>@>proxyserver:proxyport
