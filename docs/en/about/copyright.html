License and Copyright

Tera Term Mac

Tera Term Mac is a port of Tera Term to macOS. It is the Mac edition of Tera Term, approved by its original author, T. Teranishi. It is developed by a separate team from TeraTerm Project, which develops the Windows version.

The code newly written for Tera Term Mac is licensed under the MIT License. The parts derived from Tera Term (the icon, the TTL macro engine and the file transfer protocols) remain under the original Tera Term license (3-clause BSD license). The full license text is also available from [Tera Term Mac] > [Acknowledgements and Licenses…] in the menu.

Used by Tera Term Mac

  • Tera Term ... the icon, the TTL macro engine and the file transfer protocols (XMODEM / YMODEM / ZMODEM / Kermit / B-Plus / Quick-VAN). 3-clause BSD license
  • Oniguruma 6.9.10 ... regular expressions in TTL macros. 2-clause BSD license
  • Sparkle 2.9 ... automatic updates. MIT License (Copyright (c) 2006-2013 Andy Matuschak and the Sparkle developers)
  • OpenSSH ... SSH connections. Not included in the app; the ssh command that comes with macOS is used.
