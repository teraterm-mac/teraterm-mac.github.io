Features only in the Mac version

Tera Term Mac aims to behave like Tera Term for Windows. On top of that, it adds the following to make it fit the Mac.

Tabs and split panes (TTMado)

  • Connections can be grouped as macOS tabs (the Windows version uses one window per connection).
  • Drag tabs or windows to show them side by side or top and bottom inside one window. Nested splits, reordering, extending to an edge, returning to a tab and merging windows are supported.
  • Each pane has a header (× to close, drag to move, right-click for a menu), and the window shows a badge with the number of panes.
  • In a split window, [New connection], [Duplicate session] and [Local Shell Connection] let you choose: in this window, in a tab, or in a new window.
  • It is a built-in plugin: turn it on or off at any time in [Setup] > [Additional settings...] > [Plugins].
  • See Show several sessions in one window.

Working with the Mac

  • Local shell connection: instead of the Cygwin connection of the Windows version, opens this Mac's shell (the same as Terminal.app).
  • Keychain: passwords saved in TeraTerm Menu are stored in the Mac keychain.
  • Menu bar and Dock: connect to saved hosts from the icon in the menu bar at the top of the screen, or by right-clicking the Dock icon.
  • Menu bar switch: show the Windows-style menus inside the window, or use only the Mac menu bar at the top of the screen.
  • Dark Mode and Retina: follows the macOS appearance and high-resolution displays.

Languages

  • The interface can be shown in 14 languages. At first it follows the macOS language setting; change it in the "UI" tab of [Setup].

Updates and uninstalling

  • Automatic updates: tells you when a new version is out, shows what changed, and updates in place.
  • Uninstaller: removes the app together with its settings.

Help

  • Mac manual: the original Tera Term manual, reorganized for the Mac version, with chapters, search and previous/next links.
  • Quick guide: a beginner's guide with screenshots.
  • Original manual: the original Windows manual can be shown from the help window too.
  • Send feedback: tell the developer anonymously what you noticed.

For what the Mac version cannot do or does differently, see Differences from the Windows version.
