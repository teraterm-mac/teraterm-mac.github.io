Requests

This page summarizes requests frequently asked by users.(In other words, this list is not implemented items.)
When your question cannot be resolved by referring to help (MACRO Help), please contact us.

Please send requests for Tera Term Mac to the Tera Term Mac Issues.

Items already available are marked Done, and partly available ones Partly done.

Items which may be supported in future

  • Blinking and double height/width characters of VT100.
  • Faint, italic, rapid blinking, invisible and strike out characters of ECMA-48 terminal.Partly done (faint, italic, invisible, strikethrough)
  • VT3XX line drawing between characters (lines).
  • Tool bar and status bar.
  • Dialer.
  • GUI tool to configure the keyboard.
  • Customizing menus and dialog boxes.
  • Word search.
  • Screen buffer and scroll bar for TEK window.
  • Improving resolution of TEK window printing.
  • In file transfers, displaying a progress bar, time to finish and the transfer speed.Done
  • ZMODEM recovery function.
  • [File] Print setup commandPartly done (paper size and orientation in the Print dialog)
  • Saving selected text or text in the scroll buffer to a file.
  • Selecting the text/background color by using color pallets.Done (macOS color picker)
  • Switching to a small font when the screen mode is switched to the 132-column mode.
  • SFTP(SSH File Transfer Protocol)
  • OpenSSH: ProxyCommandDone (~/.ssh/config works as is)
  • Color EmojiDone

Items which may be supported in future (MACRO related items)

  • Array variables.Done
  • Supporting the redirection by the "exec" command.Done (runs via /bin/sh -c, so > and | work)
  • Waiting for binary data by the "wait" command.
  • Connect to Tera Term that is already running.

Items which may be supported in very far future

  • TEK41XX and 42XX emulations
  • Televideo and Wyse emulations
  • TN3270
  • Sharing a serial port with other applications at the same time.
  • Line input mode and a window for line input.
  • Improving the speed of Kermit transfer.Done
  • Proportional fonts.
  • ANSI/AVATAR
  • ReGIS
  • Sixel
  • Direct communication I/O from MACRO.
  • Mouse protocol(NetTerm) except xterm and DEC Locator mode.
