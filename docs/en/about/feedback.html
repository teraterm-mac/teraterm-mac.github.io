Send feedback

You can tell the developer anonymously about anything you noticed or would like to see.
There is no reply, but your message helps improve the app.

Send Feedback…

How to send

  1. Click the button above, or choose [Help] > [Send Feedback…].
  2. Choose a type (request, bug or other).
  3. Write your message and click [Send].

What is sent

  • Only the type you chose and your message. No name or email address.
  • If "Include app and macOS versions" is checked, the Tera Term Mac and macOS versions, the Mac type (Apple Silicon / Intel) and the UI language are sent too.
  • Messages go to a Google Form. Google receives the IP address of your Mac.
  • Please don't write passwords, host names or other private information.

If you want a reply or a discussion, use the contacts (GitHub Issues).
