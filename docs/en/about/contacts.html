Tera Term Mac

Tera Term Mac is the Mac edition of Tera Term, approved by its original author, T. Teranishi. It is developed by a separate team from TeraTerm Project, which develops the Windows version. Please report bugs and requests for Tera Term Mac to the Issues below.

  • Tera Term Mac (https://github.com/teraterm-mac/teraterm-mac)
    • Issues (Bug/Request)
      Please register a bug or a request as an issue. A GitHub account is required.
      For a bug, the following information helps us fix it faster:
      • The Tera Term Mac version (shown in "About Tera Term Mac")
      • The macOS version and your Mac (Apple Silicon / Intel)
      • The connection type (serial, SSH, Telnet, local shell) and the destination
      • How to reproduce it, and how often it happens
      • A log or a screenshot of the problem
    • Downloads and release notes (Releases)

Tera Term (TeraTerm Project)

Tera Term, on which Tera Term Mac is based, is developed by the TeraTerm Project. Please do not ask the TeraTerm Project about Tera Term Mac.
