Requirements

Supported macOS versions:

  • macOS 11 Big Sur or later

Available architectures:

  • Apple Silicon (arm64): Runs natively.
  • Intel (x86_64): Runs natively.

The app is a universal binary that contains both architectures. Rosetta is not required.
SSH connections use OpenSSH (/usr/bin/ssh), which comes with macOS. Nothing else needs to be installed.

Installation

  1. Download TeraTermMac-<version>.dmg from Releases and open it.
  2. Drag the "Tera Term Mac" icon to the "Applications" folder on the right.

Tera Term Mac is notarized by Apple, so it starts without a Gatekeeper warning.
If you start it directly from the disk image or the Downloads folder, it asks whether to move it to the Applications folder. Click "Move" to copy it there and restart it.

Updates

Tera Term Mac supports automatic updates with Sparkle.
Once a day it checks GitHub for a new version and, if there is one, asks whether to install it. It never replaces the app without asking.

  • Check at any time with [Tera Term Mac] > [Check for Updates...].
  • Uncheck [Tera Term Mac] > [Automatically Check for Updates] to stop all update traffic unless you check yourself.
  • No information about your Mac is sent when checking for updates.

For the changes in each version, see Releases (also available from "Release Notes" in "About Tera Term Mac").

Uninstallation

Use [Tera Term Mac] > [Uninstall Tera Term Mac…]. This menu item is shown only when the app is installed in the Applications folder. See "Uninstallation" for details.
