LIST OF MENU IDs

Menu IDs are used in [User keys] (Control flag 3) of the keyboard setup file and with the callmenu macro command. The IDs in the table below can be used; for other IDs, the message "callmenu (ID) is not supported" is shown.

  • 50112 (Cygwin connection) opens a local shell connection.
  • 50123 (Show Log dialog) shows the log file in the Finder.
  • 50360 opens the New connection dialog. 50380 (Save setup) saves the current settings in the preferences.
