For developers (Mac version)

This page is about developing Tera Term Mac. For development of the original Tera Term (Windows), see For developers (Windows Tera Term).

  • Source layout (this page)
  • Build, test and release
  • UI languages and help

Repository

The source is at https://github.com/teraterm-mac/teraterm-mac. The repository is a fork of TeraTermProject/teraterm, and all of the Mac source lives in the macos/ folder. Everything outside macos/ is a copy of the upstream source. Changes made there do not go upstream; if you want to fix upstream Tera Term, send the change to the TeraTerm Project.

Tera Term Mac is developed by a separate team from TeraTerm Project (which develops the Windows version). Please send bug reports, requests and pull requests to this repository's Issues / Discussions / Pull Requests, not to TeraTerm Project (see also CONTRIBUTING.md in the repository).

Swift package layout

macos/Package.swift is a Swift Package Manager package (swift-tools-version 5.5, macOS 11 or later). There is no Xcode project file. The targets are:

TargetLocationContents
TeraCoreSources/TeraCoreTerminal emulator, character encodings, character widths, TTL macros, file transfer, reading and writing settings files. Does not depend on AppKit (this is what the tests cover)
TeraMacSources/TeraMacThe application (executable TeraMac): AppKit windows, menus, dialogs, connections, help and automatic updates
CTeraFileSources/CTeraFileCompiles upstream teraterm/ttpfile C sources (XMODEM / YMODEM / ZMODEM / Kermit / B-Plus / Quick-VAN / raw) as they are. glue/ and compat/ stand in for the Windows APIs
COnigurumaSources/COnigurumaThe Oniguruma regular expression library (6.9.10), the same one Tera Term macros use
TeraUninstallSources/TeraUninstallUninstaller (removes the application, settings and connection list, and passwords saved in the keychain)
TeraCoreTestsTests/TeraCoreTestsTests for TeraCore (XCTest)

The only external package is Sparkle for automatic updates. It is pinned to 2.9.x because Sparkle 2.10 requires macOS 12 or later.

Relation to upstream

Upstream Tera Term is written with the Win32 API, so it does not run on the Mac as is. Tera Term Mac is a rewrite in Swift / AppKit that follows upstream behavior.

  • Upstream source used as is: the file transfer protocols (C sources of teraterm/ttpfile copied into CTeraFile) and Oniguruma
  • Upstream files used at build time: installer/release/TERATERM.INI (default settings), installer/release/lang_utf8/*.lng (UI languages), installer/release/theme (sample themes), teraterm/common/helpid.h (help IDs). scripts/bundle.sh copies them into the app
  • Generated from upstream files: the character width tables and single-byte code tables (generators)
  • Ported to Swift: TTL macros (ttpmacro), TEK, logging, command line, key maps, the TTProxy handshake and more. The comment at the top of each source file names the upstream file or function it is based on
  • Rewritten for the Mac: windows, menus and dialogs; connections (SSH uses macOS's OpenSSH instead of TTSSH); settings storage (UserDefaults); password storage (keychain)
  • Help: based on upstream doc/ja and doc/en, rewritten for the Mac, in macos/Resources/help-mac

What the macro interpreter matches with upstream and what was changed for the Mac is listed in macos/docs/マクロ互換性.md (in Japanese) in the repository. Where behavior differs between operating systems, Tera Term Mac follows the macOS way rather than the Windows way.
