SSH Authentication ([Setup] メニュー)

"TTSSH: Authentication Setup" ダイアログボックス

ここで設定した内容は、新しい接続ダイアログのユーザー名と秘密鍵の初期値、および ssh に渡す認証方式の順序 (PreferredAuthentications) になります。 認証そのものは OpenSSH (/usr/bin/ssh) が行います。

User name
ユーザ名の指定がないときに使用するユーザ名を指定します。
Do not enter username
入力しません。
Use default username
選択するとデフォルトユーザ名を使用します。
デフォルトユーザ名はエディットボックスで設定します。 デフォルトユーザ名が空の場合は何も入力されません。
Use logon username
Mac にログインしているユーザ名を使用します。
デフォルトで使用する認証方法を設定します。
Use plain password to log in
パスワード認証を用いる場合に指定します。ssh の標準の順序のまま接続します (公開鍵が使えなければパスワードを聞かれます)。
Use RSA/DSA/ECDSA/ED25519 key to login
あらかじめ作成した RSA/DSA/ECDSA/ED25519 鍵を用いた認証方法を選択します。公開鍵認証を先に試します。
Private key file
秘密鍵ファイルを指定します ([Private key...] ボタンで選べます)。ssh の -i オプションで渡します。
OpenSSH が読める形式の鍵を指定してください。PuTTY 形式 (.ppk) の鍵は使えません。
SSH2:Use keyboard-interactive to log in
キーボード・インタラクティブ認証を用いる場合に指定します。 パスワード認証を無効に設定したサーバへ、パスワードを使ってログインする場合は、 この認証方式を使います。
この認証方式では、入力した内容が暗号化された状態でサーバへ送られます。
Use ssh-agent
ssh-agent に登録した鍵で認証する場合に指定します。公開鍵認証を先に試します。
