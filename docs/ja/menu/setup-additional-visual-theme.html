テーマファイルの内容

テーマはTera Term Macの背景、文字の色、または、両方を一括して扱う枠組みです。

テーマを作ったり変えたりするときは、テーマファイル (*.ini) をテキストエディタで編集し、 "Theme" タブの Startup で読み込んでください。
このページでは、テーマファイルで設定できる内容を説明します。

Background Image
背景画像を指定します。
画像ファイルによっては画素ごとの透明度情報も考慮します。
画像ファイル名
JPEG, PNG, GIF, BMP, HEIC など macOS が読める形式が使えます (macOS の画像読み込み ImageIO を使います)。
透過 PNG などアルファチャンネルを持つ画像は、その透明度も使います。
パターン
背景画像の描画方法を指定します。
stretch
画像をウィンドウに合わせて拡大縮小します。
tile
画像をウィンドウの左上からタイル状に表示します。
center
画像をウィンドウの中央に表示します。
fit_width
画像の幅をウィンドウの横幅となるように、アスペクト比を維持したまま、画像を拡大縮小します。
fit_height
画像の高さをウィンドウの高さとなるように、アスペクト比を維持したまま、画像を拡大縮小します。
autofit
アスペクト比を維持して、はみ出さないように最大表示します。
autofill
アスペクト比を維持して、はみ出してでも最大表示します。
Color
背景画像が描画されない部分がある場合この色で埋められます。
画像に透明部分が存在していて壁紙画像を合成しない場合もこの色で埋められます。

Desktop wallpaper image
壁紙画像。デスクトップのピクチャを使います。

Text Color (カラーテーマ)

カラーテーマはデフォルト色に上書きして色が設定されます。
デフォルト色はTERATERM.INI で設定されます。
カラーテーマのiniファイル内で設定しない色はデフォルト色となります。

色はテーマファイルに書いて設定します。 "Theme" タブの「配色」で、用意された配色を選ぶこともできます。

設定した色を表示する例 

curl -fsSL https://raw.githubusercontent.com/TeraTermProject/teraterm/main/tests/256colors2.pl | perl
curl -fsSL https://raw.githubusercontent.com/TeraTermProject/teraterm/main/tests/colortable16.sh | sh
curl -fsSL https://raw.githubusercontent.com/TeraTermProject/teraterm/main/tests/color-sgr-decscnm.pl | perl

色設定のOverview

  • Tera Termのデフォルト色はTERATERM.INIから読み込む
    描画色はデフォルト色となる
    起動時に読み込むthemefileを指定していて、カラーテーマが含まれていると、テーマの色となる
  • TERATERM.INIに保存するとデフォルト色が保存される
  • 描画色をデフォルト色に持っていくことはできない

デフォルト色について

デフォルト色とフォントは TERATERM.INI の次のキーワードで設定できます。 
| Attr \ ini    | font on/off       | color on/off           | color(R,G,B,R,G,B) |
|---------------|-------------------|------------------------|--------------------|
| Normal        | -                 | -                      | VTColor            |
| Bold          | EnableBold        | EnableBoldAttrColor    | VTBoldColor        |
| Blink         | -                 | EnableBlinkAttrColor   | VTBlinkColor       |
| Reverse       | -                 | EnableReverseAttrColor | VTReverseColor     |
| URL Underline | URLUnderline      | EnableURLColor         | URLColor           |
| Underline     | UnderlineAttrFont | UnderlineAttrColor     | VTUnderlineColor   |
