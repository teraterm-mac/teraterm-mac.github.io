SSH SCP ([File] メニュー)

SCP プロトコルでファイルを転送します。
SSH で接続しているときだけ使えます。macOS の scp (/usr/bin/scp) が、いまの SSH 接続を共有して転送します (もう一度ログインする必要はありません)。
転送中は進み具合のウィンドウが表示されます。

送信

From:
送信するファイル。[...] ボタンで選ぶか、このウィンドウに Finder からファイルをドラッグできます。
TO:
送信先を指定します。
空白の場合はホームディレクトリになります。
注意："~" は送信先の OS やシェルによって使えないことがあります。
送信ボタン
送信を開始

受信

From:
受信するファイル
TO:
保存先を指定します。
ダウンロードフォルダ、またはダウンロードファイルを指定できます。
空白の場合は "ファイル転送" の設定が使用されます。
受信ボタン
受信を開始
