ZMODEM Send ([File] Transfer メニュー)

ZMODEM プロトコルでファイルを送信します。 その前にホスト側の ZMODEM の受信コマンドを起動してください。

"ZMODEM Send" ダイアログボックス

File Name

送信するファイルのファイル名を入力または選択してください。 すでに存在するファイルでなければなりません。 同時に複数のファイルを選択することもできます。

Option

Binary
バイナリファイルを送信するときは選択してください。 逆にテキストファイルを送信する場合は選択しないでください。
