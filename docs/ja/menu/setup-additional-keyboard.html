Additional settings / "Keyboard" タブ ([Setup] メニュー)

Transmit DEL by:
Backspace key
このオプションが選択されると delete キーを押した時に DEL 文字 (ASCII $7F) が送出されます。 選択されないと BS 文字 (ASCII $08) が送出されます。
また、このオプションが選択された(選択されない)時でも Control+delete で BS (DEL) 文字を送出できます。
Delete key
このオプションが選択されると前方削除キー (fn+delete、拡張キーボードの ⌦ キー) を押した時に DEL 文字が送出されます。 このオプションが選択されない場合、このキーの機能は キーボード設定ファイル により決定されます。
Meta key
Option キーをメタ・キー (meta key) として使います。 例えば、Option+A を押すと、ESC A を送出します。
off は使わない、on は左右どちらの Option キーも、left は左の Option キーだけ、right は右の Option キーだけをメタ・キーにします。 メタ・キーにしない側の Option キーは、ふつうの文字入力 (Option との組み合わせで入力する記号など) に使えます。
メニューのショートカットは ⌘ キーなので、メタ・キーモードでも使えます。
Disabled mode:
Application Keypad
アプリケーションキーパッドモードを無効にします。
アプリケーションキーパッドモードを無効にすると、 なにかの拍子でアプリケーションキーパッドモードに移行してしまい 数値キーパッドが使えなくなるというトラブルを防ぐ事ができます。 しかし、アプリケーションキーパッドモードを使用している アプリケーションでは不具合が起きるかもしれません。
Application Cursor
アプリケーションカーソルモードを無効にします。

キーボード設定ファイル を書きかえることで自由にキー設定を変更することができます。
