Window ([Window] メニュー)

実行中の Tera Term ウィンドウを画面の一番前に表示させたり閉じたりします。

"Window list" ダイアログボックス

Window
実行中の Tera Term ウィンドウのリスト。一つ選択してください。
Open
選択されたウィンドウを画面の一番前に表示させ、 そしてこのダイアログボックスを閉じます。
Cancel
何もせずにこのダイアログボックスを閉じます。
Close window
選択されたウィンドウを閉じます。
‹ ウィンドウとタブ目次端末の設定 ›
