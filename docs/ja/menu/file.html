Tera Term Mac›ドキュメント›切断するEnglish

[File] メニュー

New connection...
新しいホストまたはシリアルポートに接続します (⌘N)。
Duplicate session
現在のセッションを新しいウィンドウに複製します (⌘D)。 TELNET, SSH, ローカルシェル接続のみが複製されます。 TCP (生) 接続とシリアル接続は複製されません。
コマンドラインのパスワードを指定するときの注意を参照してください。
Local shell connection
新しいウィンドウを開き、この Mac のシェル (ログインシェル) に接続します (⌘G)。 設定はその他の設定のローカルシェルタブで行います。
Log...
受信される文字をファイルに書き込みます。
Pause Logging
ログの記録を一時中断します。
Comment to Log...
ログファイルへコメントを追加することができます。 コメントは UTF-8 で書き込まれ、最後に改行 (LF) が付きます。
View Log
ログファイルを開きます。
標準ではテキストエディットで開きます。 ViewlogEditor にアプリケーション (.app) または実行ファイルを指定すると、それで開きます。
Show Log dialog...
ログダイアログを表示します。
Stop Logging
ログの記録を終了します。
Send file...
ファイルを送信します。
選択したとき
"Send file" ダイアログ が表示されます。
control キーを押しながら選択したとき
"Send file" ダイアログがスキップされて、ファイル選択ダイアログが表示されます。
前回と同じ送信オプションが使用されます。
設定を変更することで 動作を入れ替えることができます。
Receive file...
受信したデータをファイルに出力します。
選択したとき
"Receive file" ダイアログ が表示されます。
control キーを押しながら選択したとき
"Receive file" ダイアログがスキップされて、ファイル選択ダイアログが表示されます。
前回と同じ受信オプションが使用されます。
設定を変更することで 動作を入れ替えることができます。
Transfer
Kermit/XMODEM/YMODEM/ZMODEM/B-Plus/Quick-VAN プロトコルでファイルを転送します。
SSH SCP
SCP プロトコルでファイルを転送します。
Change directory...
ファイル転送のためのディレクトリを変更します。
Replay Log...
バイナリログを再生します。/R オプションと等価です。
新しいウィンドウを開き、ファイルの内容を受信したデータとして画面に表示します。
Print...
現在の画面または、マウスで選択された文字を印刷します (⌘P)。
Disconnect
接続を切ります (⌘I)。 TCP/IP 接続時で Auto window close オプションが選択されている場合、ウィンドウを閉じます。
Exit
このウィンドウを閉じます (⌘W)。 ホストまたはシリアルポートに接続されている場合は、接続を切ります。
アプリケーションそのものを終了するには、[Tera Term Mac] メニューの「Tera Term Mac を終了」(⌘Q) を使います。
Exit All
確認のあと、すべての Tera Term Mac のウィンドウを個別の問い合わせなしで閉じます。 ホストまたはシリアルポートに接続されている場合は、接続を切ります。
