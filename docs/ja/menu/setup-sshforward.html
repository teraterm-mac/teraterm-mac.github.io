SSH Forwarding ([Setup] メニュー)

"TTSSH: Forwarding" ダイアログボックス

SSH 通信を使ってポート転送を行う設定ができます。
SSH 経由で暗号化して、既存のプロトコルをセキュアな通信を行わせる場合に指定します。
設定は、次に接続する SSH セッションから有効になります。各設定は ssh の -L / -R / -D / -X オプションとして渡します。

Port Forwarding

Add...
Forward する方向、ポート番号を指定して一覧に追加します。
Edit...
選択された Forwarding の設定を編集します。
Remove
選択された Forwarding の設定を削除します。
Accept connections to local ports from other hosts
ローカルの転送ポートに、ほかのホストからも接続できるようにします (ssh -g)。

X Forwarding

Display remote X application on local X server
このチェックボックスをオンにすると、サーバ上の X クライアントと Mac 上の X サーバの間の通信が暗号化されます (ssh -X)。
Mac で使うには、XQuartz などの X サーバを別に用意してください。

"SSH Port Forwarding" ダイアログボックス
