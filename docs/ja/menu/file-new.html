New Connection ([File] メニュー)

新しいホストまたはシリアルポート、ローカルシェルに接続します (⌘N)。 すでに接続されているときは、新しいウィンドウを開いて接続します。
ログの再生は [File] メニューの [Replay log...] で行います。

"New connection" ダイアログボックス

TCP/IP、Serial、ローカルシェル (この Mac のシェル) のどれかを選んで [接続] を押します。 最初は前回選んだ種類と内容が入っています。

TCP/IP

Host
接続するホスト名または IP アドレスを入力します。
user@myhost.example.com のように書くと、@ の前がユーザー名になります。
Telnet のとき "myhost.example.com /B" のように書くと、Telnet バイナリモードで接続します。
ポート番号は [TCP port#] に入力します。ホスト欄に書いたその他のコマンドラインオプションは使われません。
Host List
ドロップダウンを使用してホストリストからホストを選択することができます。 選ぶと、保存されているユーザー名・ポート番号・サービス・秘密鍵が各欄に入ります。
ホストリストは次の方法で編集することができます。
  • [Setup] Additional Setting の TCP/IP タブのホストリストの編集
  • ドロップダウンから "<Edit host list...>" を選択
ホストリストはアプリの設定に保存されます。[Setup] メニューの [Save setup...] で、TERATERM.INI の Hosts セクションにも書き出します。
保存できるホスト数は最大20です。
keybind
このエディットコントロールでは、macOS の標準のテキスト編集キーを使用できます。たとえば次のキーです。
Ctrl+a
キャレットを先頭へ移動
Ctrl+e
キャレットを最後尾へ移動
Ctrl+b
キャレットを1文字後ろへ移動
Ctrl+f
キャレットを1文字前へ移動
Ctrl+d
一文字削除
Ctrl+k
行末まで削除
Add host list
このオプションを選択すると、接続するときに、入力したホストがホストリストの先頭に追加されます。
ホストリストに存在している場合は、先頭に移動します。
Additional settings / "TCP/IP" タブ の Add host list when new connection がこのチェックボックスの初期値となります。
Telnet
Telnet プロトコルを使用します。
参照: ユーザ名またはパスワードに非 ASCII 文字を使用する場合の注意
SSH
SSH プロトコルを使用します。macOS の ssh (/usr/bin/ssh) で接続します。
参照: SSH 接続
Other
Telnet / SSH 以外のプロトコル (そのままの TCP) を使用します。
TCP port#
選択したサービスによって、ポート番号を指定してください。
Telnet か SSH を選ぶと、次のデフォルトが入ります。
Service TCP port# 備考
Telnet 23 well-known ports
SSH 22 well-known ports
Other （任意）
User name / Password
SSH のときのユーザー名とパスワードです。 初期値は前回のユーザー名、または SSH 認証の設定です。 パスワードを空にしたときは、端末の画面で ssh が尋ねます。
コマンドラインのパスワードを指定するときの注意も参照してください。
Private key
SSH の公開鍵認証で使う秘密鍵ファイルです。[選ぶ…] で ~/.ssh から選べます。ssh の -i オプションで渡します。

注:
Telnet が選択されて、かつ TCP port# が 23 のときだけ、Tera Term Mac から自発的に telnet の option negotiation を開始します。 それ以外の場合でも Tera Term Mac はホストから送られてきた telnet コマンドに応答することができます。

参照:
Telnet 用ポート番号 / 非 telnet 接続用の端末設定

Serial

Port
接続するシリアルポートをリストの中から選択してください。リストには /dev/cu.* のデバイス (USB シリアル変換器など) が表示されます。 利用可能なシリアルポートが存在しない場合は「(シリアルポートが見つかりません)」と表示されます。 あとからデバイスをつないだときは [再検索] を押してください。
速度・データ・パリティ・ストップ・フロー制御もここで指定できます。

ローカルシェル

この Mac のシェルに接続します。既定ではログインシェル ($SHELL) を起動します。シェルは Additional settings のローカルシェルタブで変えられます。 [File] メニューの [ローカルシェル接続] (⌘G) でも開けます。
