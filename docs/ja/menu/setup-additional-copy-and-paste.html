Additional settings / "Copy and Paste" タブ ([Setup] メニュー)

Enable continued line copy
継続している行を改行せずにコピーする機能を有効にします。
ダブルクリックでワードを選択する時、ダブルクリック後のドラッグでも有効です。
マウスの使い方を参照ください。
Disable mouse R button paste
右クリックでクリップボードの内容を貼り付ける機能を無効にします。
Confirm mouse R button paste
右クリックでクリップボードの内容を貼り付けるとき、 ポップアップメニューで確認する機能を有効にします。
"Disable mouse R button paste" が off のときに設定できます。
Disable mouse M button paste
中クリックでクリップボードの内容を貼り付ける機能を無効にします。
Select only by L button
マウスドラッグによる選択を、左ボタンでのみ有効にする。
Trim trailing new line character when pasting
貼り付け時に末尾の改行を削除する。
Bracketed paste only when the text contains control characters
ブラケットペーストモードのとき、貼り付ける文字に制御文字が含まれる場合だけブラケットで囲みます (TERATERM.INI の BracketedControlOnly)。
Confirm change paste
クリップボードに改行コード(CR/LF)を含む場合、マウスの右クリックおよび ⌘V で Tera Term Mac のウィンドウへ貼り付けようとするタイミングで、確認ダイアログを表示させることができます。 誤操作により、端末へ予期せぬコマンド投入を防ぐことができます。
Always confirm paste with new line
[Edit] メニューの Paste<CR> (⌘R) で貼り付けるときは、内容にかかわらずいつも確認ダイアログを表示します (TERATERM.INI の ConfirmChangePasteCR)。
"Confirm change paste" が on のときに作用します。
String file
クリップボードに、この設定で指定したファイル内に存在するテキストが含まれる場合、マウスの右クリックおよび ⌘V で Tera Term Mac のウィンドウへ貼り付けようとするタイミングで、確認ダイアログを表示させることができます。 誤操作により、端末へ予期せぬコマンド投入を防ぐことができます。
この設定は、ConfirmChangePasteの設定が有効な場合に作用します。
Delimiter characters
単語選択の区切り文字を設定します。
Paste delay per line
複数行のデータを貼り付けるとき、改行が現れるごとにデータの送信を遅延させることができます。遅延する時間をミリ秒で設定します。
Enabling text selection when the window is activated by mouse
非選択状態のウィンドウを、文字領域をマウスでクリックすることで 選択するとき、文字の選択を禁止します。
Copy to clipboard when text is selected
マウスで文字列を選択したとき、クリップボードへコピーします。
