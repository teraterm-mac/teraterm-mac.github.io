Tera Term Mac›ドキュメント›端末のリセット・ブレーク送信English

[Control] メニュー

Reset terminal
ターミナルの各種モードをリセットします。
Reset remote title
リモートタイトルをリセットします。
Are you there
Telnet の AYT (Are You There) コマンドを送出します。 通常ホストはこれに呼応して何等かのメッセージを送り返してきます。 Telnet 接続のときだけ使用できます (⌘T)。
Send break
ブレーク信号を送出します (⌘B)。sendbreak マクロコマンドも参照。
Telnet とシリアル接続で使えます。SSH 接続ではブレーク信号を送れません (SSH には macOS の OpenSSH を使うため)。
Reset port
シリアルポートをリセットします。 シリアルポート接続のときだけ使用できます。
Broadcast command
ブロードキャストコマンドを送信するためのダイアログを表示します。
Open TEK
TEK window を開きます。
Close TEK
TEK window を閉じます。
Always on top
このウィンドウをほかのウィンドウより常に手前に表示します。もう一度選ぶと元に戻ります。
Macro
マクロを実行します。
Show Macro Window
実行中のマクロウィンドウを表示します。
