SSH ([Setup] メニュー)

Tera Term Mac の SSH 接続は、macOS に入っている OpenSSH (/usr/bin/ssh) を使います。 このダイアログの設定は、接続するときに ssh のオプション (-o ...) に直して渡します。 設定は、次に接続するセッションから有効になります。
~/.ssh/config の設定も、ふだんの ssh と同じように使われます。

"TTSSH: Setup" ダイアログボックス

Preferred cipher order
SSH 接続で使用する暗号の種類を順序を付けて指定します (ssh の Ciphers)。
<ciphers below this line are disabled> より下の暗号は使用されません。
一覧には、この Mac の ssh が対応している暗号 (ssh -Q cipher) が表示されます。 順序を ssh の標準のままにしたときは、オプションを渡しません。
SSH Known Hosts
SSH で接続したホスト (とホスト公開鍵) が格納されるファイルを指定します。
読み書き用の既定は ~/.ssh/known_hosts です (ssh の UserKnownHostsFile)。 読み取り専用のファイルは ssh の GlobalKnownHostsFile として渡します。 相対パスは設定フォルダ (~/Library/Application Support/Tera Term Mac) からのパスになります。
Host key rotation

ホスト公開鍵の自動更新を実施するかどうかを設定します (ssh の UpdateHostKeys)。

SSH サーバはホスト鍵を持っていますが、何らかの理由でこのホスト鍵を変更することがあります。
この場合 SSH サーバによっては新しいホスト鍵の一覧をクライアントに送信し、クライアントにホスト鍵一覧の更新を促します。
新しいホスト鍵の一覧を受信したときに、クライアント側の known hosts リストを更新することができます。

無効
更新を行いません (UpdateHostKeys=no)。
有効
known hostsファイルを自動更新します (UpdateHostKeys=yes)。
確認する
known hostsファイルを更新する際、問い合わせを行います (UpdateHostKeys=ask)。
Keepalive
指定した秒数のあいだサーバから何も届かなかったときに、接続維持用のパケットを送信します (ssh の ServerAliveInterval)。 0 を指定すると無効になります。
Enable agent forwarding
ssh-agent を利用した SSH エージェント転送を有効にします (ssh の ForwardAgent=yes)。
転送した鍵を使うたびに確認したいときは、ssh-add -c で鍵を登録してください。
Verify host key fingerprint by DNS
SSHFP リソースレコードを利用して SSH サーバホスト鍵を検証するか指定します (ssh の VerifyHostKeyDNS)。
KEX order (SSH2 only)
SSH2 接続で使用するKEX(鍵交換)の種類を順序を付けて指定します (ssh の KexAlgorithms)。
<KEXs below this line are disabled> より下の方式は使用されません。
一覧には、この Mac の ssh が対応している方式 (ssh -Q kex) が表示されます。
MAC order (SSH2 only)
SSH2 接続で使用するMACの種類を順序を付けて指定します (ssh の MACs)。
<MACs below this line are disabled> より下の方式は使用されません。
一覧には、この Mac の ssh が対応している方式 (ssh -Q mac) が表示されます。
Host key order (SSH2 only)
SSH2 接続で使用するホスト鍵の種類を順序を付けて指定します (ssh の HostKeyAlgorithms)。
<Host keys below this line are disabled> より下の方式は使用されません。
一覧には、この Mac の ssh が対応している方式 (ssh -Q key) が表示されます。
Compression level
通信路の圧縮を指定します。 0 (なし) 以外にすると圧縮が有効になります (ssh の Compression=yes)。 OpenSSH は圧縮レベルを選べないため、1 から 9 のどれでも同じ動作になります。 (高速な回線ではレスポンスが悪くなる場合もあります。)
LogLevel
ssh のデバッグ情報を記録するレベルを指定します。
0 より大きい場合、ssh のログが設定フォルダ (~/Library/Application Support/Tera Term Mac) の「TTSSH.LOG」に記録されます (ssh -E)。 値は ssh の LogLevel に次のように対応します。
値 ssh の LogLevel
0 無効
1～24 INFO
25～49 VERBOSE
50～74 DEBUG1
75～99 DEBUG2
100 以上 DEBUG3
