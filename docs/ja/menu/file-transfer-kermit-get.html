Kermit Get ([File] Transfer メニュー)

Kermit プロトコルでファイルを受信します。 ホスト側の Kermit が server の状態の時にこのコマンドを使用してください。

"Kermit Get" ダイアログボックス

受信したいホスト側のファイルのファイル名を入力してください。
受信したファイルは、ファイル転送用フォルダの中に、 ホスト側と同じファイル名で保存されます。
