Additional settings / "UI" タブ ([Setup] メニュー)

UI Language
メニューやメッセージの言語を選びます。一覧はアプリに同梱された言語ファイル (*.lng) から作られます。
先頭の「自動 (macOS の設定に従う)」を選ぶと、macOS の言語設定に合う言語を使います。
OK を押すと切り替わります。 言語ファイルも参照してください。
フォント設定/フォントフォルダを開く
リンクをクリックすると、Finder でユーザのフォントフォルダ (~/Library/Fonts) を開きます。
