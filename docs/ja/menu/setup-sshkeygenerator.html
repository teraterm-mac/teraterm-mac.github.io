SSH Keygenerator ([Setup] メニュー)

"TTSSH: Key Generator" ダイアログボックス

詳しい解説はSSH 接続の「キーの生成」 をご覧下さい。
鍵の生成には macOS の ssh-keygen (/usr/bin/ssh-keygen) を使います。

Key type
生成する鍵の種類を指定します。
RSA
SSH2用 RSA鍵を生成します。
DSA
SSH2用 DSA鍵を生成します。鍵長は 1024 ビットに固定です。
DSA鍵の鍵長を1024ビットより大きくしても、セキュリティを高める事にはなりません。 より強度の高い鍵を使いたい場合は、RSA鍵やECDSA鍵、ED25519鍵を使用して下さい。
macOS の新しい ssh では DSA 鍵が使えないことがあります。
ECDSA-256
SSH2用 ECDSA(256bit)鍵を生成します。
ECDSA-384
SSH2用 ECDSA(384bit)鍵を生成します。
ECDSA-521
SSH2用 ECDSA(521bit)鍵を生成します。
ED25519
SSH2用 ED25519鍵を生成します。
Key Bits
生成する鍵の鍵長を指定します。RSA のときだけ変更できます。
bcrypt KDF
秘密鍵を OpenSSH 形式 (bcrypt KDF) で保存します。ラウンド数も指定できます。
チェックしないときは PEM 形式で保存します。
Generate
鍵を生成します。生成した鍵は、保存するまで一時フォルダに置かれます。
Key passphrase
生成した秘密鍵に付けるパスフレーズを指定します。
Confirm passphrase
秘密鍵に付けるパスフレーズの確認をします。 Key passphraseと同じものを入力してください。
Comment
鍵に付けるコメントを指定します。
Save public key
生成した公開鍵を保存します。保存パネルは ~/.ssh で開き、ファイル名の初期値は id_種類.pub です。
Save private key
生成した秘密鍵を保存します。保存パネルは ~/.ssh で開き、ファイル名の初期値は id_種類 です。 ファイルのアクセス権は 600 (自分だけ読み書きできる) になります。
パスフレーズによる暗号化は ssh-keygen が行います。
