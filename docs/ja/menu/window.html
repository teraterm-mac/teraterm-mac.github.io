[Window] メニュー

実行中の Tera Term ウィンドウをこのメニューのリストから選び、 画面の一番前に表示させます。 最大で9個のウィンドウがリストに表示されます。 実行中のウィンドウが9個より多く、リストにないウィンドウを選択したい場合は、 このメニューにある Window コマンドを使用してください。
ウィンドウ名の前の記号は、+ が通常、- が Dock にしまっている、@ が拡大している、# が隠れている状態を表します。

Window...
実行中の Tera Term ウィンドウを画面の一番前に表示させたり閉じたりします。
Minimize All
すべての Tera Term ウィンドウを最小化します。
Restore All
すべての Tera Term ウィンドウを通常表示にします。
Cascade
Tera Term ウィンドウを重ねて表示します。
Stacked
Tera Term ウィンドウを上下に並べて表示します。タブにまとめたウィンドウは別々のウィンドウに戻してから並べます。
Side By Side
Tera Term ウィンドウを左右に並べて表示します。タブにまとめたウィンドウは別々のウィンドウに戻してから並べます。
Undo - Cascade|Stacked|Side By Side
並び替えたTera Term ウィンドウを元の位置に戻します。
Minimize (しまう)
このウィンドウを Dock にしまいます (⌘M)。
Zoom (拡大/縮小)
このウィンドウを拡大、または元の大きさに戻します。
Previous tab / Next tab
ウィンドウをタブにまとめているとき、前のタブ (⌘{) / 次のタブ (⌘}) に切り替えます。
Open menu bar / Close menu bar
ウィンドウの中 (タイトルバーの下) にメニューバーを表示する/隠すを切り替えます (TERATERM.INI の PopupMenu)。 画面上部の macOS のメニューバーはいつも使えます。
メニューバーを隠しているときは、control キーを押しながら左クリックするとメニューがポップアップします。
TTMado (タブ・窓割り)
TTMado は、タブと窓割りの機能をまとめた Mac 版の組み込みプラグインです。 タブやウィンドウをドラッグして 1 つのウィンドウの中に並べる、見出しのドラッグで並べ替える・タブに戻す、画面を端まで伸ばす、などを行います。 使い方は、かんたんマニュアルの 1 つのウィンドウに画面を並べる を見てください。
[ウィンドウ] の [上下に並べて表示] [左右に並べて表示] は、タブにまとめたウィンドウを窓割りで並べます。
使わないときは、[設定] - [その他の設定...] の [プラグイン] タブで「TTMado」のチェックを外して OK を押します。 すぐに効き、分割している画面はタブに戻り、macOS のふつうのタブと同じ動きになります。 もう一度チェックを付けると使えるようになります。
