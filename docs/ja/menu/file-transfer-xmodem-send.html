XMODEM Send ([File] Transfer メニュー)

XMODEM プロトコルでファイルを送信します。 その前にホスト側の XMODEM の受信コマンドを起動してください。

"XMODEM Send" ダイアログボックス

File Name

受信するファイルのファイル名を入力または選択してください。

Option

1K
パケットサイズ 1K で送信する場合には選択してください。
エラー検出の種類(Checksum/CRC)は受信側でのみ指定できます。
