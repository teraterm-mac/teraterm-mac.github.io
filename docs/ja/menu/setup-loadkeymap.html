Load key map ([Setup] メニュー)

キーボード設定ファイル の内容にしたがってキーボードを設定しなおします。

"Load key map" ダイアログボックス

Mac の標準のファイル選択パネルが、端末ウィンドウのシートとして開きます。 すでに存在するキーボード設定ファイル (.cnf) を選んでください。 初期値は ~/Library/Application Support/Tera Term Mac/KEYBOARD.CNF です。
同じキーコードが 2 回以上割り当てられているときは、エラーの一覧が表示されます。
