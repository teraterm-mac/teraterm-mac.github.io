Additional settings / "ローカルシェル" タブ ([Setup] メニュー)

[File] メニューの「ローカルシェル接続」(⌘G) で開くシェルの設定です。新しく開くときから使われます。

ローカルシェル
Mac のシェルを端末の中で直接起動します。
SHELL
起動するシェルのパスです。"..." ボタンで選べます。空のときは環境変数 SHELL のシェル (それも無いときは /bin/zsh) を使います。
TERM
シェルに渡す環境変数 TERM の値です。既定は xterm-256color です。
ENV_1, ENV_2
シェルに渡す環境変数を "名前=値" の形で指定します。
LOGIN_SHELL
ログインシェルとして起動します。
HOME_CHDIR
ホームフォルダで起動します。

この設定はアプリの設定に保存されます。
