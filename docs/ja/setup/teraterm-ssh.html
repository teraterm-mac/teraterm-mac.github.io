この設定は、TERATERM.INI を編集したあと [設定]-[設定の読み込み...] で読み込むと使われます。扱いの詳細は「Tera Term Mac での扱い」を参照してください。

ログレベル

SSH 接続のログを TTSSH.LOG に記録するかどうかと、記録する詳しさを設定します。 

LogLevel=<設定値>

SSH 接続には macOS の ssh を使います。0 以外を指定すると、値を ssh の LogLevel に直し、ssh -E で設定フォルダ (~/Library/Application Support/Tera Term Mac) の TTSSH.LOG に書きます。

値 ssh の LogLevel
0 (記録しない)
1～24 INFO
25～49 VERBOSE
50～74 DEBUG1
75～99 DEBUG2
100 以上DEBUG3 
省略時:
LogLevel=0
