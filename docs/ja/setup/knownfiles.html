TTSSH known_hosts ファイル

SSH は macOS の ssh (OpenSSH) を使うので、known_hosts も OpenSSH のものを使います。既定は ~/.ssh/known_hosts です (Windows で作った TERATERM.INI の KnownHostsFiles が ssh_known_hosts のときも、こちらとして扱います)。書式は OpenSSH の known_hosts と同じで、ハッシュされたホスト名も使えます。

known_hostsファイルの書式は以下のとおりです。 

  書式:
    ホスト名  キー種別  ホスト公開鍵
    
    #  コメント
    !  否定

   例:
    192.168.1.2 ssh-rsa AAAAB3NzaC1...nXIDE=
    192.168.1.2 ssh-dss AAAAB3NzaC1...nXIDE=
    #192.168.1.3 ssh-rsa AAAAB3NzaC1...nXIDE=
    *.example.com,!mail.example.com ssh-rsa AAAAB3NzaC1...nXIDE=
‹ SSH 鍵の生成目次telnet と TCP/IP の設定 ›
