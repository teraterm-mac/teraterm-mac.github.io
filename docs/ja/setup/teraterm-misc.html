ここに挙げた項目は、TERATERM.INI を編集したあと [設定]-[設定の読み込み...] で読み込むと使われます。設定ファイルの扱いは「Tera Term Mac での扱い」を参照してください。

ユーザインタフェースの言語ファイル

ユーザインタフェースのメッセージが含まれたファイルを指定すると、表示される言語を切り換えることができます。 

UILanguageFile=lang_utf8\ja_JP.lng

言語はアプリに入っている言語ファイルから選びます ([設定]-[その他の設定...] の「UI」タブ)。読み込むときはファイル名 (ja_JP.lng など) だけを見て、アプリにある言語のときだけ使います。保存するときは lang_utf8\ja_JP.lng の形で書きます。空のときは macOS の言語設定に従います。 

省略時:
UILanguageFile=

ブロードキャストコマンドの履歴の保存数

ブロードキャストコマンドの履歴の保存数を設定をしたい場合、MaxBroadcatHistory エントリを設定します。以下に例を示します。 

MaxBroadcatHistory=200

省略時:
MaxBroadcatHistory=99

マウスの中ボタンによる貼り付けを有効にする

中ボタンをクリックしたときに貼り付けを有効にするには、設定ファイルの [Tera Term] セクションの DisablePasteMouseMButton 行を以下のように変更してください。 

DisablePasteMouseMButton=off

省略時:
DisablePasteMouseMButton=on

設定ファイルの自動バックアップ

既存の設定ファイルに上書きする場合、バックアップファイルが自動的に作られます。 自動バックアップが不要であれば、設定ファイルの [Tera Term] セクションの IniAutoBackup 行を以下のように変更してください。 

IniAutoBackup=off

Default:
IniAutoBackup=on

ブラケットペーストのサポート

ブラケットペーストが不要であれば、設定ファイルの [Tera Term] セクションの BracketedSupport 行を以下のように変更してください。 

BracketedSupport=off

Default:
BracketedSupport=on

ブラケットペーストを制御文字を含む場合に限定する

ブラケットペーストはペーストした内容を確定する前に確認できるので便利です。 しかし、改行などの制御文字が含まれていない場合にも貼り付けと確定の二段階の操作が必要になります。 制御文字が含まれているときだけブラケットペーストを有効にしたい場合には、設定ファイルの [Tera Term] セクションの BracketedControlOnly 行を以下のように変更してください。 

BracketedControlOnly=on

Default:
BracketedControlOnly=off
