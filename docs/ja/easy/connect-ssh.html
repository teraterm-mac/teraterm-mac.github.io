SSH でサーバーにつなぐ

ここでは、例のサーバー「example.com」に、ユーザー名「user」でつなぐ手順を説明します。実際には、サーバーの管理者から教わったホスト名とユーザー名を入れてください。

つなぐ手順

  1. ⌘N を押します (メニューの [ファイル] > [新しい接続...] でも同じです)。
  2. 「TCP/IP」が選ばれていることを確かめます。
  3. 「ホスト」に、つなぐ先のホスト名か IP アドレスを入れます (例: example.com)。
  4. 「サービス」で「SSH」を選びます。TCP ポートは 22 のままでかまいません。
  5. 「ユーザー名」を入れます (例: user)。
  6. 「パスワード」は空のままでかまいません。空のときは、つないだあとで端末の画面で聞かれます。
  7. 「接続」を押します。


新しい接続のダイアログ。ホストに example.com、ユーザー名に user を入れたところ

はじめてつなぐときの質問

はじめてのサーバーにつなぐと、画面に次のような英語の質問が出ます。

The authenticity of host 'example.com (...)' can't be established.
ED25519 key fingerprint is SHA256:....
Are you sure you want to continue connecting (yes/no/[fingerprint])?
  1. これは「このサーバーとは、はじめてつなぎます。本物ですか?」という確認です。
  2. つなぐ先が正しければ、yes と打って return を押します。
  3. 2 回目からは聞かれません。

いつもつないでいるサーバーで「REMOTE HOST IDENTIFICATION HAS CHANGED!」と出たときは、つながずにサーバーの管理者に確かめてください。

パスワードを入れる

  1. 画面に「user@example.com's password:」のように出たら、パスワードを打ちます。
  2. 打った文字は画面に出ません。そのまま打って return を押します。
  3. サーバーのプロンプト (「$」など) が出たら、つながっています。コマンドを打てます。

切断する

  • サーバーで exit と打つか、[ファイル] > [接続断] (⌘I) を選びます。
  • ウィンドウを閉じるときは ⌘W です。

くわしくは

  • 新しい接続
  • SSH で接続する (鍵での認証、ホスト鍵の確認)
  • SSH の設定
