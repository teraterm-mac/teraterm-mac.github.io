困ったとき

文字化けする

日本語が「縺薙ｓ縺ｫ縺｡縺ｯ」のようにおかしく出るときは、文字コードが合っていません。

  1. [漢字コード] メニューを開きます。
  2. 接続先に合う文字コードを選びます。いまのサーバーの多くは「送受信: UTF-8」です。古い機器では「Shift_JIS」や「EUC-JP」のことがあります。
  3. 選ぶとすぐに切り替わります。おかしかった文字は、もう一度表示させると直ります。

delete キーで文字が消えない (^H や ^? が出る)

  1. [設定] > [キーボード...] を選びます。
  2. 「DELを送信するキー:」の「Backspace キー」のチェックを切り替えます。Mac の delete キーは Windows の Backspace キーにあたります。
  3. 「OK」を押して、もう一度試します。

つながらない

  • ホスト名やユーザー名のつづりを確かめてください。
  • SSH のときは、サービスが「SSH」、TCP ポートが 22 (または管理者から教わった番号) になっているか確かめます。
  • 会社や学校のネットワークでは、プロキシの設定や VPN が要ることがあります。管理者に確かめてください。プロキシは [設定] > [プロキシ...] で設定します。
  • シリアルのときは、ポートとスピードが機器と合っているか確かめます (「シリアル機器につなぐ」)。
  • 画面に出た英語のメッセージ (例: Connection refused、Permission denied) をそのまま検索すると、原因がわかることがあります。

ヘルプを開く

  • [ヘルプ] > [目次] を選ぶと、このマニュアルが開きます。
  • 左の目次の上の欄に言葉を入れると、目次を検索できます。
  • 上の「従来のマニュアル (Windows 版)」に切り替えると、本家 Tera Term のヘルプも読めます。
