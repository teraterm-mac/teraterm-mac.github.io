かんたんマニュアル

Tera Term Mac は、Mac からサーバーやネットワーク機器につないで操作するためのアプリ (ターミナルエミュレーター) です。
Windows でおなじみの Tera Term を Mac で使えるようにしたもので、SSH・Telnet・シリアル接続と TTL マクロが使えます。


Tera Term Mac のウィンドウ

はじめての方は、上から順に読んでください。1 ページ数分で読めます。

はじめに読むところ

  1. 起動と終了、アップデート
  2. SSH でサーバーにつなぐ
  3. シリアル機器につなぐ (USB シリアルケーブル)
  4. 画面の基本 (コピー・貼り付け、スクロール、タブとウィンドウ、メニューバー)
  5. 1 つのウィンドウに画面を並べる (TTMado)

慣れてきたら

  1. ログを取る
  2. ファイルを送る・受け取る
  3. 見た目を変える・言語を変える
  4. よく使う接続先を登録する (TeraTerm Menu)
  5. マクロを動かしてみる
  6. 困ったとき

Mac 版だけで使える機能は、Mac 版だけの機能にまとめています。
