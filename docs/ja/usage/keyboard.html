キーボード

キーボードに関するいくつかの設定は [設定] キーボード... でできます。

キーボード設定ファイル (KEYBOARD.CNF) を書きかえることで自由にキー設定を変更することができます。Tera Term Mac は設定フォルダ (~/Library/Application Support/Tera Term Mac) の KEYBOARD.CNF を読み込みます。Windows 版 Tera Term で使っていた KEYBOARD.CNF もそのまま使えます。詳しくは、設定ファイル/キーボード設定 概要 を読んでください。

Mac のキーは、PC のキーの同じ位置・同じ刻印のキーとして扱います。Mac のキーボードにない Home / End / PageUp / PageDown は fn+←/→/↑/↓、テンキーの NumLock は clear キーです。

ショートカット・キー

VT window

ショートカット・キーには ⌘ (Command キー) を使います。⌘ を使うキーはすべてメニューのショートカットで、接続先には送りません。
ヒント: 「ユーザー・ショートカット・キー」

⌘B
ブレーク信号を送出します。(シリアル接続と Telnet のとき。SSH では送れません)
⌘C, Ctrl+Insert
マウスで選択した文字列をクリップボードへコピーします。 AutoTextCopy が有効な場合は、マウスで選択した時点でコピーされています。
⌘D
セッションを複製します。
⌘G
ローカルシェル接続 (この Mac のシェル) を新しいウィンドウで開きます。
⌘I
接続を切断します。
⌘N
新しいホストまたはシリアルポートに接続します。
⌘P
現在の画面または、マウスで選択された文字を印刷します。
⌘W
このウィンドウを閉じます。
⌘Q
Tera Term Mac を終了します。接続中のウィンドウがあるときは確認します。
⌘R
クリップボードの中の文字列をホストへ送出し、続いて改行コードも送出します。
⌘T
Telnet の AYT (Are You There) コマンドを送出します。通常ホストはこれに呼応して何等かのメッセージを送り返してきます。Telnet 接続のときだけ使用できます。
⌘V, Shift+Insert
クリップボードの中の文字列をホストへ送出します。 マウス右クリックでも同じです。 DisablePasteMouseMButton を off にしている場合は、マウス中ボタンクリックでも同じです。
⌘A
バッファ全体を選択します。
⌘,
端末の設定を開きます。
Ctrl+Tab, Ctrl+Shift+Tab
Tera Term Mac のウィンドウを切り替えます。Mac の ⌘` でも切り替えられます。タブにまとめたウィンドウは ⌘⇧[ / ⌘⇧] で前・次のタブに移ります。
Ctrl+Up/Down cursor
上下方向へ一行スクロールします。(macOS の設定で Mission Control などに割り当てられていると使えません)
Ctrl+PageUp/PageDown, Shift+PageUp/PageDown
上下方向へページ単位スクロールします。Mac のキーボードでは fn+↑/↓ が PageUp/PageDown です。
Ctrl+Home
バッファの先頭へ移動します。
Ctrl+End
バッファの末尾へ移動します。
Option+F / E / S / O / W / K / H
ウィンドウ内のメニューバーを表示しているとき、[ファイル] [編集] [設定] [コントロール] [ウィンドウ] [漢字コード] [ヘルプ] の各メニューを開きます。Option キーをメタ・キーにしているときは使えません。
F1 key
Num pad NumLockキー押下。
F2 key
Num pad '/' キー押下。
F3 key
Num pad '*' キー押下。
F4 key
Num pad '-' キー押下。

F1 などのファンクションキーは、macOS の設定によっては fn キーと一緒に押す必要があります。

TEK window

TEK window のショートカット・キーには Option キーを使います。

Option+C
マウスで選択された領域の画像をクリップボードへコピーします。
Option+O
VT window に移動します。
Option+P
画面全体または、マウスで選択された領域の画像を印刷します。
Option+Q
TEK window を閉じます。
Option+R
VT window の ⌘R と同じ。
Option+V
VT window の ⌘V と同じ。

メタ・キー (Meta key)

[設定] キーボード... で Meta キー を選択すると、VT window で Option キーをメタ・キーとして使うことができます。例えば Option+A を押すと、ESC A を送出します。左右の Option キーのどちらか一方だけをメタ・キーにすることもできます (left / right)。
メタ・キーにしていても、⌘ を使うショートカット・キーはそのまま使えます。
