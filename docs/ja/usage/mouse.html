マウス

VT window

左ボタン

左クリック
クリック位置が、Shift+左クリック時の選択領域の始点になります。
選択領域が存在する時、選択領域がキャンセルされます。
Enabling text selection when the window is activated by mouse が OFF のとき、ウィンドウをアクティブにするときのクリックでは選択を始めません。
マウスイベントの通知を使うアプリケーション (vim, tmux など) が動いているときは、クリックは接続先に送られます。
Shift キーを押しながら左クリック
選択領域がない場合、左クリックした位置から現在位置までを選択領域とします。
選択領域がある場合、選択済みテキスト領域の伸縮ができます。
Copy to clipboard when text is selected が ON のとき、選択領域の文字はクリップボードにコピーされます。
左ボタンでドラッグ
1文字単位で選択します。
Copy to clipboard when text is selected が ON のとき、選択領域の文字はクリップボードにコピーされます。
左ボタンをダブルクリック
1語選択します。
Copy to clipboard when text is selected が ON のとき、選択領域の文字はクリップボードにコピーされます。
単語の区切り文字は Delimiter characters で指定します。
DelimDBCSがONのとき、 1cell で表示されている文字と 2cell以上(漢字や絵文字など)で表示されている文字の間を区切りとします。
左ボタンをダブルクリックして(2回目を押したまま)ドラッグ
単語単位で選択領域を伸縮できます。
Copy to clipboard when text is selected が ON のとき、選択領域の文字はクリップボードにコピーされます。
左ボタンをトリプルクリック
1行選択します。
Copy to clipboard when text is selected が ON のとき、選択領域の文字はクリップボードにコピーされます。
左トリプルクリックして(3回目を押したまま)ドラッグ
行単位で選択領域を伸縮できます。
Copy to clipboard when text is selected が ON のとき、選択領域の文字はクリップボードにコピーされます。
URL をダブルクリック、または ⌘ キーを押しながら URL をクリック
クリッカブル URL (EnableClickableUrl) が有効なとき、その URL をブラウザで開きます。
タイトルバーの上で左ボタンをダブルクリック
macOS の設定 (システム設定の「デスクトップと Dock」) に従い、ウィンドウを拡大/縮小するか、Dock にしまいます。
Ctrl キーを押しながら左ボタンをクリック
ウィンドウ内のメニューバーを隠しているときは、ポップアップメニューが現れます (メニューの内容はウィンドウ内のメニューバーと同じです)。
ウィンドウ内のメニューバーは、[ウィンドウ] メニューの「メニューバーを閉じる」「メニューバーを開く」で隠したり表示したりできます。画面上部の Mac のメニューバーはいつも使えます。

右ボタン

右クリック
クリップボードの中の文字列をホストへ送出します。
Disable mouse R button paste が OFF のときに動作します。
ConfirmPasteMouseRButton が on のときは、「貼り付け」「貼り付け<CR>」のメニューを出し、選んだときだけ貼り付けます。
トラックパッドでは、2 本指でクリックするか Control キーを押しながらクリックすると右クリックになります (ウィンドウ内のメニューバーを隠しているときの Control+クリックは、上のポップアップメニューになります)。
右ボタンでドラッグ
文字列を選択し、それをクリップボードにコピーし、さらにそれをホストへ送出します。
Disable mouse R button paste が OFF かつ、Select only by L button が OFF のときに動作します。

中ボタン

中ボタンをクリック
クリップボードの中の文字列をホストへ送出します。
Disable mouse M button paste が OFF のときに動作します。

ホイール

マウスホイール
ホイールの回転 (トラックパッドでは 2 本指のスクロール) でスクロールバーを上下させることができます。
また、vi や less など代替画面を使うアプリケーションの使用時には、ホイールの回転を上下のカーソルキーとして送信します。マウスイベントの通知を使うアプリケーションには、ホイールのイベントとして送ります。

ドロップ

ファイル/フォルダをドラッグし、ウィンドウにドロップ
ドロップされたファイル/フォルダを、「SCPで送信」「ファイルの内容を送信」「ファイル名をペースト」することができます。
確認ダイアログの表示
ConfirmFileDragAndDrop が on のとき
ドロップするとダイアログが表示されます。
ただし、ダイアログで "次のドロップ時、ダイアログを表示しない" をチェックして OK を押すと表示されなくなります。その後は Control キー (または Option キー) を押しながらドロップすると、ふたたびダイアログが表示されます。
ConfirmFileDragAndDrop が off のとき
1つのファイルをドロップすると、ダイアログを表示せずに処理します。デフォルトの処理はSend File (Paste content of file)です。
1つまたは複数のフォルダをドロップすると、ダイアログを表示せずに処理します。デフォルトの処理はPaste Filenameです。
これら以外(複数のファイル/ファイルとフォルダ)の場合はダイアログが表示されます。また、上記の場合でも、Control キー (または Option キー) を押しながらドロップするとダイアログが表示されます。
ダイアログ
ファイル/フォルダをドロップしたときの動作を指定します。
SCP
SCP でファイルを送信します。
SSH 接続の場合で、ドロップ内容がファイルだけのとき選択できます。接続に使っている ssh の接続を共有して scp コマンドで送ります。
dest
送信先を指定します。
空白の場合はホームディレクトリになります。
注意："~" は送信先の OS やシェルによって使えないことがあります。
Send File (Paste content of file)
ファイルの内容を端末内に送信(ペースト)します。
ドロップ内容がファイルだけのとき選択できます。
Binary
チェックが入っているときは、ファイルの内容がそのまま送信されます。
チェックが入ってないときは、漢字コード、改行コードは変換されます。
Paste Filename
ファイル名/フォルダ名をペーストします。
Escape
チェックが入っていると次の処理が行われます。
  • " ;&()$!`'[]{}#^~"の文字を"\"でエスケープします。
Separator is Space
複数ドロップされたとき、ファイル名の区切りはスペースとなります。
Separator is NewLine
複数ドロップされたとき、ファイル名の区切りは改行となります。
同じ処理を次の N 個のファイルに適用
チェックが入っていると、同時にドロップされた残りのファイル/フォルダも同様に処理します。
次のドロップ時、同じ処理を行う
ダイアログの設定内容をメモリに記憶し、次にドロップされたときに利用します。 ダイアログが表示される場合にはダイアログの設定に反映され、 表示されない場合はユーザへ確認せずに同じ処理をします。
設定ファイル(TERATERM.INI)に対応する設定項目は存在せず、保存はされません。
記憶されるのは、処理の種類(SCP/Send File/Paste Filename)です。
次のドロップ時、ダイアログを表示しない
チェックが入っていると、次回のファイルドロップ時にダイアログが表示されなくなり、 ユーザへ確認せずにファイル/フォルダを処理します。
このチェックボックスは ConfirmFileDragAndDrop が off のときのみチェックすることができます。
この設定は ConfirmFileDragAndDrop とは別の設定であり、 [Setup] Save Setup で設定を保存しても保存されません。
この設定をチェックした後でも、たとえば「次のドロップ時、同じ処理を行う」で SCP を選んだあとにフォルダをドロップするなど処理できない（確認が必要な）場合や、 Control キー (または Option キー) を押しながらドロップした場合には、ふたたびダイアログが表示されます。
