TeraTerm Menu Tutorial

1. TeraTerm Menuとは

TeraTerm Menu とは、登録した接続先にボタン一発で接続できるランチャーツールです (原作: 早川信平氏、TeraTerm Project によりメンテナンス)。

TeraTerm Menu は Tera Term Mac に組み込まれています。別のアプリを起動する必要はありません。 接続先を選ぶと、Tera Term Mac の新しいウィンドウで接続します。ユーザ名やパスワードをコマンドラインで渡すことはありません。

2. 設定の保存場所

接続先の一覧は macOS の環境設定 (net.satoru.teramac) に、パスワードは macOS のキーチェーンに暗号化して保存します。

リスト編集の左下の「読み込み…」「書き出し…」ボタンで、ttpmenu.ini を読み書きできます。

  • 読み込み: Windows 版の ttpmenu.ini (UTF-16 / UTF-8 / Shift_JIS、変換スクリプトでレジストリから書き出した形式も可) から、接続先とパスワードを読み込みます。LockBox で暗号化されたパスワードは読めないので、入れ直してください。
  • 書き出し: Windows 版でそのまま読める形式 (UTF-16, CRLF) で書き出します。パスワードも書き出すかは選べます (簡易な暗号化なので、取り扱いには注意してください)。

3. 起動方法

Tera Term Mac を起動すると、まずリスト編集のウィンドウが開きます (ホスト名や /M= を付けて起動したときは、直接接続します)。
TeraTerm Menu はメニューバーの Tera Term アイコンに常駐します。ウィンドウを全部閉じてもメニューバーに残ります。

  • 左クリック: 登録した接続先の一覧を表示します。選ぶと新しいウィンドウで接続します。
  • 右クリック: リスト編集 / 大きいアイコンで表示 / フォントを指定 / 左クリックでリスト表示 / ホットキー (⌃⌥M) で一覧を表示 / Mac にログインしたら Tera Term Mac を起動 / バージョン情報 / 実行 (新しい接続) / 終了
  • ホットキー ⌃⌥M を押すと、マウスの位置に一覧を表示します。
  • 一覧は、Dock の Tera Term Mac のアイコンの右クリックからも開けます。リスト編集は、アプリのメニューの「TeraTerm Menu のリスト編集…」からも開けます。
  • 終了するには、メニューバーのアイコンの右クリック →「終了」か、⌘Q を押します。

4. 設定

初めて使う場合、何も接続先が登録されていないので、まずはリスト編集で一覧を作ります。右側の設定内容に項目を入力して「登録」を押すと、左側の一覧に登録されます。同じ名前のときは上書きします。 一覧の右クリックやドラッグで、接続先をフォルダに分けることもできます。

名前 / ホスト名
ホスト名は「ホスト名:ポート番号」の形でポート番号も指定できます。
自動ログイン
ユーザ名・パスワード・sshを使用・鍵ファイルを指定します。SSH 接続する場合は「sshを使用」にチェックを入れます。公開鍵認証を行いたい場合は、鍵ファイルに秘密鍵ファイルを指定します。Telnet では、プロンプトを待ってユーザ名とパスワードを送ります。
マクロファイルを指定して実行
接続してから TTL マクロを実行します。
起動のみ
接続だけ行います。
詳細設定
ログファイル (%Y%m%d などで日時を入れられます)、ユーザ名プロンプト、パスワードプロンプト、オプションを指定します。
オプションは Tera Term のコマンドラインと同じ書き方です。例えば "/KT=UTF8 /KR=UTF8" で文字コード、"/C= /BAUD=" でシリアル接続、"/T=0" で生 TCP を指定します。
起動時に実行
Tera Term Mac の起動時に、自動で接続します。

一覧の登録が完了すると、メニューバーのアイコンを左クリックすることで一覧が表示され、すぐに接続できるようになります。

アンインストールするときに接続先を残したい場合は、先に「書き出し…」で ttpmenu.ini に保存しておいてください。
