Windows 版 Tera Term から Tera Term Mac へ移行する

Windows 版 Tera Term (4 または 5) で使っていた設定ファイル・接続先・マクロは、Tera Term Mac に持ってくることができます。

設定ファイル

  • Tera Term Mac の設定フォルダは ~/Library/Application Support/Tera Term Mac です。
    • cf. フォルダについて
    • [設定] メニューの「設定フォルダ..」で、TERATERM.INI や KEYBOARD.CNF の場所を確かめられます。
    • ふだんの設定は macOS の環境設定 (~/Library/Preferences/net.satoru.teramac.plist) にも保存されます。
  • TERATERM.INI
    • Windows 版の TERATERM.INI を、[設定] メニューの「設定の読み込み...」で読み込みます。UTF-16 (BOM 付き)、UTF-8、Shift_JIS のどれでも読めます。
    • 端末サイズ、文字コード、改行コード、色、フォント、シリアルポート、SSH、Proxy などの設定を反映します。Mac にない設定は読み飛ばします。
    • Mac にないフォント (MS ゴシックなど) は、大きさだけ反映します。フォントは [設定] メニューの「フォント...」で選び直してください。
    • COM ポートの番号は Mac では使えません。シリアルポートは接続ダイアログで /dev/cu.* のポートを選んでください。
    • [設定] メニューの「設定の保存...」で TERATERM.INI に書き出すこともできます。
  • KEYBOARD.CNF
    • Windows 版の KEYBOARD.CNF を設定フォルダにコピーすると、そのまま使えます。[設定] メニューの「キーマップ読み込み...」でほかの場所のファイルも読み込めます。
  • TeraTerm Menu の接続先 (ttpmenu.ini)
    • TeraTerm Menu のリスト編集で「読み込み…」を押し、Windows 版の ttpmenu.ini を読み込みます。cf. TeraTerm Menu
    • Windows 版で設定をレジストリに保存している場合は、先に変換スクリプトで ttpmenu.ini に書き出してください。

マクロファイル

  • Windows 版のマクロファイル (.ttl) は、多くがそのまま動きます。Mac に合わせて変えたところは マクロのページの説明を参照してください。
  • ファイル(拡張子ttl)の文字コードはUTF-8を推奨します。
  • ttlファイル読み込み時、ファイルの文字コード (UTF-8 / UTF-16 (BOM 付き) / Shift_JIS) を自動判定してUTF-8に変換して読み込みます。しかし判定を誤ることがあります。
    BOMを付けると確実にUTF-8として読み込むことができます。
  • 文字変数の文字列長の上限は511バイトです。
  • ttlファイル内の文字列リテラルや、文字列変数に代入した文字列の文字コードはUTF-8です。Tera Term 4 向けに Shift_JIS (CP932) を前提に書いたマクロは注意してください。
  • 漢字などは1文字のバイト数が増える(例 "あ" は 0x82,0xa0 から 0xe3,0x81,0x82となる)ため、Tera Term 4ではセットできたデータが途切れる可能性があります。
  • 文字を扱うコマンドの文字長、文字位置(index,pos)の単位はバイトです。
    内部文字コードが UTF-8 なので、Tera Term 4 とは異なる値になります。
  • ファイルのパスは Mac の書き方 (/Users/... や ~/...) にしてください。c:\work\a.txt のような Windows のパスは、\ を / に読み替え、ドライブ名を除いて扱います。
  • マクロファイルを Tera Term Mac で開く (Finder でダブルクリックするなど) と、マクロが実行されます。

プラグイン

  • Windows 版のプラグイン (.dll) は使えません。プロキシ (TTProxy) と [漢字コード] メニュー (TTXKanjiMenu) は Tera Term Mac に組み込んであります。SSH (TTSSH) の代わりに macOS の ssh コマンドを使います。
