ZMODEM のヒント

ZMODEM は、7 bit 回線では使用できません。

シリアルポートの場合

Data が 7 bitだと、ZMODEM が使えません。[設定] シリアルポート... で Data を 8 bit にしてください。モデム(ホスト)側の設定も同じにしてください。

Telnet の場合

もし正しく転送できない場合は制御文字をすべてエスケープしてみてください。それでもだめな場合はバイナリオプションで telnet 接続してみてください。
バイナリオプションで接続するには、

  • コマンドラインまたは [ファイル] 新しい接続 のホスト名に /B オプションをつけるか、
  • Tera Term 設定ファイルを書き換えてください。
    → Telnet のバイナリオプション

ZMODEM の転送は [ファイル] メニューの「転送」→「ZMODEM」から始めます。
どうしても正常に転送できない場合は、ホスト側の ZMODEM コマンドを正しく設定および使用していることを確認した上で、Tera Term Mac の GitHub Issues に報告してください。

また、以下の設定も可能です。

  • → ZMODEM 送信の設定

参考: 中間ホストを経由してホストに接続した場合のファイル転送

通信ソフトウェア

ZMODEMによるファイル送信は、Red Hat系Linux(Fedora, CentOS)上で lrzsz パッケージに対して正常に動作します。zmtx-zmrx パッケージに対しては動かないことがあります。
Mac では Homebrew などで lrzsz を入れることができます (brew install lrzsz)。

モデム通信プログラム

  • lrzsz
  • zmtx-zmrx
