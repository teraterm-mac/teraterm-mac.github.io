ユーザー・ショートカット・キー

キーボード設定ファイルの [Shortcut keys] と [VT function keys] セクションの項目を書き換えると、以下のショートカット・キーを自分の好きなキーに割り当てることができます。詳しくは、キーボード設定ファイルを読んでください。

*1) これらの機能にはシステム・ショートカット・キーが割り当てられています。 メニューの ⌘ キーです (コピー ⌘C、貼り付け ⌘V、貼り付け<CR> ⌘R、印刷 ⌘P、ブレーク送信 ⌘B)。

Mac での注意

  • ⌘ キーはメニューのショートカットに使うので、キーボード設定ファイルでは割り当てられません。Option キーは Alt として扱います。
  • Mac のキーボードには Insert キーがありません。help キーのあるキーボードでは、help キーが Insert にあたります。初期設定の Ctrl+Insert / Shift+Insert のかわりに ⌘C / ⌘V を使ってください。
  • PageUp・PageDown・Home・End は、それぞれ fn+↑・fn+↓・fn+←・fn+→ でも押せます。
  • Control+↑・Control+↓ などは macOS の Mission Control に使われていることがあります。その場合は、システム設定の「キーボード」→「キーボードショートカット」で macOS 側の割り当てを外すか、別のキーを割り当ててください。
  • スクロールバックは Shift+PageUp / Shift+PageDown でもできます。

例えば、Ctrl+V を [Edit] Paste に割り当てたい場合は、キーボード設定ファイルの [Shortcut keys] セクションで、 

EditPaste=1071

としてください (IBM PC/AT キーボードの場合。Mac では Control+V です)。

また [User keys] セクションでは、ユーザーキーを使ってすべてのメニューコマンドに対してショートカット・キーを設定することができます
