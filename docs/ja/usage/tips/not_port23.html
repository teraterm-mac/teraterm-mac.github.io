Telnet 用ポート番号

コマンドライン、または [ファイル] 新しい接続 ダイアログボックスでは、TCP/IP 接続に使用される TCP ポート番号 (<TCP port#>) と telnet フラグ (<telnet flag>) を指定することができます。コマンドラインでこれらのパラメーターが省略された場合は、設定の値が使用されます。

<telnet flag> が 1 (on) で、かつ <TCP port#> が 23 の場合だけ、Tera Term Mac はホストに接続した直後に、自発的に telnet コマンドをホストに送信し option negotiation を開始します。

<telnet flag> が 1 (on) なら、<TCP port#> が何であれ Tera Term Mac はホストから送られてきた telnet コマンドに応答します。 <telnet flag> が 0 (off、/T=0 の生 TCP) のときは、受信したデータをそのまま扱います。

非 telnet TCP/IP 接続用の端末設定

Telnet プロトコルに対応していないホスト(通常 23 以外のポート番号を使用)に TCP/IP 接続する場合、ローカルエコーを on に、送信する改行コードを CR+LF にする必要がある場合があります。

[設定] 端末... でローカルエコーと改行コード (送信) を変えてください。
