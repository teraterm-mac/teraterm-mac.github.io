[Edit] メニュー (TEK window)

Copy
マウスで選択された領域の画像をクリップボードへコピーします (option+C)。
Copy screen
画面全体の画像をクリップボードへコピーします。
Paste
クリップボードの中の文字列をホストへ送出します (option+V)。
TEK window で右クリックしても貼り付けます。
Paste<CR>
クリップボードの中の文字列をホストへ送出し、続いて改行コードも送出します (option+R)。
Clear screen
画面を消去します。

TEK window のメニューは、ウィンドウの中のメニューバーにあります。ショートカットは option キーとの組み合わせです。
