Print (TEK window [File] メニュー)

"プリント" ダイアログ

macOS 標準のプリントダイアログが開きます。画像は用紙の大きさに合わせて印刷されます。

印刷範囲の選択
マウスで領域を選択していないときは、現在の画面を印刷します。
領域を選択しているときは、選択した領域の画像を印刷します。
