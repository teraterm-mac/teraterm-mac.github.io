TTSSH command line

SSH 接続 (TTSSH) では以下のコマンドラインオプションが使用できます。SSH は macOS の ssh (OpenSSH) を使います。起動のしかたは「Tera Term Mac コマンドライン」を参照してください。 これらのオプションは、新しい接続ダイアログのホスト名の欄や connect マクロコマンドでも使えます。
ポートフォワーディング・X11 転送は [設定]-[SSH転送...]、エージェント転送・圧縮は [設定]-[SSH...] で設定します。

オプション

<username>@<host>[:<#TCP port>]
ホスト名指定ではTera Term本体が対応している形式の他に、ttssh拡張としてユーザ名付きも使えます。
<scheme>://[<username>[:<password>]@]<host>[:<TCP port>][/]
URL形式も拡張されます。
<scheme>には、ssh, ssh2, slogin, slogin2が使えます。
ポート番号が指定されなかった場合は22が使われます。
コマンドラインの引数として使えます (例: open -a "Tera Term Mac" --args ssh://user@host)。Tera Term Mac は ssh:// の URL を開くアプリとしては登録されません。URL の中のパスワードは、起動時のコマンドラインでは使いません (connect マクロコマンドでは使えます)。
/t=<value>
  • value=2 SSH を有効にする
  • value=2以外 SSH を無効にする
/nossh
SSH 接続を無効にする
/telnet
SSH 接続を無効にする
さらに、Telnet プロトコルを使用する。Tera Term の /T=1 と同じ。
/2
SSH2 で接続する
/ssh2
SSH2 で接続する
/auth=<mode>
<mode> で指定された認証方式で自動ログインを試みる
  • password パスワード認証
  • publickey 公開鍵認証
  • challenge キーボードインタラクティブ認証
  • keyboard-interactive challenge と同じ
  • pageant エージェント (ssh-agent) を用いた公開鍵認証
connect マクロコマンドで使えます。ssh の PreferredAuthentications に直して渡します。起動時のコマンドラインでは使いません。
/user=<username>
ユーザ名を指定する
/passwd=<password>
パスワードを指定する
connect マクロコマンドで使えます。起動時のコマンドラインでは使いません。/auth=publickey のときは鍵のパスフレーズとして使います。
パスワードを指定するときの注意を参照のこと
/keyfile=<file>
秘密鍵を指定する
ssh の -i に渡します。絶対パスか ~ で始まるパスで指定してください。OpenSSH の形式の秘密鍵を使います (PuTTY の .ppk は使えません)。
/ask4passwd
自動ログインをせず、パスワードを聞く
/auth=<mode> は、認証方式のみを意味するようになる
connect マクロコマンドで使えます。

パラメータの値にスペースやセミコロンを含めるためには、値全体を `"' で囲んでください。
値に `"' を含めるためには、連続した `"'("") を指定してください。

例

open -a "Tera Term Mac" --args server1
open -a "Tera Term Mac" --args server1:22 /ssh /user=guest
open -a "Tera Term Mac" --args guest@server2
open -a "Tera Term Mac" --args ssh://guest@server3:2222/
open -a "Tera Term Mac" --args server4 /ssh /user=admin /keyfile=~/.ssh/id_ed25519

connect マクロコマンドの例: 

connect 'server3:22 /ssh /2 /auth=password /user=guest /passwd=guest'
connect 'server4:22 /ssh /2 /auth=publickey /user=admin /keyfile=~/.ssh/id_ed25519 /ask4passwd'

パスワードを指定するときの注意

コマンドライン引数にパスワードを書くと、起動しているプロセスのコマンドライン引数 (ps コマンドなど) から見られることがあります。Tera Term Mac では次のとおりです。

コマンドライン引数を指定して実行する
起動時のコマンドラインの /passwd= と URL の中のパスワードを使いません。パスワードをコマンドラインに書かないでください。
connect マクロコマンドの引数に指定する
connect は同じプロセスの中で処理し、新しいプロセスを起動しません。パスワードは ssh の引数には渡さず、ssh がパスワードを聞いてきたときに入力します。
パスワードをマクロファイルに書く代わりに、getpassword などを使うこともできます。
[ファイル]-[セッションの複製] と TeraTerm Menu
どちらも新しいプロセスを起動しないので、コマンドライン引数でパスワードを渡すことはありません。

例: エージェントとの連携

エージェントには macOS の ssh-agent を使います。鍵を ssh-agent に登録しておきます (macOS のキーチェーンにパスフレーズを保存することもできます)。 

ssh-add --apple-use-keychain ~/.ssh/id_ed25519

Tera Term Mac からエージェントを利用して、公開鍵認証による接続をするには以下のようにします。 

connect 'shell.example.com:22 /ssh /auth=pageant /user=yutaka'
