Tera Term Mac コマンドライン

Tera Term Mac はコマンドラインで起動できます。ターミナル.app などから、次のどちらかの方法で起動します。 

open -a "Tera Term Mac" --args [ <host>[[:]<TCP port#>] | telnet://<host>[:<TCP port#>][/] | ssh://... ]
         [/B] [/BAUD=<speed>] [/C=<serial port#>|<device>]
         [/KR=<kanji code (receive)>] [/KT=<kanji code (transmit)>]
         [/M=<macro file>] [/P=<TCP port#>] [/SPEED=<speed>] [/T=<telnet flag>]
         [/SHELL] [;<comment>]

"/Applications/Tera Term Mac.app/Contents/MacOS/TeraMac" [同じオプション]
  • open -a を使うときは、オプションを --args の後に書きます。アプリがすでに起動しているときは、macOS の決まりで --args の引数は渡されません。そのときは open -n -a で新しく起動するか、アプリの実行ファイル (Tera Term Mac.app/Contents/MacOS/TeraMac) を直接起動してください。
  • 引数なしで起動すると、接続先一覧 (TeraTerm Menu) を開きます。ホスト名などを付けて起動すると、新しいウィンドウで接続します。オプションが読めないときは、新しい接続ダイアログを開きます。
  • コマンドラインで指定した /B /KR= /KT= は、起動して最初に開くウィンドウだけに使います。保存はしません。
  • マクロファイル (.ttl) は open -a "Tera Term Mac" macro.ttl や Finder でのダブルクリックでも実行できます。こちらはアプリが起動していても使えます。
  • ssh:// で始まる URL と /ssh などの SSH のオプションは「TTSSH コマンドライン」、プロキシは「TTProxy コマンドライン」を参照してください。

オプション

<host>
ホスト名または IP アドレス
IPv6アドレスは角括弧（大括弧）で囲みます（RFC3986 / RFC5952 参照）。
SSH か Telnet かを指定しないときは、ポート番号が 22 か指定なしなら SSH、それ以外のポート番号 (23 など) なら Telnet で接続します。
<host>:<TCP port#>
TCP ポート番号つき <host>
<host> と <TCP port#> の間に":"が置かれる。
<host> <TCP port#>
TCP ポート番号つき <host>
<host> と <TCP port#> の間に1個以上の空白文字が置かれる。
<host> のすぐ後にくる数字は TCP ポート番号とみなされる。
telnet://<host>[:<TCP port#>][/]
URL形式
TCP ポート番号および末尾の / は省略可能。
TCP ポート番号が省略された場合は23となる。
コマンドラインの引数として使えます。Tera Term Mac は telnet:// の URL を開くアプリとしては登録されません。
/B
Telnet バイナリオプション
/BAUD=<speed>
シリアルポートのスピードを指定します。/SPEED= と同じ動作です。 指定した値が実際に反映されるかは、シリアルポートのチップ・ドライバの仕様によります。
/C=<serial port#>
シリアルポート
次のように指定します。
  • /C=/dev/cu.usbserial-XXXX デバイスを直接指定する
  • /C=1 見つかったシリアルポート (/dev/cu.*、名前の順) の 1 番目
  • /C=2 2 番目
  • :
番号が範囲外のときは、最初のシリアルポートを使います。
/CDATABIT=<value>
シリアルポートのデータビット
  • /CDATABIT=7 7bit
  • /CDATABIT=8 8bit
/CPARITY=<value>
シリアルポートのパリティ
  • /CPARITY=none none
  • /CPARITY=odd odd
  • /CPARITY=even even
  • /CPARITY=mark mark
  • /CPARITY=space space
/CSTOPBIT=<value>
シリアルポートのストップビット
  • /CSTOPBIT=1 1bit
  • /CSTOPBIT=2 2bit
1 以外は 2bit になります。
/CFLOWCTRL=<value>
シリアルポートのフロー制御
  • /CFLOWCTRL=x Xon/Xoff
  • /CFLOWCTRL=hard RTS/CTS
  • /CFLOWCTRL=rtscts RTS/CTS
  • /CFLOWCTRL=none none
  • /CFLOWCTRL=dsrdtr DSR/DTR
/FD=<file transfer directory>
ファイル転送用ディレクトリ
起動時のコマンドラインでは使いません。connect マクロコマンドでは使えます。
/KR=<kanji code (receive)>
漢字コード (受信)
使用可能文字コードは文字コードページを参照ください。
/KT=<kanji code (transmit)>
漢字コード (送信)
使用可能文字コードは文字コードページを参照ください。
/M=<macro file>
起動時にマクロを実行
絶対パスで指定してください (~ で始まるパスも使えます)。ホスト名なども指定したときは、接続を始めてからマクロを実行します。
/P=<TCP port#>
TCP ポート番号
/SPEED=<speed>
シリアルポートのスピードを指定します。/BAUD= と同じ動作です。 指定した値が実際に反映されるかは、シリアルポートのチップ・ドライバの仕様によります。
/T=<telnet flag>
  • /T=1 Telnet プロトコルを使用
  • /T=0 Telnet プロトコルを不使用 (TCP でそのまま接続)
どちらも SSH は使いません。ポート番号を指定しないときは 23 になります。
/TIMEOUT=<connecting timeout value>
接続中の処理をキャンセルするまでの時間（秒単位）
起動時のコマンドラインでは使いません。connect マクロコマンドでは使えます。
/W=<window title>
ウィンドウのタイトル
起動時のコマンドラインでは使いません。connect マクロコマンドでは使えます。
/SHELL
ローカルシェルに接続する。[ファイル]-[ローカルシェル接続] と同じです。
;<comment>
コメント。コマンドラインの最後に置く必要がある。
シェルから指定するときは、; をシェルに解釈されないよう引用符で囲んでください。

例

open -a "Tera Term Mac"
open -a "Tera Term Mac" --args myhost.example.com
open -a "Tera Term Mac" --args myhost.example.com:23
open -a "Tera Term Mac" --args myhost.example.com 23
open -a "Tera Term Mac" --args 192.0.2.1
open -a "Tera Term Mac" --args "[2001:db8:1:2:8401:2ff:fe03:405]"
open -a "Tera Term Mac" --args telnet://myhost.example.com
open -a "Tera Term Mac" --args /C=1
open -a "Tera Term Mac" --args /C=/dev/cu.usbserial-XXXX /SPEED=115200

open -a "Tera Term Mac" --args myhost.example.com /T=0 /P=7
open -a "Tera Term Mac" --args myhost /B /KR=UTF8 /KT=UTF8
open -a "Tera Term Mac" --args /M=~/macro/login.ttl
open -a "Tera Term Mac" ~/macro/login.ttl
"/Applications/Tera Term Mac.app/Contents/MacOS/TeraMac" myhost.example.com /telnet

省略時の値

省略時の値は、設定画面の設定 (環境設定に保存されたもの) です。シリアルポートで指定しなかった項目は、9600bps・8bit・パリティなし・1 ストップビット・フロー制御なしになります。

注

[1] <telnet flag> が 1 で、かつ <TCP port#> が 23 のときだけ、Tera Term から自発的に telnet の option negotiation を開始します。それ以外の場合でも Tera Term はホストから送られてきた telnet コマンドに応答することができます。

[2] パラメータの値にスペースや `"' を含めるためには、値全体を `"' で囲んでください。
値に " を含めるためには、連続した `"'("") を指定してください。
シェルから起動するときは、シェルの引用符の規則も合わせて考えてください。空白を含む 1 つの引数は、そのまま 1 つの値として扱います。 

open -a "Tera Term Mac" --args '/M=/Users/user/My Macros/login.ttl'
