Mac 版だけの機能

Tera Term Mac は、Windows 版 Tera Term の動きをそのまま Mac に移すことを基本にしています。そのうえで、Mac で使いやすくするために、次の機能を足しています。

タブと窓割り (TTMado)

  • 接続を macOS のタブにまとめられます (Windows 版は 1 接続 1 ウィンドウ)。
  • タブやウィンドウをドラッグして、1 つのウィンドウの中に左右・上下に並べられます。入れ子の分割、並べ替え、端まで伸ばす、タブに戻す、ウィンドウどうしの合体ができます。
  • 並べた画面には見出し (× で閉じる、ドラッグで移す、右クリックでメニュー) と、画面の数のバッジが付きます。
  • 窓割り中の [新しい接続] [セッションの複製] [ローカルシェル接続] は、窓内・タブ・新しいウィンドウから開く場所を選べます。
  • 組み込みプラグインなので、[設定] > [その他の設定...] の [プラグイン] タブで、いつでも入/切できます。
  • くわしくは 1 つのウィンドウに画面を並べる を見てください。

Mac との連携

  • ローカルシェル接続: Windows 版の Cygwin 接続の代わりに、この Mac のシェル (ターミナル.app と同じもの) を開きます。
  • キーチェーン: TeraTerm Menu で覚えさせたパスワードは、Mac のキーチェーンに保存します。
  • メニューバーと Dock: 画面上部のメニューバーのアイコンと、Dock のアイコンの右クリックから、登録した接続先にすぐつなげます。
  • メニューバーの切り替え: Windows 版と同じメニューをウィンドウの中に出すか、Mac の画面上部のメニューバーだけにするかを切り替えられます。
  • ダークモード・Retina: macOS の外観と高解像度の画面に合わせて表示します。

言語

  • 画面の文字を 14 言語で表示できます。最初は macOS の言語設定に合わせて自動で選び、[設定] の「UI」タブで切り替えられます。

アップデートとアンインストール

  • 自動アップデート: 新しい版が出ると知らせ、更新内容を確かめてからその場で更新できます。
  • アンインストール: 設定ファイルなどもまとめて消すアンインストーラーを付けています。

ヘルプ

  • Mac 版マニュアル: 元の Tera Term のマニュアルをもとに、Mac 版に合わせて整理し直したものです。章立てと検索、「前へ/次へ」で読めます。
  • かんたんマニュアル: はじめての方向けの、画面の写真付きの説明です。
  • 元のマニュアル: Windows 版の元のマニュアルも、ヘルプの画面で切り替えて見られます。
  • 要望・お知らせを送る: 気づいたことを匿名で開発者に送れます。

Windows 版との違い (できないこと・動きの違い) は、Windows 版との違い を見てください。
