要望集

ユーザーの方々からよくよせられる要望です。(つまり実現できていないものです。)
ヘルプ(MACRO ヘルプ)を参照しても解決できないことがありましたら、問い合わせください。

Tera Term Mac への要望は Tera Term Mac の Issues へお願いします。

すでに対応しているものには 対応済、一部だけ対応しているものには 一部対応 の印を付けています。

将来対応するかもしれないもの

  • VT100の倍角文字、点滅文字
  • ECMA-48端末の低輝度文字、イタリック体、高速点滅文字、不可視文字、抹消線文字一部対応 (低輝度・イタリック・不可視・抹消線)
  • VT3XXの文字(行)間罫線
  • ツール・バー、ステータス・バー
  • ダイアラー
  • キーボード設定用ユーティリティー
  • メニューやダイアログボックスのカスタマイズ
  • 文字列検索機能
  • TEK window の画面バッファ & スクロール・バー
  • TEK window の印刷の解像度を改善する。
  • ファイル転送時の転送速度、残り時間、棒グラフ表示対応済
  • ZMODEM の転送再開機能
  • [File] Print setup コマンド一部対応 (印刷ダイアログで用紙と向きを選べます)
  • スクロールバッファの内容、選択された文字をファイルに保存
  • 画面/文字色の指定をカラーパレットで行う対応済 (macOS のカラーピッカー)
  • 132 桁モードのとき小さいフォントに切り替える
  • SFTP(SSH File Transfer Protocol)
  • OpenSSHのProxyCommand対応済 (~/.ssh/config がそのまま使えます)
  • カラー絵文字対応済

将来対応するかもしれないもの(MACRO 関係)

  • 配列変数対応済
  • "exec" コマンドでリダイレクション対応対応済 (/bin/sh -c で動くので > や | が使えます)
  • バイナリデータを "wait" で待てるようにする。
  • 既に起動しているTera Termへのconnect

遠い遠い将来に対応するかもしれないもの

  • TEK41XX, 42XX 端末のエミュレーション
  • Televideo, Wyse 端末のエミュレーション
  • TN3270
  • 開いているシリアルポートを他のアプリケーションと同時共有可能にする。
  • 行入力モード、行入力のためのウィンドウを用意する。
  • Kermit の転送速度改善対応済
  • 可変幅(プロポーショナル)フォント
  • ANSI/AVATAR
  • ReGIS
  • Sixel(シクセル)
  • マクロで直接通信ポートを操作
  • xterm, DEC Locator mode以外のマウスプロトコル(NetTerm等)
