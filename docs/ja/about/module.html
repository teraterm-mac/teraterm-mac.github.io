構成要素

Tera Term Mac は、以下のモジュール(コンポーネント)をもとに作られています。

Tera Term Mac

Tera Term Mac は 1 つのアプリ (Tera Term Mac.app) です。下の各モジュールの機能は、すべてこのアプリに組み込まれています。

原作著作者 T. Teranishi (寺西 高)
開発者 satorunet
ライセンス MIT License
詳細は「ライセンス・著作権」を参照してください。
変更履歴 Releases を参照してください。

Tera Term

ターミナルエミュレータ本体です。 Tera Term Mac では、端末エミュレータ本体を Swift / AppKit で作り直しています。TTL マクロの処理系 (ttpmacro) とファイル転送は Tera Term のソースを移したものです。

原作開発者 T. Teranishi (寺西 高)
後継開発者 TeraTerm Project
ライセンス BSD Style License
詳細は「ライセンス」を参照してください。
著作権 「著作権」を参照してください。

TTProxy

プロキシ接続 (HTTP / SOCKS4 / SOCKS4a / SOCKS5 / TELNET) をサポートするモジュールです。Tera Term Mac に組み込んでいます。

原作開発者 蛭子屋双六
後継開発者 TeraTerm Project
ライセンス BSD Style License
詳細は「ライセンス」を参照してください。

TeraTerm Menu

自動ログインを支援するランチャーです。Tera Term Mac に組み込んでいて、メニューバーに常駐します。パスワードは macOS のキーチェーンに保存します。

原作開発者 S.Hayakawa (早川信平)
後継開発者 TeraTerm Project
ライセンス BSD Style License

TTX KanjiMenu

メニューから漢字コードを変更するためのモジュールです。Tera Term Mac では [漢字コード] メニューとして組み込んでいます。
