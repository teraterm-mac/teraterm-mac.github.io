ライセンス・著作権

Tera Term Mac

Tera Term Mac は、Tera Term を macOS 用に移植したものです。 Tera Term の原作者 T. Teranishi (寺西 高) 氏の公認を受けた Mac 版のプロジェクトで、Windows 版を開発している TeraTerm Project とは別のチームで開発しています。

Tera Term Mac で新しく書いたコードは MIT License です。 Tera Term から受け継いだ部分 (アイコン、TTL マクロの処理系、ファイル転送) は、元の Tera Term のライセンス (三条項BSDライセンス) のままです。 ライセンスの全文は、メニューの [Tera Term Mac] > [謝辞とライセンス…] でも見られます。

Tera Term Mac が使っているもの

  • Tera Term ... アイコン、TTL マクロの処理系、ファイル転送 (XMODEM / YMODEM / ZMODEM / Kermit / B-Plus / Quick-VAN)。三条項BSDライセンス
  • 鬼車 (Oniguruma) 6.9.10 ... TTL マクロの正規表現。二条項BSDライセンス
  • Sparkle 2.9 ... 自動アップデート。MIT ライセンス (Copyright (c) 2006-2013 Andy Matuschak ほか Sparkle の開発者)
  • OpenSSH ... SSH 接続。アプリには含まず、macOS に入っている ssh コマンドを使います
