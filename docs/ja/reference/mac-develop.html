開発者向け (Mac 版)

このページは Tera Term Mac の開発についての資料です。本家 Tera Term (Windows 版) の開発については「開発者向け (本家 Windows 版)」を見てください。

  • ソースの構成 (このページ)
  • ビルド・テスト・リリース
  • 画面の言語とヘルプ

リポジトリ

ソースは https://github.com/teraterm-mac/teraterm-mac にあります。 このリポジトリは本家 TeraTermProject/teraterm を fork したもので、Mac 版のソースはすべて macos/ フォルダにあります。 macos/ 以外は本家のソースの写しです。ここで直しても本家には入らないので、本家を直したいときは本家に送ってください。

Tera Term Mac は、Windows 版を開発している TeraTerm Project とは別のチームで開発しています。不具合の報告・要望・Pull Request は、TeraTerm Project ではなくこのリポジトリの Issues / Discussions / Pull Request へお願いします (リポジトリの CONTRIBUTING.md も見てください)。

Swift Package の構成

macos/Package.swift は Swift Package Manager のパッケージ (swift-tools-version 5.5、macOS 11 以上) です。Xcode のプロジェクトファイルはありません。ターゲットは次のとおりです。

ターゲット場所中身
TeraCoreSources/TeraCore端末エミュレータ・文字コード・文字幅・TTL マクロ・ファイル転送・設定ファイルの読み書きなど。AppKit に依存しない部分 (テストはここを対象にします)
TeraMacSources/TeraMacアプリ本体 (実行ファイル TeraMac)。AppKit の画面・メニュー・ダイアログ・接続・ヘルプ・自動アップデート
CTeraFileSources/CTeraFile本家 teraterm/ttpfile の C のソース (XMODEM / YMODEM / ZMODEM / Kermit / B-Plus / Quick-VAN / raw) をそのままコンパイルするターゲット。glue/ と compat/ が Windows の API の代わりをします
COnigurumaSources/COniguruma正規表現ライブラリ 鬼車 (Oniguruma 6.9.10)。本家のマクロと同じ正規表現にするため
TeraUninstallSources/TeraUninstallアンインストール (アプリ本体、設定と接続リスト、キーチェーンに保存したパスワードを消す)
TeraCoreTestsTests/TeraCoreTestsTeraCore のテスト (XCTest)

外部のパッケージは自動アップデートの Sparkle だけです。Sparkle 2.10 からは macOS 12 以上が必要になるため、2.9 系に固定しています。

本家との関係

本家 Tera Term は Win32 API で書かれているので、Mac ではそのまま動きません。Tera Term Mac は、本家の動きに合わせながら Swift / AppKit で作り直したものです。

  • 本家のソースをそのまま使うもの: ファイル転送のプロトコル (teraterm/ttpfile の C のソースを CTeraFile にコピー)、正規表現の鬼車
  • 本家のファイルをビルドのときに使うもの: installer/release/TERATERM.INI (設定の初期値)、installer/release/lang_utf8/*.lng (画面の言語)、installer/release/theme (テーマの見本)、teraterm/common/helpid.h (ヘルプ ID)。scripts/bundle.sh がアプリにコピーします
  • 本家のファイルから作るもの: 文字幅の表と 1 バイト文字コードの表 (生成スクリプト)
  • 本家を Swift に移したもの: TTL マクロ (ttpmacro)、TEK、ログ、コマンドライン、キーマップ、TTProxy のやりとりなど。ソースの先頭のコメントに、元にした本家のファイルや関数を書いています
  • Mac 向けに作り直したもの: 画面・メニュー・ダイアログ、接続 (SSH は TTSSH の代わりに macOS の OpenSSH を使う)、設定の保存 (UserDefaults)、パスワードの保存 (キーチェーン)
  • ヘルプ: 本家の doc/ja・doc/en を元に Mac 向けに書き直したものを macos/Resources/help-mac に置いています

マクロについて本家に合わせたところ・Mac 向けに変えたところは、リポジトリの macos/docs/マクロ互換性.md にまとめています。 OS によって違う動きは、Windows ではなく macOS のやり方に合わせる方針です。
