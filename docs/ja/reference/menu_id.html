メニュー ID 表

メニュー ID は、キーボード設定ファイルの [User keys] (Control flag 3) と callmenu マクロコマンドで使います。使えるのは下の表の ID です。ほかの ID を指定すると「callmenu (ID) には対応していません」と表示します。

  • 50112 (Cygwin connection) はローカルシェル接続を開きます。
  • 50123 (Show Log dialog) はログファイルを Finder で表示します。
  • 50360 は新しい接続ダイアログを開きます。50380 (Save setup) は今の設定を環境設定に保存します。
