画面の言語 (Lang.swift)

画面の文言は Sources/TeraCore/Lang.swift の Lang で引きます。言語ファイルは 2 種類あります。

引き方言語ファイル使うところ
Lang.t("Tera Term", "MENU_FILE_NEW", "新しい接続...")本家の installer/release/lang_utf8/<言語>.lng (節とキーは本家と同じ)本家と同じ文言
Lang.m("MENU_TOGGLE_MENUBAR", "メニューバーを開く")macos/Resources/lang/mac_<言語>.lng の [Tera Term Mac] 節Mac 版だけの文言

最後の引数は、見つからないときの既定の文言 (日本語) です。%s %d などを含む文言には、後ろに値を渡せます (Lang.m("SETUP_INI_LOADED", "%s を読み込みました", name))。 返す文字列からは Windows のアクセスキー ((&F) &F) とショートカットの表示 (\tAlt+N) を外し、\n を改行にします。手を加えない値が要るときは Lang.raw を使います。

探す順

  1. 選んだ言語の本家の言語ファイル (例 ja_JP.lng)
  2. 選んだ言語の Mac 版の言語ファイル (例 mac_ja_JP.lng)
  3. 英語の本家の言語ファイル (en_US.lng)
  4. 英語の Mac 版の言語ファイル (mac_en_US.lng)
  5. 引数の既定の文言

節名とキー名は大文字小文字を区別しません。言語ファイルは、アプリでは Contents/Resources/lang、開発中 (swift build) はソースの macos/Resources/lang と installer/release/lang_utf8 から読みます。

言語の選び方

使う言語は UserDefaults の UILanguageFile (本家の TERATERM.INI と同じ名前。例 ja_JP.lng) です。本家の lang_utf8\ja_JP.lng のような書き方でも、ファイル名だけを使います。 空のとき (自動) は macOS の言語設定を優先順に見て、いちばん近い言語ファイルを選びます。地域まで合うもの (例 pt-BR → pt_BR.lng)、なければ同じ言語のもの、中国語は繁体字 (Hant・TW・HK・MO) なら zh_TW.lng、それ以外は zh_CN.lng です。どれもなければ英語にします。 言語を変えると Lang.didChange の通知が出て、メニューなどを作り直します。

文言を足すには

  1. 本家の言語ファイルに同じ意味の文言があれば、Lang.t で本家の節とキーを使います。
  2. なければ Lang.m("キー", "日本語の文言") と書き、Resources/lang/mac_ja_JP.lng と mac_en_US.lng の [Tera Term Mac] 節にキーを足します。ほかの言語の mac_*.lng にも足してください (ない言語では英語が出ます)。
  3. 言語ファイルの値は前後の空白が落ちます。前後に空白や記号が要るときはコードの側で付けてください。

言語を足すには

選べる言語は、本家の lang_utf8 にある言語ファイル (Default.lng と mac_*.lng を除く) です。名前は各ファイルの [Info] language= を使います。 本家にある言語なら、Resources/lang/mac_<言語>.lng を作って (mac_en_US.lng を写して訳します。UTF-8) [Info] language= と [Tera Term Mac] 節を書けば、scripts/bundle.sh がアプリに入れます。 本家にない言語は、まず本家の言語ファイルが必要です。

ヘルプ

ヘルプは macos/Resources/help-mac/{ja,en} にあります。本家の doc/ja・doc/en を元に Mac 向けに書き直したもので、本家と同じ BSD ライセンスです。 画面の言語が日本語のときは ja、それ以外の言語では en を見ます (HelpViewer.language)。その言語のヘルプがないときはもう一方を使います。

ファイル中身
html/ヘルプのページ。従来の目次は html/index.html
teraterm.hhp本家の CHM と同じ hhp。[ALIAS] の HlpXxx=html\menu\xxx.html を、ヘルプ ID からページを引くのに使います (Shift_JIS)
modern-toc.jsonモダン表示の左の目次 (やりたいこと別)
html/modern.htmlモダン表示のトップページ

アプリでは scripts/bundle.sh が Contents/Resources/help/{ja,en} にコピーし、本家の teraterm/common/helpid.h を Contents/Resources/help/helpid.h に入れます。開発中はソースの help-mac (なければ本家の doc) を読みます。

ヘルプ ID

ダイアログの「ヘルプ」ボタンなどは、本家と同じヘルプ ID でページを開きます。 

HelpViewer.openIndex()                                 // 目次 (モダン表示では modern.html)
HelpViewer.open(topic: "HlpMenuSetupAdditionalTheme")  // helpid.h の名前
HelpViewer.open(id: 43024)                             // helpid.h の番号
HelpViewer.open(relativePath: "html/menu/setup-font.html#xxx")

名前から teraterm.hhp の [ALIAS] でページを、番号から helpid.h の #define で名前を引きます。知らない名前のときは目次 (HlpIndex) を開きます。 ページを足して ID から開きたいときは、teraterm.hhp の [ALIAS] に行を足します。

ヘルプの画像

アプリを小さくするため、ヘルプの画像 (*.png) はアプリに入れていません。ページを表示したとき、手元に画像がなければ、本家が公開している Web 版のマニュアル (https://teratermproject.github.io/manual/5/<言語>/) の同じパスから読みます。ネットにつながっていないときは画像だけが出ません。 そのため、Mac 版で書き直したページでも、画像のパスは本家と同じにしておく必要があります。

モダン表示 (HelpModernStyle.swift)

ヘルプのウインドウでは「クラシック」と「モダン」を切り替えられます (既定はモダン。UserDefaults の HelpStyleModern)。モダン表示でもページの HTML はそのままで、表示するときにスクリプトで新しい見た目 (システムのフォント、広めの行間、ダークモード、左の目次と検索) をかぶせます。

  • 左の目次は <言語>/modern-toc.json です。形は [{"t": 見出し, "items": [{"t": 題, "p": html/ からのパス}]}] で、p には # 付きのアンカーも書けます。ファイルがないときは、従来の目次 (html/index.html の div.topic とその下のリンク) から作ります。
  • トップページは html/modern.html です (なければ html/index.html)。
  • ページを足したら、html/index.html、modern-toc.json、必要なら modern.html の 3 か所に載せてください。

ページの文字コード

本家から来たページの多くは Shift_JIS (日本語) / ASCII (英語) で、改行は CRLF です。書き直すときは元の文字コードと改行のままにしてください。Mac 版で新しく作るページは UTF-8 (<meta charset="utf-8">) にしています。モダン表示はページの meta charset を見て読みます (ないときは UTF-8、だめなら Shift_JIS)。
