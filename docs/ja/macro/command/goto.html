goto

ラベルへジャンプする。 

goto <label>

解説

<label>行の次の行へジャンプする。
なお、forやwhileなどのループを抜けるために、gotoは使えないため、代わりにbreakを使うこと。

例

; ':label' の次の行へジャンプ。
goto label
...
...
...

; ラベル行
:label
send 'abc'
