var2clipb

テキストデータをクリップボードにコピーする。 

var2clipb <string>

解説

<string>をクリップボードにコピーする。
このコマンドの実行結果はシステム変数 result に格納される。変数 result の値の意味は以下のとおり。

値 意味
0 クリップボードを開けなかった。
1 クリップボードへのコピーに成功した。

例

var2clipb 'Tera Term 4.46'
clipb2var data
messagebox data 'clipboard data'
