setflowctrl

シリアルポートのフロー制御を変更する。 

setflowctrl <value>

パラメータ

整数 <value>
以下のフラグにより、シリアルポートのフロー制御を指定する。
値 意味
1 Xon/Xoff
2 hardware(RTS/CTS)
3 none
4 hardware(DSR/DTR)

例

; change flow control to "none"
setflowctrl 3
