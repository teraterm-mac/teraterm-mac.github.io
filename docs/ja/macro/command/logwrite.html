logwrite

文字列をログに書き込む。 

logwrite <string>

解説

文字列 <string> を Tera Term のログファイルに追加して書き込む。
このコマンドは Tera Term がログを取っている時だけ有効。ログを一時中断している時でも書き込むことができる。

空文字列の場合は syntax error となる。
