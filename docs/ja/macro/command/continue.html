continue

ループの次の反復処理に移る。 

continue

解説

"for" や "while" のループの内側から、そのループの次の反復処理に制御を移す。

例

a=0
b=0
while a<5
    a=a+1
    if a>2 then
        continue
    endif
    b=b+1
endwhile

sprintf2 var "a=%d b=%d" a b
dispstr var
;a=5 b=2

参照

  • do, loop
  • for, next
  • until, enduntil
  • while, endwhile
  • break
