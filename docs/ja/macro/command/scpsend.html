scpsend

SCPプロトコルでファイルを送信する。 

scpsend <filename> [<destination filename>]

解説

ファイル <filename> を SCP(Secure Copy Protocol) プロトコルで送信する。 SSH の接続を共有して、Mac の scp コマンドで転送する。SSH で接続しているときだけ使える。 転送先を省略した場合は、ファイルはリモートホストのホームディレクトリへコピーされる。 送信が終わるのを待たずに、次のコマンドを実行することができる。

例

connect '192.168.3.2:22 /ssh /auth=password /user=hoge /passwd=fuga'
wait '$'
scpsend '/Users/user/doc/manual.pdf'
scpsend '/Users/user/doc/manual.pdf' 'tmp/foo.pdf'

; ファイル送信完了を確認する
SOURFILE = '/Users/user/doc/manual.pdf'
DESTFILE = '~'

;; ファイル送信
scpsend SOURFILE DESTFILE
;; ファイル送信プロセス確認
do
  mpause 5000
  sprintf2 str 'ps -ef |grep -v grep |grep -c scp'
  sendln str
  waitln '0' '1'
loop while result != 1
;; ファイル送信が完了すると次のマクロを実行
sendln 'echo SCP finish'
;; マクロ終了
end
