getttdir

Tera Term Mac.app があるディレクトリを得る。 

getttdir <strvar>

解説

Tera Term Mac.app が置いてあるフォルダ (例: /Applications) を文字列変数 <strvar> に格納する。
ディレクトリの取得に成功した場合は、システム変数 result に1が返る。失敗した場合は、result に0が返る。

例

getttdir dir
messagebox dir 'getttdir' 0
; dir is "/Applications"
