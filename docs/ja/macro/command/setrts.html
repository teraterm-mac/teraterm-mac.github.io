setrts

Tera Term で RTS(Request To Send) の状態を変更する。 

setrts <flag>

解説

接続がシリアル接続ではない場合やフロー制御が none でない場合には、このコマンドは何も行わない。

もし <flag> が0なら RTS は off になる。
もし <flag> が0以外なら RTS は on になる。

例

; RTS on
setrts 1

; RTS off
setrts 0
