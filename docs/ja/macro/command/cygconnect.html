cygconnect

Mac のローカルシェルに接続する。 

cygconnect [<command line parameters>]

解説

マクロを動かしているウインドウを、この Mac のローカルシェル (設定のローカルシェルタブで決めたシェル) につなぐ。<command line parameters> は Windows 版のマクロとの互換のために受け付けるが、使わない。

マクロがウインドウとリンクされていない場合 (unlink や closett のあと) は、新しいウインドウを開いてマクロとリンクし、そのウインドウでローカルシェルにつなぐ。

マクロがウインドウとすでにリンクされていて、ウインドウがホスト又はローカルシェルにすでに接続されている場合、このコマンドは無視される。

このコマンドの結果、リンクと接続の状態に応じて以下のうちの一つの値がシステム変数 result に格納される。

値 状態
0 ウインドウとリンクされていない。
1 ホスト又はローカルシェルへの接続はされていないが、ウインドウとのリンクはされている。
2 リンクおよび接続両方ともされている。

"cygconnect" コマンドを実行する前にリンクと接続の状態を調べるには、"testlink" コマンドを使うことができる。

マクロがウインドウとリンクしていない状態では、"connect" と "cygconnect", "testlink" 以外の通信コマンドは実行できない。

例

; ローカルシェルに接続する
cygconnect
