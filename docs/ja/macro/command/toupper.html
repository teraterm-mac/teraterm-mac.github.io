toupper

文字列をすべて大文字に変換する。 

toupper <strvar> <string>

解説

<string> に含まれるアルファベットを全て大文字にし、 <strvar> に代入する。

例

; valstrに 'ABCDEFGH' が代入される
toupper valstr 'abCDefGH'
