connect

接続する。 

connect <command line parameters>

解説

マクロを動かしているウインドウを、<command line parameters> で指定した接続先につなぐ。<command line parameters> の書式は Tera Term Mac のコマンドラインと同じ (SSH のオプションも使える)。

マクロがウインドウとリンクされていない場合 (unlink や closett のあと、またはウインドウが閉じられたあと) は、新しいウインドウを開いてマクロとリンクし、そのウインドウで接続する。

マクロがウインドウとすでにリンクされていて、ウインドウがホストに接続されていない場合、そのウインドウを <command line parameters> で指定されるホストに接続させる。接続先を指定しないときは、接続のダイアログを出す。

マクロがウインドウとすでにリンクされていて、ウインドウがホストにすでに接続されている場合、このコマンドは無視される。

接続し終わる (または失敗する) まで、マクロは次の行に進まない。このコマンドの結果、リンクと接続の状態に応じて以下のうちの一つの値がシステム変数 result に格納される。

値 状態
0 ウインドウとリンクされていない。
1 ホストへの接続はされていないが、ウインドウとのリンクはされている。
2 リンクおよび接続両方ともされている。

"connect" コマンドを実行する前にリンクと接続の状態を調べるには、"testlink" コマンドを使うことができる。

マクロがウインドウとリンクしていない状態では、"connect" と "cygconnect", "testlink" 以外の通信コマンドは実行できない。

接続方法

マクロから接続する方法には、次の種類があります。

  • telnet接続 (port 23)
  • SSH接続 (port 22)
  • シリアルポート接続

telnet接続

connect 'myserver:23 /nossh /T=1'
connect 'myserver:23'

/nossh を指定することを強く推奨します。このオプションがない場合、最後に保存された設定と同じ方法（telnet もしくは SSH）で接続しようとします。もし、SSHを使って接続しようとするならば、connectマクロは失敗するでしょう。

/T=1 を使うことを推奨します。このオプションがない場合、設定の Telnet の値にしたがって接続しようとします。もし、Telnet の値も off の場合、telnet ネゴシエーションをしないので、意図したとおりの通信ができないでしょう。

SSH接続

SSH は Mac の ssh コマンド (OpenSSH) で、SSH2 でつなぎます。 

connect 'myserver /ssh'
connect 'myserver /ssh /2'

connect 'myserver /ssh /auth=password /user=username /passwd=password'
connect 'myserver /ssh /auth=publickey /user=username /passwd=password /keyfile=private-key-file'
connect 'myserver /ssh /auth=challenge /user=username /passwd=password'

この方法は、マクロからユーザ名とパスワードを渡すことにより、パスワードの入力を省くことができます。/auth=passwordはパスワード認証、/auth=publickeyは公開鍵認証 (/passwd= は秘密鍵のパスフレーズ)、/auth=challengeはチャレンジレスポンス認証であることを表します。 

connect 'myserver /ssh /auth=pageant /user=username'

この方法は、マクロからユーザ名を渡して、ssh-agent などに登録した鍵で公開鍵認証をします。 

connect 'myserver /ssh /auth=password /user=username /ask4passwd'
connect 'myserver /ssh /auth=publickey /user=username /ask4passwd /keyfile=private-key-file'
connect 'myserver /ssh /auth=challenge /user=username /ask4passwd'

この方法は、マクロからユーザ名と認証方法を渡して、ポップアップでパスワードの入力を促します。

シリアルポート接続

connect '/C=x'
connect '/C=/dev/cu.usbserial-XXXX'

x は、Mac のシリアルポートの一覧で何番目のポートかを表します (1 から数えます)。たとえば、1 番目のポートに接続したいのなら、 connect '/C=1' とします。/C=/dev/cu.usbserial-XXXX のように、デバイスを直接書くこともできます。

例

; 接続先を指定しない (接続のダイアログを出す)
connect ''

; 接続が成功しなかった場合、5秒でタイムアウトが発生
connect 'myserver /timeout=5'

; telnet セッションを開く
connect 'myserver:23 /nossh'

; SSH セッションを開く
connect 'myserver /ssh'

; SSH セッションを開き、ユーザ名とパスワードのプロンプトは表示されない。
connect 'myserver /ssh /auth=password /user=username /passwd=password'

; SSH セッションを開き、ユーザ名とパスワードと秘密鍵ファイルのプロンプトは表示されない。
connect 'myserver /ssh /auth=publickey /user=username /passwd=password /keyfile=private-key-file'

; ssh-agent の鍵を利用して、公開鍵認証で接続する。ユーザ名とパスワードと秘密鍵ファイルのプロンプトは表示されない。
connect 'myserver /ssh /auth=pageant /user=username'

; シリアルポート接続を開く。x はシリアルポートの一覧で何番目か (1 から)。
connect '/C=x'

CommandLine = '111.111.11.11'
connect CommandLine

; Sample macro for Tera Term
;  Telnet login

; connect to the host (telnet)
connect 'myhost.mydomain'

; set username
UsernamePrompt = 'Username:'
Username = 'MYNAME'
PasswordPrompt = 'Password:'
; get password from file
getpassword 'password.dat' 'mypassword' Password

; login

sendln Username

wait   PasswordPrompt
sendln Password

; OK, auto login complete.

;

; Environment: generic

username = 'nike'
hostname = '192.168.1.3'

;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;

msg = 'Enter password for user '
strconcat msg username
passwordbox msg 'Get password'

msg = hostname
strconcat msg ':22 /ssh /auth=password /user='
strconcat msg username
strconcat msg ' /passwd='
strconcat msg inputstr

connect msg

注意

  1. このページの例において斜体で表示されている値を、実際の値に置き換える必要があります。
  2. パスワードにはスペースを含むことが可能です。パスワードの中でスペースを表すには、パスワード全体を `"' で囲んでください。パスワードに " を含めるためには、連続した `"`("") を使用してください。
  3. マクロにユーザ名とパスワードを指定した場合、そのマクロファイルをプレーンテキストとして保存したのなら、セキュリティ的に安全な場所に置く必要があることを肝に銘じておいてください。
  4. ホストとの接続を終了してすぐにconnectコマンドで新しい接続を開始しようとした場合、タイミングによっては接続できない場合があります。詳しくは"切断後すぐに接続する場合の注意点"を参照してください。
  5. SSH のコマンドラインのパスワードを指定するときの注意を参照してください。
