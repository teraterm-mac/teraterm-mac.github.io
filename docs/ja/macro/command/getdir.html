getdir

マクロのカレントディレクトリを得る。 

getdir <strvar>

解説

"マクロのカレントディレクトリ" を、Mac のパス (例: /Users/user/Macro) で文字列変数 <strvar> に格納する。初めは、マクロファイルのあるフォルダ。
ルートディレクトリの場合は "/" になる。ルート以外のディレクトリの場合、文字列はディレクトリ名で終わり、末尾に "/" は付かない。

例

getdir dir
; dir = /Users/user/Macro
