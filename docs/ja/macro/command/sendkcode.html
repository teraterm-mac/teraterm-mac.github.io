sendkcode

キーコードを送信する。 

sendkcode <key code> <repeat count>

解説

あるキーまたはキーの組み合わせを押すことに対して割り当てられた機能を実行させる。
そのキーまたはキーの組み合わせはキーコード <key code> (キーボード設定ファイルと同じ、IBM PC キーボードのキーコード) で指定される。その機能は <repeat count> 回繰り返して実行される。
キーボード設定ファイル (KEYBOARD.CNF) で割り当てのあるキーは、その内容を送る。割り当てがないときは、よく使うキー (矢印キー、ファンクションキー、テンキーなど) だけ送れる。送れないキーコードでは、画面に「対応していません」と出す。

通常、その機能とは文字または文字列をホストへ送出するということ。その機能はキーボード設定ファイルによって定義することができる。
キーボード設定ファイル 参照。

sendkcode を用いて キーボード設定ファイルの [User keys] セクション <制御フラグ> 2 マクロファイルの実行はできません。
sendkcode を用いた キーボード設定ファイルの [User keys] セクション <制御フラグ> 3 メニューコマンドの実行は未サポートです。
メニューコマンドの実行はcallmenuコマンドを使用して下さい。

例

; ↓キーが3回押された場合と同じ動作をさせる。
; ↓キーのキーコードは IBM PC キーボードの場合336。
sendkcode 336 3
