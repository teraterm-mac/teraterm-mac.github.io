closett

マクロを動かしているウインドウを閉じる。 

closett

解説

ウインドウを閉じ、マクロは非リンク状態に入る。マクロは動き続ける。
非リンク状態では、connect コマンドによって新しいウインドウを開き、マクロをそれにリンクさせることができる。

ConfirmDisconnectの設定有無に関係なく、常に TCP/IP 回線切断の確認をしない。

例

messagebox 'foo' 'val'
closett
end
