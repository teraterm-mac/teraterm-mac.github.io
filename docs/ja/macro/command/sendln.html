sendln

データと改行を送信する。 

sendln <data1> <data2>....

解説

文字列とそれに続く改行文字をホストへ送信させる。
<data> の形式は、"send"コマンドと同じ。

例

; 改行文字だけ送信
sendln

sendln 'abc'

Password='mypassword'
sendln Password

同期モードについては "setsync" を参照。
