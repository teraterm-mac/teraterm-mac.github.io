basename

パス名からファイル名を得る。 

basename <strvar> <path>

解説

パス名 <path> からファイル名部分を <strvar> に格納する。
パス名は文字列として処理しており、実在している必要はない。フォルダの区切りは '/' と '\' のどちらでもかまわない。

例

basename fname '/Users/user/teraterm/test.txt'
; fname = "test.txt"
