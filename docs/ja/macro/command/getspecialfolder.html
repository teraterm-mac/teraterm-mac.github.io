getspecialfolder

特殊フォルダのパスを取得する。

形式

getspecialfolder <strvar> <foldertype>

解説

<foldertype> で指定した種類の特殊フォルダのパスを取得して <strvar> に格納します。種類の名前は Windows 版と同じで、それぞれ Mac の近いフォルダ (下の表) を返します。'~' はホームフォルダ (例: /Users/user) を表します (実際の値には展開したパスが入ります)。

パラメータ

文字列変数 <strvar>
取得された文字列が格納される。
文字列 <foldertype>
この引数で指定した種類の特殊フォルダが文字列変数 <strvar>に代入される。
AllUsersDesktop /Users/Shared
AllUsersStartMenu /Applications
AllUsersPrograms /Applications
AllUsersStartup /Library/LaunchAgents
Desktop ~/Desktop
Favorites ホームフォルダ
Fonts /Library/Fonts
MyDocuments ~/Documents
NetHood ホームフォルダ
PrintHood ホームフォルダ
Programs ~/Applications
Recent ホームフォルダ
SendTo ホームフォルダ
StartMenu ~/Applications
Startup ~/Library/LaunchAgents
Templates ホームフォルダ

返り値

システム変数 <result>
取得に失敗すると0が格納される。
成功すると1が格納される。

例

getspecialfolder str "Desktop"
if result then
	messagebox str "Desktop"   ; /Users/user/Desktop
endif
