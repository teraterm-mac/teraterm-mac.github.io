filerename

ファイル名を変更する。 

filerename <file1> <file2>

解説

ファイル <file1> を <file2> という名前に変更する。
<file1> と <file2> は違う名前でなければならない。
ファイル名の変更が成功した場合、システム変数 result に 0 が格納される。それ以外の場合、result に 0 以外が格納される。

例

filerename 'test.dat' test2.dat'
