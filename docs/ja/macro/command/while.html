while, endwhile

繰り返す。 

while <expression>

  ...

  ...

endwhile

解説

'while' と 'endwhile' の間のコマンドを、 <expression> が0以外である限り、繰り返す。

例

; 10回繰り返す。
i = 10
while i>0
  i = i - 1
endwhile
