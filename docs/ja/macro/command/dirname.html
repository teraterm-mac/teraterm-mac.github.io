dirname

パス名からディレクトリ名を得る。 

dirname <strvar> <path>

解説

パス名 <path> のディレクトリ名部分を <strvar> に格納する。
パス名は文字列として処理しており、実在している必要はない。フォルダの区切りは '/' と '\' のどちらでもかまわない。

例

dirname dir '/Users/user/teraterm/test.txt'
; dir = "/Users/user/teraterm"
dirname dir '/Users/user/teraterm/'
; dir = "/Users/user"
dirname dir '/Users/user/teraterm'
; dir = "/Users/user"
