clearscreen

ウィンドウの画面を消去する。 

clearscreen <int>

解説

<int> が0の場合、 端末のウインドウの画面を消去する。
<int> が1の場合、 端末のウインドウのスクロールバッファーの内容と画面を消去する。
<int> が2の場合は何もしない (Windows 版のマクロとの互換のために受け付ける)。

例

clearscreen 0
