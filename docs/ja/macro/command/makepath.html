makepath

フルパス名を作成する。 

makepath <strvar> <dir> <name>

解説

ディレクトリ名 <dir> とファイル名 <name> からフルパス名を作成し、文字列変数 <strvar> に格納する。 もし必要なら <dir> と <name> の間に "/" を挿入する (<dir> に "\" だけが使われているときは "\" を挿入する)。

例

makepath path '/Users/user/teraterm' 'test.txt'
; path = "/Users/user/teraterm/test.txt"
