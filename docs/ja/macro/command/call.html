call

サブルーチンをコールする。 

call <label>

解説

<label> 行から始まるサブルーチンをコールする。

例

messagebox "I'm in main." "test"
; ":sub" へ飛ぶ。
call sub
messagebox "Now I'm in main" "test"
end

; サブルーチンの始まり。
:sub
messagebox "Now I'm in sub" "test"
; メインルーチンへもどる。
return
