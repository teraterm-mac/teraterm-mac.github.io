setdir

マクロのカレントディレクトリを変更する。 

setdir <dir>

解説

マクロのカレントディレクトリを <dir> に変更する。パスは Mac のパスで書く ('~' はホームフォルダ。'c:' のようなドライブ名は無視し、'\' は '/' として扱う)。

ファイル操作コマンド(fileopen 等)で指定されるファイル名は "マクロのカレントディレクトリ" を基準にする。

注意

setdir コマンドは "マクロのカレントディレクトリ" を変更する。
changedir コマンドは "ファイル転送用ディレクトリ" を変更する。

例

setdir '~/Documents'
