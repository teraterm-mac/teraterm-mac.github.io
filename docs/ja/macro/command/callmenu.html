callmenu

ウィンドウのメニューを実行する。 

callmenu <menu ID>

解説

<menu ID> で指定されたメニューを実行する。使える ID は次のとおり。そのほかの ID では、画面に「対応していません」と出すだけで何もしない。

ID 操作
50110, 50003 新しい接続
50111, 50010 セッションの複製
50112 新しいウインドウでローカルシェル
50120 ログ
50124 ログの一時停止 / 再開
50125 ログの停止
50122 ログファイルを開く
50123 ログファイルを Finder で表示
50130 ファイル送信
50190, 50009 切断
50199, 50005 ウインドウを閉じる
50200 終了
50210, 50002 コピー
50230, 50008 貼り付け
50250 画面のクリア
50260 バッファのクリア
50280, 50290 すべて選択
50310, 50320, 50330, 50340, 50370, 50375 設定のダイアログ
50350 シリアルポートの設定
50360 新しい接続
50380 設定の保存
50410 端末リセット
50411 リモートタイトルリセット
50420 AYT 送信
50430, 50001 ブレーク送信
50440 ポートのリセット
50470 マクロ
50990 バージョン情報

例

; すべて選択
callmenu 50280

; クリップボードへコピー
callmenu 50210
