showtt

Tera Term ウィンドウの表示状態を変更する。 

showtt <show flag>

解説

<show flag> が-1の場合、 端末のウインドウを隠す。
<show flag> が0の場合、 端末のウインドウを最小化する。
<show flag> が1の場合、 端末のウインドウを元の大きさに戻す。
<show flag> が2の場合、 TEK ウインドウを隠す。
<show flag> が3の場合、 TEK ウインドウを最小化する。
<show flag> が4の場合、 TEK ウインドウを開く、または元の大きさに戻す。
<show flag> が5の場合、 TEK ウインドウを閉じる。
<show flag> が6の場合、 ログウィンドウを隠す。
<show flag> が7の場合、 ログウィンドウを最小化する。
<show flag> が8の場合、 ログウィンドウを元の大きさに戻す。

例

; Tera Term を最小化
showtt 0

; Tera Term を元の大きさに戻す
showtt 1

; Tera Term を隠す
showtt -1

showtt 7    ;Minimize log window 
showtt 8    ;Restore log window 
showtt 6    ;Hide log window
