exec

アプリケーションを起動する。 

exec <command line> [<show> [<wait> [<current directory>]]]

解説

コマンドライン文字列 <command line> を /bin/sh -c で実行する。パイプやリダイレクトなど、シェルの書き方が使える。Mac のアプリは 'open -a TextEdit readme.txt' のように open コマンドで起動する。

パラメータ

文字列 <show> (オプション デフォルト="show")
Windows 版のマクロとの互換のために受け付けるが、使わない ("hide", "minimize", "maximize", "show" のどれを指定しても同じ)。
整数値 <wait> (オプション デフォルト=0)
1 の場合は、起動したアプリケーションが終了するまで待つ。アプリケーションの終了コードが result システム変数に格納される。
1 以外の場合は、アプリケーションを起動してマクロに制御が返る。
文字列 <current directory> (オプション デフォルト="")
カレントディレクトリを指定することができる。
省略したときは、マクロファイルのあるフォルダで動く (setdir や changedir では変わらない)。

返り値

システム変数 <result>
<wait> が 1 の場合
値 意味
-1 アプリケーションの実行に失敗した。
-1 以外 アプリケーションの終了コード

<wait> が 1 以外の場合
値 意味
-1 アプリケーションの実行に失敗した。
0 アプリケーションの実行に成功した。

例

; 「テキストエディット」でファイルを開く
exec 'open -a TextEdit readme.txt'

; フォルダを指定して実行
exec 'ls -l > list.txt' 'show' 0 '/Users/user/work'

; 終わるまで待って、終了コードを調べる
exec 'ping -c 1 192.0.2.1' 'hide' 1
if result = 0 messagebox 'OK' 'ping'

; シェルスクリプトを起動する
tmp='/bin/sh ~/upload.sh '
strconcat tmp username1
strconcat tmp ' '
strconcat tmp userpass1
strconcat tmp ' '
strconcat tmp address
messagebox tmp 'exec'
exec tmp

; ディレクトリを作る
getenv "HOME" home
getdate logdir "log-%Y%m%d"
sprintf2 cmd 'mkdir -p "%s/Documents/%s"' home logdir
exec cmd "HIDE"
