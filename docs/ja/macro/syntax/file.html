エンコーディング

マクロファイルは Unicode (UTF-8, UTF-16BE, UTF-16LE) で書けます。UTF-8 を推奨します。
Windows 版の Tera Term 用に Shift_JIS で書いたマクロファイルも読めます。

1) サポートするエンコーディング

encoding support
Shift_JIS Support
UTF-8 (with BOM) Support
UTF-8 (without BOM) Support
UTF-16BE (without BOM) Not support
UTF-16LE (without BOM) Not support
UTF-16 (with BE BOM) Support
UTF-16 (with LE BOM) Support
UTF-16 (without BOM = UTF-16BE) Not support

2) エンコーディングの判定

Tera Term Mac は次のように判定します。

BOMがある場合
BOMの種別からUTF-8, UTF-16BE, UTF-16LEを判定して読み込む
BOMがない場合
  • UTF-8として読み込む
  • UTF-8としてデコードできなかった場合はShift_JISとして読み込む
