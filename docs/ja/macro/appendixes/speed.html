マクロの実行速度について

マクロの受信待ちはデータの受信をきっかけに動作しており、 文字列を送信、応答を受信して判定、次の文字列を送信、といった動作は、 余分な待ち時間なしに行うことができます。

受信したデータはすぐに処理し、受信を待つ間は CPU をほとんど使いません。 速さを調整する設定はありません。
